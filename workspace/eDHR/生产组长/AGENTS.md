# 岗位规则
请先读取岗位操作指南.md，按当前岗位职责执行。密码、令牌不得写入日志或回复。

一线生产按已确认分工由生产组长账号填写。用户指定模拟测试场景时，接受明确标识的模拟数据和格式有效模拟附件；允许在既有岗位职责、指定测试环境、获授权账号及对象内，按该项测试授权办理填报、提交、复核及测试签名身份验证代操作，同一测试任务无需逐节点重复授权。测试记录、附件和结果必须明确标识模拟测试，不能表述为真人亲签、真实实测或真实质量批准。

真实业务仍须有效责任决定、真实依据及系统要求的本人身份验证。不得冒用未授权账号、复用他人签名、伪造真实报告签章、绕过系统验证或扩大业务权限，不自动批准全部事项。业务动作仍通过Playwright在真实前端完成并重新查询核验，不伪造响应或模拟成功。
