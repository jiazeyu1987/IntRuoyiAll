## 2. 数据准备：统一从同步工单取数（不是已创建的事实）

2026-11-25按用户要求修订：所有被测工单统一通过正式页面的工单同步取得，再在“排产工单→同步工单”中筛选、核验和选取；后续入池、排程、报工归属及状态场景均沿用这些同步工单的真实ID与正式关联。不使用“准备本轮虚拟数据”、手工新建工单、模拟生成工单、接口或数据库造单作为输入来源，也不把虚拟RUN准备失败当作同步工单测试的前置阻塞。

先记录同步入口、同步结果及来源单号，在同步工单页核对产品、数量、单位、路线版本、BOM和当前状态；仅打开页签不代表已执行同步。A/B/C只是选中同步工单的测试别名，不是要求新建的编号。数量、资源能力和余量取实际页面值，按真实值计算预期；不得为凑100/50件等例数修改来源数量或伪造库存、报工及生产事实。需要固定边界的子项应从同步数据中筛选符合条件的对象，找不到则仅登记该子项缺少的具体条件。

资源、班次、库存、BOM、单位、账号和模板不是工单同步自动生成的工单。它们只作为已选同步工单的配套前置核实：读取正式关联，获授权的可逆设置通过正式页面维护并记原值及共享范围，不另造一套虚拟工单配套。报工测试文件依据所选同步工单及正式模板准备，配置包从正式页面导出；错误文件只改副本。断网、无权、损坏文件等异常输入仍按各用例执行，不伪称它们来自工单同步，也不允许生成新的工单来源。

入池资格按工单状态、重复入池保护、产品绑定的启用生效路线、逐工序智能排产用途和排产策略及所选模式必需的产能条件判断；不要求ERP正式同步记录、来源ID或来源单据编号。该变更不豁免路线或产能配置，不伪造来源；正式应用排程时现有ERP来源风险提示与确认单独验证。

## 12. 报工菜单与导入链

写入由获授权责任岗在明确可修改的同步工单对象执行，不替代一线本人签署。D7必须分别制作普通第三方模板和李萍报工单模板，不能混用结果。当前同一上传入口按表头自动识别并切换模式，选择文件本身不写业务，点击“确定”才发起导入。普通模板列与直接模板列分别以正式入口及解析器为准；文件大小上限以部署配置为准，未明确记待确认，不自行猜值。

| 分支 | 导入后的正式结果 | 后续步骤与验证边界 |

## 13.1 条件变化的因果验收（2026-11-26新增，全部未执行）

本组补足E2E-01/05的完整用户主链：基线→调整产能/系数→保存核验→检查并应用→独立计算预期与实际对照。先证明条件已保存，再证明重新计算实际消费了条件，最后证明正式应用与各页面一致。原126个用例保留，新增CC-01～08共8个，合计134个；参数分支分别记执行记录，不另冒计编号。历史观察日期及结果不变。

完整测试主链为：核实同步来源及已有结果 → 筛选同步工单 → 核对入池条件 → 单笔／批量入池 → 核对路线、产能、班次及物料提示 → 排产前检查 → 确认范围和开排日期 → 应用基线排程 → 工单、工序计划、工作台、日历、甘特图交叉核对 → 记录基线并调整获授权的产能／系数等条件 → 核对保存、生效对象和生效时机 → 重新检查并应用排程 → 独立计算并核对需求、工时、每日量、负荷和起止日期变化 → 生产组长查到正确工单与计划 → 获授权生产人员提交实际报工 → 核对报工、进度及剩余需求 → 按变化再次检查并重排 → 核对保护对象、范围外工单及历史记录 → 恢复获授权且可逆的测试设置，保留正式业务记录并汇总未完成项。已有同步结果未知时先核实，不重复同步。

授权前提：881MO105183仅只读参考；881MO104106也不因本文件编制而获得写授权。选择任务自有或明确授权的同步工单，另取得共享设置及受影响路线范围授权。没有可操作对象只阻塞对应子项。真实报工由获权生产角色在真实前端办理，不造生产事实。

**计算口径和入口必须先辨清：**工作台工序列表班次产能C是该节点正式数量单位/班，按同组一致班时H换算小时产能R=C/H（六位HALF_UP），不是订单数量。它保存到同路线版本/节点的在制工序快照；保存并不重建正式任务起止。生产数量系数c来自路线SCHEDULE用途配置，不能把工作台当作它的编辑入口；须由获权责任岗通过正式路线入口按版本发布规则维护。节点计划需求为订单量Q×c（六位HALF_UP；先核对Q单位与c的量纲及路线正式单位），剩余需求还要扣正式有效完成量。c增大表示节点需求增大，不是速度增快。默认无限时长a(h/件)属于工作台排产设置，a增大表示每件耗时增大；它与生产数量系数、损耗系数是三种不同参数。仅保存默认a不能证明现有节点公式已改变，应核对正式节点公式与计算消费；传播规则未核实记待核/阻塞；只有业务明确要求该默认值作用于既有节点、而执行证据显示计算未消费时，才判失败。不得因静态代码搜索未找到链路就认定故障。正式节点公式变更与默认值传播验证可独立执行。

对应有限产能计算分支的理论总分钟为ceil(ceil8(Qrem/R)×60)+准备分钟+等待分钟，最少1分钟；具体资源时间切片、任务拆分精度及共享占用需按实际分配规则逐段复算，不能把理论总分钟当成所有任务必然等式。无限公式使用存储分钟参数ceil(a分钟×Qrem+b分钟)，界面小时须乘60。实际起止须沿可用班次逐段累加工作分钟，扣共享占用，并满足前后工序约束、开排日期及保护条件；不得简单用自然时间相加。任务总数量、各日分配数量、占用和负荷各用实际口径复算；负荷分母、舍入或分段规则不明时记录待确认，不能硬套百分比。参数变化可能被瓶颈或保护项遮蔽，须选可辨别的对象及足够跨分钟/班次阈值的合法变化，保留不变的合理解释。
