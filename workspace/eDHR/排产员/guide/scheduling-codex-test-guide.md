## 测试主链

登录指定服务器和租户 → 核对参与账号、岗位权限与本次可操作范围 → 核实同步来源及结果 → 筛选同步工单 → 核对入池条件 → 单笔／批量入池 → 核对路线、产能、班次及物料提示 → 排产前检查 → 确认排程范围和开排日期 → 应用基线排程 → 交叉核对工单、工序计划、排产员工作台、日历和甘特图 → 记录排程基线 → 分别调高、调低获授权的工序产能、生产数量系数等条件，再核对组合变化 → 核对保存结果、生效对象及生效时机，区分工作台产能维护、路线系数维护和正式任务重排 → 重新检查并应用排程 → 对照独立计算结果核实工序需求、剩余需求、工时、每日排量、负荷及起止时间是否按预期变化，并再次交叉核对各页面 → 由排产员本人查询并核对正确工单与计划 → 核对保护对象、范围外工单及历史记录 → 恢复获授权且可逆的测试设置，保留正式业务记录与测试证据 → 汇总成功、失败、阻塞及未完成项。

范围调整（2026-11-26）：按用户要求删除报工、报工导入、报工进度回写及依赖实际报工的生产变化后重排环节；这些环节不再是本轮主链的前置或验收项，也不计为测试通过。既有报工数据仅供只读核对，不新增或修改正式报工。
