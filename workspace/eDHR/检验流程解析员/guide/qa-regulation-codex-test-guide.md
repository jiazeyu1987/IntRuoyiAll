## 测试主链

登录指定服务器和租户 → 核对账号、目标产品与操作权限 → 记录现有数据基线 → 导入产品规程 Word 并查看解析结果（不验证原文，不以原文描述判定对错） → 验证错误文件、缺项提示 → 新增、修改、删除检验项目及调整顺序 → 核对筛选、分页、无结果和增删后的总数 → 新增或修改设备与抽样规则 → 验证取消编辑、保存、重复保存及刷新 → 验证发布拦截与失败后恢复 → 导入通用规程 Word、查看解析结果（不验证原文，不以原文描述判定对错）、保存、预览并发布 → 产品规程关联指定通用版本并发布 → 修改产品草稿、核对旧正式版不变、发布新版本 → 升级通用规程并核对旧关联不变 → 产品主动改绑新版通用规程并发布 → 查看历史版本，核对新旧版本的内容、设备、抽样规则和通用关联 → 导出回导逐项对照 → 重置目标项目 → 对照基线核查清理范围和非目标数据 → 汇总成功、失败和未完成项。
