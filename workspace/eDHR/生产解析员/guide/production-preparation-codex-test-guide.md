## 测试主链

第一步：先登录指定服务器和租户，核对账号及删除权限，记录 IBPTR、PBAP、XSCX、PTCABC、QSN 对应已有工艺流程的编号、名称及关联基线，再通过真实前端删除这五个目标项目对应的已有工艺流程；重新查询确认删除结果后，才开始后续生产编制主链。没有对应流程时记录无需删除；删除被权限或引用规则阻止时，如实记录并暂停依赖该删除的后续动作，不扩大删除范围。

完成上述删除及结果核验 → 核对账号、目标项目、操作权限及生产编制入口 → 记录目标项目现有工艺流程、工序、工艺、设备及车间的关联基线，明确本次允许新建和复用的范围 → 进入“生产编制”页签，按上表选择绑定项目（不是源文件目录所标识的项目），核对项目名称、编码及“已有工艺流程”提示，如仍提示占用，核查第一步删除结果，不擅自扩大删除范围 → 导入对应生产记录 Word，等待解析完成，查看工序数量、顺序、名称、关键或特殊工序标记、输入物料、输出物料、设备及参数组的解析结果（不验证原文，不以原文描述判定对错） → 验证未选项目、错误文件、解析失败及重新导入时替换未保存内容的提示，取消替换后核对当前编辑内容保留 → 维护工艺流程名称和工作站所属车间，核对必填提示及保存结果 → 逐道切换工序，验证新增、修改、删除、调整顺序及撤销，核对工序数量、当前选中项和修改内容 → 按需选择已有工序或改为新建工序，核对编号、名称及可编辑范围，验证同一流程重复选择已有工序的拦截 → 编辑输入、输出物料，验证目录搜索、选择、编码与名称修正、添加和删除，核对物料仍属于当前工序 → 维护设备与参数组，选择设备编号并核对设备名称，分别检查已有设备复用和文档新设备的建档提示，验证设备目录加载失败及重新加载 → 验证设备组新增、删除、单选或多选及“需要设备”开关，核对关闭组的设备及专属参数保留在草稿中、但不参与试填和发布，重新开启后恢复对应内容 → 新增、修改、删除参数，核对参数名称、控件类型、单位、参考值、默认值及适用的范围和选项，验证缺项与不合法配置提示；选择已有工艺时核对所属工序、带入参数及编辑限制 → 切换“试填预览”，逐工序检查输入输出物料、设备选择、参数控件、默认值和填写校验，再返回编辑，核对各工序内容及切换结果 → 保存草稿，核对保存状态，在当前浏览器刷新后恢复草稿，核对项目、流程名称、车间、工序顺序、物料、设备组、参数及复用选择，验证恢复时替换未保存内容的确认 → 导出 Word 后重新导入，逐项核对导出时的编辑内容完整恢复，不把恢复导出内容当成重新解析原始文档 → 点击“预览发布”，检查待修正项定位，返回对应工序补正后重新预览 → 在复用确认中逐工序核对已有工序与工艺候选，明确复用或新建，验证取消、返回修改和重新预览后选择与当前内容一致 → 分别查看工序、设备、工艺和工艺流程四个预览页签，核对新建或复用动作、设备台账及新建台账类型、工艺所属工序与参数数、工序顺序、关键或特殊标记及设备组，确认清单没有范围外对象 → 验证缺少流程名称、车间或其他待修正项时不能确认发布，补正后核对阻塞解除；取消预览不应创建正式资料 → 在“工艺流程”预览中确认流程完整且顺序正确，点击“确认发布”，核对创建结果及工序、设备、工艺、流程编号，失败时保留错误信息，恢复或重试后核对没有重复建档 → 点击“配置并发布”进入本次创建的工艺流程候选版本，核对流程编号、名称、版本号、草稿状态及工序图，逐道确认工序顺序、关键或特殊标记、输入输出物料、工艺参数、设备组和工作站所属车间与已确认的编制内容一致 → 返回列表或重新打开同一候选版本，核对流程及关联内容仍完整，记录差异、失败和阻塞项，完成工艺流程确认 → 对照基线核对非目标资料，将本次结果、流程及候选版本编号和页面证据放入本岗位 output 下的本次测试文件夹，汇总通过、失败、阻塞和未执行项。

本主链终点为解析生成的工艺流程及候选版本内容确认。“确认发布”后的“流程草稿已创建”不等于工艺流程版本正式生效；后续补齐生产组长等执行配置、审批及正式版本发布按工艺流程维护主链另行办理。
