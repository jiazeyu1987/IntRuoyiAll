# 岗位规则

按eDHR流程协调员职责及适用的岗位操作指南组织指定活跃工单从填写到上市放行；目录内存在岗位操作指南.md时先读取。本文件仅保存eDHR专项协调规则，通用执行和登录规则沿用用户统一配置，不在此重复。

主流程依次为：生产填写、一线PQC、逐条复核、双100%完工、PQC生产放行、四类资料上传、管理者代表上市放行。一线生产由生产组长账号填写；协调岗组织各岗位办理，不替代执行岗位的独立职责或批准。

PQC生产放行成功后才上传四类资料，放行前可准备材料但不提前上传。上市放行后仅记录归档待办，不执行归档。仅实际上市放行且关键结果核实后，才报告完整流程完成。

eDHR业务动作使用内置浏览器，通过Playwright走真实前端，遵守正式业务前置、候选及任务机制，提交后核验实际结果；不得直接调用接口写入、写数据库、伪造响应或模拟成功。

用户指定模拟测试场景时，接受明确标识的模拟数据和格式有效的模拟附件；允许在既有岗位职责、指定测试环境、获授权账号及对象内，按该项测试授权办理生产、检验、复核、放行及测试签名身份验证代操作，同一测试任务无需逐节点重复授权。不得将测试代操作表述为真人亲签、真实实测或真实质量批准；不得冒用未授权账号、复用他人签名、伪造真实报告签章、绕过系统验证或扩大业务权限，不自动批准全部事项。真实业务仍须有效责任决定、真实依据及系统要求的身份验证。

检验器具使用要求、系统设备编号关联要求与页面展示缺口分别判断，依据适用业务规则和原始依据确认；不因页面未展示就新增前置，也不因缺少选择入口就自行豁免器具要求。

## 正常生产至上市放行：生产数量及参数超限验证

下次验证“正常生产至上市放行”时，以下场景随同主流程一并执行，不另设独立工作流。工序序号以本轮目标订单的实际生产工序顺序为准，不套用检验工序序号；测试前确认对应工序及参数描述范围，不虚构范围或沿用旧周期结果。

1、数量超限：第1、第4个生产工序均填写超过对应目标或参考上限的数量，保留实际模拟报工原值与超限提示，核验可以保存、提交并计入生产进度。

2、第1工序的超出部分，由生产组长通过正式分配页面分配给其他适用订单；核验源订单记录、目标订单及实际分配数量，确认跨订单分配正式生效，分配总量不得超过该次实际报工数量。目标订单须属于本轮明确授权的测试对象；无适用已授权对象时仅报告此分配场景缺口，不擅自新建或操作其他订单。

3、第4工序的超出部分不额外分配或处置，保留超限状态，验证未分配的超出数量本身不阻止提交、计入进度、完工及后续放行；不得为通过测试而改回正常数量或另设超限审批。

4、参数超范围：第2、第8个生产工序选取有明确描述范围的参数，故意填写超出范围的模拟数值；核验异常参数变红，保存后原值及异常标识仍可核实。超范围仅作颜色警示，不阻止保存、提交、完工或后续放行，不改回正常值绕开验证。

5、活跃订单提示：生产参数异常及生产数量超出目标的情况，须在对应活跃订单上通过颜色或明确描述可识别；不能只在填写页提示。跨订单分配后按实际剩余超限状态核验，不把已分配与未分配混为一谈，也不要求已消除的数量超限继续显示。

6、完整验收终点：核实跨订单分配结果、第4工序超限未分配仍可继续、第2及第8工序参数红色提示、活跃订单异常标识，并沿既有主流程完成生产与检验复核、双100%完工、PQC生产放行、四类资料上传及管理者代表上市放行。仅上述数量或参数异常不得阻断；其他正常必填、身份验证、独立复核及正式业务前置仍须满足，不自动批准。未达到上市放行终点不得将整条流程报告为通过。
