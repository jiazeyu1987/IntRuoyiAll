# 用户新增查询与资料维护主链

## 环境

执行前确认的服务器及对应租户（本地为测试1，其他服务器见00）；启动、命名、凭据及记录规则见00，先完成01中的edit账号准备。

## 参与账号

yingtaigroupadmin维护本轮edit员工；不操作公共员工，不给edit增加业务角色。

## 测试主链

1. 在用户管理按edit完整账号查询，核对实际用户编号、昵称、甲部门、本轮岗位、启用状态和空业务角色；把01新增保存和本次查询作为新增结果证据。
2. 分别按实际页面可用的用户名称、昵称和部门筛选查询，清除条件、刷新、翻页后仍能找到同一编号。无匹配条件使用“saRnotfound”，应显示无结果，不得拿列表未刷新当查询通过。
3. 打开edit行“编辑”，将昵称改为“主链Redit2”、归属部门改为乙、本轮岗位保持不变、备注改为“运行R：用户资料维护”；确认影响后保存。回查列表和编辑表单实际值，角色仍为空。
4. 点击“高级 → 新增”，用edit同一账号和不同昵称提交一次，密码按P0，核对重复账号被拒绝、原用户编号和资料不变，没有新增同名账号。
5. 另开新增表单，账号拟填saRinvalid，逐项验证缺少用户名、昵称等页面必填信息时无法提交。记录实际验证字段，取消表单后查询该账号不存在。
6. 再打开edit编辑，将昵称或部门作临时修改后取消，刷新核对保存值仍为第3步结果。保留edit在乙部门供03使用，记录最终资料和角色，不删除。
