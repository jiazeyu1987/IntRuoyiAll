## 主审退回并补正的具体问题

1. CE 类型必须从详情 factsJson 获取；详情不存在可直接使用的 certificateType 属性。
2. 详情版本状态是 CURRENT；用 ACTIVE 判断会使支持材料入口一直不显示。
3. 上传 API 返回 CommonResult，必须解包 data；业务文件 Mapper 注入不得与 infra 文件 Mapper 混淆。
4. CE 续证不能把 SUSPENDED 等原事实状态强行改为 VALID；不能把初次获证日和 Rev 签发日混用。
5. 国内受托企业不能只提交文本名；远程搜索必须保留已选项。取消选择的变更不能偷偷提交。
6. CE 型号数组必须同步到列表投影、详情及履历，不只保存在 JSON 中。
7. 支持材料上传后，必须继续核对详情列表、预览引用、下载申请、下载授权及实际交付；校验材料记录与文件、租户、证书、版本及类型对应关系，不能只检查上传成功。
