# 20260615 展厅奖项导出回导真实 E2E

## 任务目标

使用本机测试租户 `测试租户/aoteman` 通过真实浏览器路径验证：产品管理导出的 `产品资料修改版-补充产品资料.xlsx` 可直接再次导入，且导入前后奖项数据保持一致。

## 经验门禁

- 登录与真实 E2E：先确认本机入口 `http://localhost:8081`，写入型 E2E 使用 `测试租户/aoteman`。
- 登录失败必须记录实际租户、账号、入口和失败位置，不得静默切换租户、账号或环境。
- 长链路前先验证登录到目标页面的最小路径。
- Playwright 操作真实前端页面；API 仅用于最终数据一致性核验。
- 不操作测试服、备份服或正式服。

## 设计约束检查

- `是否引入 fallback/降级/吞异常`：否；登录、导出、导入或数据对比失败均直接失败。
- `是否从根因和长期维护角度解决`：是；按真实用户路径验证导出文件回导合同。
- `是否存在临时补丁或绕过`：否。

## BDD 场景

- BDD: 导出后回导奖项一致 -> Given 测试租户存在可导出的奖项并具备封面 / When 用户在产品管理导出 Excel 后直接导入同一文件 / Then 导入结果识别奖项且导入前后奖项关键字段一致。

## 里程碑

1. M1 前置检查：确认本机前后端可访问、Playwright 可用、登录租户和账号有效。
2. M2 RED/GREEN：执行真实浏览器导出、同文件导入和最终 API 对比。
3. M3 收尾：记录证据、必要时提交 E2E 脚本和任务文档。
