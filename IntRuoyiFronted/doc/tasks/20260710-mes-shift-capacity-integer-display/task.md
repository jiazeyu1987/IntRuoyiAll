# 排产工作台班次产能整数显示

## 任务目标
- 修复排产员工作台“工序列表”中班次产能展示浮点误差小数的问题。
- 班次产能按整数四舍五入并保留千分位，例如 `4799.99998` 显示为 `4,800`。
- 仅调整班次产能列，不改变后端计算、接口值及其他允许小数的数量列。
