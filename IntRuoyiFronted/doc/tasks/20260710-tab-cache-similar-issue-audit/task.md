# 页签缓存同类问题审计

## Task Goal

审计前端其他详情页或多页签页面是否存在与批次详情相同的“切走再切回重复加载”风险，并给出明确范围和优先级，不在本任务中直接扩大修改。

## 经验门禁

- PowerShell 与中文文件读写显式使用 UTF-8，不使用 `&&`。
- 审计以真实路由配置、keep-alive 规则和组件 watcher/lifecycle 为准，不凭页面名称推断。
- 区分合理的首次加载、参数变化加载与标签返回重复加载。
- 不引入 fallback，不修改未获批准的其他页面。

## 设计约束检查

- 是否引入 fallback/降级/吞异常：否。
- 是否从根因和长期维护角度解决：是；按路由缓存与组件生命周期组合识别同类风险。
- 是否存在临时补丁或绕过：否。

## Milestones

- [x] M1：建立审计任务与判定标准。
- [x] M2：扫描路由缓存配置和详情组件生命周期。

## Expected Verification

- 列出 `noCache: true` 且页面含 `onMounted(load)` 或路由 watcher 的详情路由。
- 列出已缓存但 watcher 会在离开/返回时重复加载的页面。
- 对高风险候选读取具体路由块和组件代码，避免仅凭正则误报。
- 输出明确的“已确认、疑似、无同类问题”结论。
