# eDHR 执行列表未归档提示修复任务

## 目标

进入 `eDHR执行列表` 时，未生成单张批记录归档的执行记录应显示为“未归档”，不应弹出“批记录执行归档不存在”错误提示。

## 里程碑

- [x] RED：确认最新归档查询接口会经过全局 Axios 错误提示，导致“归档不存在”先被弹出。
- [x] GREEN：让最新归档查询请求忽略全局错误提示，由页面逻辑将该业务结果显示为“未归档”。
- [x] REGRESSION：运行类型检查，并用真实页面验证进入执行列表不再弹“批记录执行归档不存在”。

## 预期验证

- `$env:NODE_OPTIONS='--max-old-space-size=8192'; pnpm ts:check` 通过。
- Playwright 打开 `eDHR执行列表`，页面存在未归档记录时不出现“批记录执行归档不存在”弹窗，列表归档状态显示“未归档”。

## 设计约束检查

- `是否引入 fallback/降级/吞异常`：否。未归档是业务状态，由列表显式展示为“未归档”。
- `是否从根因和长期维护角度解决`：是，修正接口调用的错误提示归属，避免全局拦截器误弹业务状态。
- `是否存在临时补丁或绕过`：否。

## 当前状态

已完成。进入 eDHR 执行列表时未归档记录显示“未归档”，不再弹出归档不存在错误。
