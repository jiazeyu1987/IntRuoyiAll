# 任务：运行控制台真实备份恢复回滚 E2E

## 任务目标

- 新增或复用显式授权才可运行的真实 E2E，用页面完成测试服 `立即备份`、`恢复数据`、`回滚版本` 全链路。
- E2E 必须走真实登录、按钮点击、原因填写、确认执行、在线日志轮询和最终健康检查。
- 流程使用测试服真实数据，不使用 mock，不触碰正式服。

## BDD 场景

- BDD: 测试服备份恢复回滚全链路成功 -> Given 本机运行控制台可访问且 admin 拥有运维权限, When 用户依次点击 `立即备份`、`恢复数据`、`回滚版本` 并填写原因确认执行, Then 每个运行操作都成功完成，日志可在线查看，测试服健康检查通过，恢复使用真实备份数据，回滚后应用服务可访问。
- BDD: 修复后从测试服前端完成 DR 链路 -> Given 测试服后端已接入 Linux native DR 脚本, When E2E 从测试服前端依次提交 `立即备份`、`恢复数据`、`回滚版本`, Then 三个操作均成功并通过测试服健康检查。

## 里程碑

- [x] M1: 确认现有运行控制台 E2E helper 可覆盖三步动作。
- [x] M2: 实现真实 DR E2E 流程。
- [x] M3: 用授权环境变量执行真实三步流程。
- [x] M4: 记录操作 ID、日志结果和测试服健康检查。

## 预期验证

- RED：新增 E2E 前缺少完整备份、恢复、回滚真实测试文件。
- GREEN：`RUNTIME_CONTROL_ALLOW_REAL_DR=1` 执行 E2E 通过。
- GREEN：三个运行操作都返回 `succeeded`。
- GREEN：测试服后端、管理端前端和 Website 健康检查通过。
