# eDHR 页签缓存一致性修复

## Task Goal

修复审计确认的 8 个 eDHR 页面在页签切走再返回时重复加载的问题，统一启用页面缓存，并为存在路由参数 watcher 的页面增加当前路由与已加载标识防重。

## Scope

- eDHR 执行表单
- 主数据追溯详情
- 字段审计详情
- eDHR 操作审计
- eDHR 审批详情
- eDHR 批次复盘
- 历史批记录
- DHR 模板目录

## 经验门禁

- PowerShell 与中文文件读写显式使用 UTF-8，不使用 `&&`。
- 所有行为修改先写 BDD 与失败回归测试，再执行最小修复。
- 不修改后端接口、权限、业务状态或页面视觉结构。
- 不对审计中可能有意禁用缓存的其他 14 个模块页面扩大修改。
- 页面参数实际变化时必须继续加载新数据；同一路由同一标识返回时不得加载。
- 不引入 fallback、静默吞错或默认成功。
