# 任务：清理电子批记录报表名称前缀

## 任务目标

清理报表设计器中电子批记录报表名称开头的 `电子批记录[A]-表x-` 前缀；仅处理确实匹配该前缀的记录，保留其余报表名称不变。

## 范围边界

- 作用对象为 `jimu_report` 中未删除的电子批记录报表名称。
- 仅移除名称开头形如 `电子批记录[A]-表1-`、`电子批记录[A]-表12-` 的前缀。
- 不修改报表编码、报表内容、路线绑定、工序、产品或资源配置。
- 不使用默认名称、占位名称或静默跳过失败。

## 设计约束检查

- `是否引入 fallback/降级/吞异常`：否。

- `是否存在临时补丁或绕过`：否。
