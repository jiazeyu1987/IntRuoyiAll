# 任务：运行控制台真实提升正式服链路验证

## 任务目标

- 使用 Playwright 通过真实前端路径点击运行控制台的“提升正式服”按钮。
- 使用真实测试服和正式服环境验证默认“只发代码”提升正式服链路是否正确完成。
- 验证正式服提升后后端、管理端前端、Website 静态资源可访问，并确认运行控制台操作日志记录成功。

## 前序任务检查

- 后端上一任务 `20260525-dcc-nas-active-task-stuck` 状态为 `completed`，无阻塞。

## BDD 场景

- BDD: 默认只发代码提升正式服成功 -> Given 运维人员在测试服运行控制台打开“提升正式服”弹窗, When 默认选择“只发代码”、填写原因并输入 `PROD` 后确认执行, Then 系统应提交 `promote-prod` 动作，参数包含 `publishScope=code-only`，发布脚本应跳过数据库与 MinIO 同步，正式服服务健康检查返回成功。
- BDD: 正式服提升后前端闭环到正式后端 -> Given 提升正式服完成, When 访问正式环境管理端登录页并执行真实登录, Then 登录请求应闭环到正式后端，不能继续指向测试后端。
- BDD: 操作日志可追溯 -> Given 提升正式服动作完成, When 在运行控制台查看最近操作和日志, Then 最近操作应显示“提升正式服”“只发代码”和成功状态，日志可打开并包含发布完成证据。
