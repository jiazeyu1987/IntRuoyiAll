# 排产闭环与 eDHR 边界开发计划执行日志

- BDD: 排产工单承接排产决策 -> Given ERP 同步生产工单已存在 / When 排产员选择生产工单并填写承诺交期 / Then 系统生成唯一排产工单，排产数量等于生产工单数量，ERP 后续变更只生成差异提示。
