# 任务：确认芋道源码 admin 下 eDHR 产品主数据

## 任务目标

在 `芋道源码/admin` 范围内检查 MES 主产品/物料主数据是否存在 `冠状动脉棘突球囊扩张导管`；如果确实不存在，再按正式主数据要求新建产品记录。

## 范围边界

- 本任务按用户最新要求作用于 `芋道源码/admin`。
- 先做只读存在性检查；已有同名产品时不新建重复记录。
- 不绑定工艺路线、不修改批记录报表、不创建 eDHR 执行记录。
- 不使用 mock、占位产品、默认规格、默认单位或默认成功值。

## 设计约束检查

- `是否引入 fallback/降级/吞异常`：否。
- `是否从根因和长期维护角度解决`：是。先确认主产品是否已存在，避免重复产品污染后续路线和 eDHR 绑定。
- `是否存在临时补丁或绕过`：否。

## BDD 场景

- BDD: admin 产品主数据存在性检查 -> Given 用户要求在 `芋道源码/admin` 下确认产品主数据 / When 按产品名称查询 MES 主产品/物料主数据 / Then 如果已存在启用产品记录，不创建重复产品。
- BDD: admin 缺失时新建产品主数据 -> Given `芋道源码/admin` 下产品主数据确实缺失 / When 创建正式产品主数据 / Then 必须按确定的编码、规格、单位、产品类型创建，且可查询到启用记录。

## 里程碑

- [x] M1：确认 `芋道源码` 租户 ID 和 admin 操作范围。
- [x] M2：查询 admin 范围产品主数据和产品类型。
- [x] M3：如缺失则新建；如已存在则停止写入并记录结果。

## 预期验证

- 查询 `system_tenant` 确认 `芋道源码` 租户 ID。
- 查询 `mes_md_item_type` 确认 admin 产品分类。
- 查询 `mes_md_item` 确认 `冠状动脉棘突球囊扩张导管` 是否存在。
- 若执行新增，必须再次查询新记录并记录新增主键；若未新增，记录不写入原因。
