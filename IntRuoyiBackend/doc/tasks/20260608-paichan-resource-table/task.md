# MES 产品工艺资源大表

## 任务目标

在 `paichan` 独立 worktree 内，将 `芋道源码/admin` 的相关 MES 路线、产品、工序、设备、工位与产能数据覆盖到 `测试租户/aoteman`，并在测试租户实现一个前端聚合操作大表。大表仅用于方便前端操作，底层仍然使用现有产品、路线、工序、设备、工位、设备绑定与人员绑定表，不新增另一套业务关系。

## 里程碑

1. 创建任务文档、需求、计划与测试计划。
2. 将 admin 相关 MES 基础数据覆盖到测试租户，并记录覆盖前后校验。
3. 后端新增产品工艺资源聚合查询与保存能力，保存仍写入现有底层表。
4. 前端新增/调整产品工艺资源大表页面，按统一生产列表风格展示和编辑。
5. 使用 Playwright 登录测试租户执行真实 E2E 验证。
6. 更新任务文档、清理临时产物并提交本任务改动。

## 预期验证

- 后端单元/集成测试覆盖聚合行、设备产能、人工人数与保存规则。
- 数据库校验确认测试租户已获得 admin 的相关 MES 数据，且 admin 数据未被修改。
- 前端构建或类型检查通过。
- Playwright 通过 `http://localhost:8081` 登录 `测试租户/aoteman`，在真实页面查看并操作大表。

## 当前状态

已完成：测试租户 MES 相关数据已覆盖并校验；后端已提供产品工艺资源聚合查询与保存接口；前端已在 MES 工艺路线页面增加“资源大表”操作视图；真实 Playwright E2E 已登录 `测试租户/aoteman` 完成查看、人工人数编辑/恢复与同设备同工序产能一致性校验。

- `是否从根因和长期维护角度解决`：是。大表作为现有数据模型的聚合操作层，避免继续手填产品差异产能，同时保留底层路线、工序、设备、工位关系。
- `是否存在临时补丁或绕过`：否。
