# DCC 批量识别运行态控制

## 任务目标
- 在本机实现 DCC 受控浏览前端可查看当前 Codex/worker 运行状态。
- 支持前端停止/开始批量识别任务。
- 支持前端查看共享识别记录账本当前已记录文件数量。

## 经验门禁
- PowerShell 命令先读取 docs/powershell-memory.md，并显式 UTF-8。
- 本轮仅做本机代码与测试，不操作测试服/正式服。
- 功能变更采用 BDD + 严格 TDD，先记录 Given/When/Then 与 RED/GREEN 证据。
- 涉及 SQL/脚本/迁移时补 script/tests 门禁；本轮优先复用已有任务表，不新增 schema，除非实现发现正式字段缺口。

## 设计约束检查
- 是否引入 fallback/降级/吞异常：否。
- 是否从根因和长期维护角度解决：是，使用任务状态 + 运行 worker 状态快照 + 账本统计接口，不用前端假状态。
- 是否存在临时补丁或绕过：否。
