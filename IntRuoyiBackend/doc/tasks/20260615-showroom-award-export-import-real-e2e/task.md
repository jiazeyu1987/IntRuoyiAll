# 展厅奖项导出回导一致性修复

## 任务目标

真实数据 E2E 已确认：测试租户从产品管理导出包含奖项页签的 Excel 后直接回导，奖项数据必须保持一致。当前失败点是奖项封面会被重新上传为新 URL，且 Excel 未携带的英文名/讲解等编辑字段会被清空。本任务修复后端奖项导入逻辑，保证导出文件回导不破坏已有奖项数据。

## 经验门禁

- 本机修改优先，不操作正式服或测试服远程环境。
- 严格无 fallback：缺少奖项页签、奖项中文名、奖项序号、奖项封面或现有封面不可读取时必须明确失败。
- E2E 使用真实用户路径，API 仅用于最终校验；本后端修复需服务于该真实 E2E。
- 不修改受保护的 `infra_file_config.id=28` 配置，不改写默认展厅媒体域。

## 设计约束检查

- 是否引入 fallback/降级/吞异常：否。
- 是否从根因和长期维护角度解决：是，导入同一奖项时保留 Excel 未管理字段，并复用内容一致的现有封面 URL。
- 是否存在临时补丁或绕过：否。

## 里程碑

1. 记录真实 E2E 失败证据，补充 BDD/TDD 文档。
2. 新增后端回归测试，覆盖奖项导出回导保留英文名/讲解/封面 URL。
3. 修复奖项导入逻辑。
4. 运行后端定向测试与真实 E2E 回归。
