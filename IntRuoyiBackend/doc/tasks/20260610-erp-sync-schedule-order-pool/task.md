# 20260610 ERP 生产订单同步与排产工单池完善

## 任务目标

在独立 worktree `erp_sync_schedule_order` 中先完成排产目标 1 和目标 2：

- ERP 生产订单按工单编码作为唯一键同步进 MES 生产工单，每天凌晨 2 点同步最近一年未完成工单。
- 排产员从 ERP 生产工单生成排产工单并填写承诺交期，排产数量必须等于生产工单数量，排产工单不允许拆分。
- ERP 后续变化不直接修改排产工单，只形成差异提示，由排产员手动更新排产工单。
- 验证成功后融合回 `int_main`，并在合并结果上做回归。

## 范围

### 本期必须完成

1. 梳理并复用现有生产工单、金蝶/ERP 同步、排产工单池、排产差异表与菜单能力。
2. ERP 同步规则：
   - 唯一键：ERP 工单编码 / 本地生产工单编码。
   - 同步窗口：当前日期往前一年到当前日期，且 ERP 状态为未完成。
   - 每天凌晨 2 点自动执行。
   - ERP 只同步生产订单基础信息，不包含承诺交期。
   - 已存在生产工单只更新生产订单基础信息。
   - ERP 状态只识别已完成 / 未完成，其他状态不参与业务判断。
3. 排产工单池规则：
   - 从生产工单生成排产工单时必须填写承诺交期。
   - 排产数量必须等于生产工单数量。
   - 一个生产工单只能生成一个排产工单，不允许拆分。
   - 排产工单编号使用清晰格式。
   - 生产工单变化后，排产工单不自动更新，只产生差异提示。
4. 测试与验证：
   - BDD 场景先行。
   - 严格 TDD：RED -> GREEN -> REGRESSION。
   - 本机测试租户真实 E2E，不修改 `芋道源码/admin` 数据。
   - 合并回 `int_main` 后再次验证。
