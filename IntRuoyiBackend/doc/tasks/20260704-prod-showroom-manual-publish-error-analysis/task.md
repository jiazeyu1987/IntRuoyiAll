## 里程碑

- 是否存在临时补丁或绕过：否。
## 分析结论

正式服手动发布展厅报“系统异常”的直接原因是展厅 release 组装阶段发现 `hall_01` 的展项映射（正式库表 showroom_hall_item）缺少画布布局字段，触发严格校验失败：`SHOWROOM_REQUIRED_FIELD_MISSING: hall canvas layout is required`。这不是前端按钮问题，也不是 release readback 失败。
## 修复建议

- 一次性补齐正式服所有 `showroom_hall_item` 的 `layout_x/layout_y/layout_width/layout_height`，布局必须覆盖完整画布且不重叠。
- 在展柜管理/手动发布入口增加前置可读校验，直接提示缺布局的展柜和映射行。
- 另行处理自动发布 scope 配置缺失，避免定时任务持续报错。
