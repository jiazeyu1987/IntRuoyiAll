# 任务：复制芋道源码租户数据到瑛泰医疗租户

## 任务目标

- 将源租户 `芋道源码` 的租户内数据复制到目标租户 `瑛泰医疗`。
- 复制前必须确认执行环境、源/目标租户编号、受影响表范围、目标已有数据处理策略与回滚/恢复方案。
- 复制过程不得修改源租户数据；目标租户写入必须在用户确认后执行。

## 维护性与安全评估

- 本任务属于真实租户数据变更，默认不做隐式 fallback，不静默跳过冲突表，不用 mock 或默认成功掩盖失败。
- 优先采用可审计的数据复制脚本或事务化 SQL，复制前后保留表级计数和冲突检查证据。
- 对唯一键冲突、外键依赖、主键重映射、目标租户已有数据、备份/回滚方案不明确的情况直接阻塞。
