# 旧工序 ID 系统性消除

## Task Goal

从根因修复 MES 实时业务链路对易变 `process_id` 的直接依赖，使报工导入、普通报工、审批、物料消耗、IPQC、工位资源与计划实际日报能够正确识别历史工序与当前路线工序的同一业务身份；对无法唯一识别的情况明确失败，不静默跳过。

## Milestones

1. 建立统一工序身份解析规则和严格测试。
2. 修复报工创建、导入和审批链路。
3. 修复路线 BOM、物料消耗、IPQC、工位与资源链路。
4. 修复计划实际日报的稳定关联键。
5. 增加旧工序引用一致性门禁并完成回归验证。
6. 提交、合并、清理并完成任务收尾。
