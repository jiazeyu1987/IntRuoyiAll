# DCC 截图需求测试数据计划

## Purpose and Scope

本文定义 DCC 截图 14 条需求的真实测试数据。所有数据必须写入测试租户，不得修改芋道源码租户生产基线数据，不得使用 mock 数据或备份数据替代真实测试环境。测试数据只服务验收计划，后续实现和 E2E 应按本文准备、核验和清理。

## Reset Procedure

1. 仅清理测试租户中带 `DCC-E2E`、`dcc_.*_e2e` 或本计划明确编号的数据。
2. 清理顺序：下载记录、发放记录、培训记录、签核记录、流程实例、受控文件版本、文件 master、模板、目录、路线、岗位绑定、测试用户。
3. 不清理生产租户、芋道源码租户或未带测试标识的真实业务数据。
4. 文件下载、导出、打印产物只保存在 E2E 临时目录，测试结束后删除。
5. 如果清理脚本发现数据不带测试标识，应停止并报告，不得扩大删除范围。

## Data Ownership

- Worker-A 负责后端测试数据 schema、Mapper fixture、服务级真实数据准备脚本和清理脚本。
- Worker-B 负责前端静态测试所需的最小源码样例，不创建 mock 业务数据。
- Worker-D 负责 E2E 运行前检查真实测试租户数据是否存在，运行后清理下载产物。
- Reviewer 负责确认测试数据没有污染芋道源码租户、没有绕过真实权限、没有使用 mock 数据。

## Test Blockers

- 测试租户账号和权限未准备：阻塞全部真实路径 E2E。
- 四节点审批路线、第四节点文控角色和会签节点选择规则未准备：阻塞 R05、R09、R13、R14。
- 文件类别和目录绑定未准备：阻塞 R01、R06、R08。
- `INT/RE` 完整编码规则未确认：阻塞 CF04 和 R08。
- 密码强制更新周期未确认：阻塞 PW05 和 R02 周期更新。
- Word 模板占位符未确认：阻塞 F08 和 R12 成功路径。
- 外来文件评审完整业务定义缺失：阻塞 EXT01 和 R07。
