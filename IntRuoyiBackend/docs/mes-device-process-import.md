# 设备产能与工序设备关系导入格式

适用于设备产能同步 `/mes/dv/machinery/sync-final-sheet` 和工作站关系同步 `/mes/md/workstation/import-balloon-process-device-mapping`。两处共用 `Sheet1` 解析器。

## Sheet1 列顺序

| 列 | 表头 | 说明 |
|---|---|---|
| A | 产品名称 | 沿用现有格式 |
| B | 物料编码 | 沿用现有格式 |
| C | 设备编码 | 设备行必填；纯人工行填 `/` |
| D | 工序名称 | 用于展示及核对，必须与编码对应的工序名称一致 |
| E | 设备名称 | 设备行必填 |
| F | 设备数量 | 设备行填写正数；工作站同步要求正整数 |
| G | 10.5小时日产能 | 设备行填写正数，换算为单台标准小时产能 |
| H | 人工 | 纯人工行填写正数，沿用现有换算规则 |
| I | 工序唯一编码 | 新增必填列，填写工序管理中的正式“工序编码”（`mes_pro_process.code`） |

设备行和有效人工行都必须填写工序唯一编码。设备编码为 `/` 且没有人工产能的占位行仍不导入。

## 关联和核对规则

- 只按当前租户内的工序编码定位，不按名称、产品名称、已有设备关系或工作站归属猜测。
- 编码不存在、未启用、对应多条工序，或名称不一致，拒绝整批导入并指出问题；不按名称补齐编码。
- 同名但不同编码的工序可以分别导入。设备产能按“设备＋具体工序”分别保存，互不覆盖。
- 同一设备、同一工序编码的来源行必须符合原有产能一致性规则；不同工序编码不因同名而合并。
- 工作站关系同步只绑定文件明确指定的工序，仍要求设备工序产能明细已存在。

旧文件需要增加 I 列后才能使用。此次格式调整不迁移已有产能关联，也不自动为同名工序复制产能。设备产能同步仍保留原有全量替换行为，工作站关系同步仍保留原有绑定更新范围。
