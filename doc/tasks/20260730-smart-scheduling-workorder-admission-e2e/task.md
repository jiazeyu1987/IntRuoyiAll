- Playwright 必须操作真实前端页面；API 仅可用于最终只读核验。
- Element Plus 表格必须按可见业务唯一文本定位行，确认前断言选中集合无额外工单。
- 写入型 E2E 必须完成页面清理闭环，不得用 API 或 SQL 写入替代删除。
