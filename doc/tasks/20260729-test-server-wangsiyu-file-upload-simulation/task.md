## Authorization And Scope

- 目标环境：测试服务器。
- 前端入口：`http://172.30.30.58:8081/`。
- 账号来源：用户在当前任务中明确提供的 `wangsiyu` 测试账号。
- 操作类型：真实页面登录与一次文件上传。
- 数据影响：仅创建本任务可追踪的测试上传记录或附件。
- 任务日期：`2026-07-29`。
- 清理方式：优先通过产品页面删除任务自有测试数据；若页面不提供删除入口，则记录实际生成的数据标识和保留影响，不使用 API、SQL 或服务器命令绕过清理。

## Applicable Gates

- 真实 E2E 必须使用 Playwright 操作测试服务器前端，API 只能用于最终只读核验。
- `setInputFiles` 后必须看到目标文件名进入可见上传列表，或确认目标上传请求已触发；否则停止，不得用 API-only 上传替代。
- DCC 文件上传入口必须只允许选择当前账号具备类别级 `UPLOAD` 权限的文件类别；若无可上传类别则停止。
- 登录失败、账号无权限、目标上传入口不存在、文件类型要求无法满足或测试数据无法安全落地时 fail fast。
- 密码只在浏览器交互中使用，不写入任务文档、日志、证据文件或命令记录。
