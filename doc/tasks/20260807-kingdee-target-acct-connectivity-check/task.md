## 预期验证

- 当前运行配置能够提供非空 `baseUrl`、用户名、密码和 `lcid`，敏感值不输出到日志。
- 目标账套登录接口返回 HTTP 成功状态、金蝶登录成功状态，并返回会话 Cookie。
- 不保存目标账套配置，不调用 `ExecuteBillQuery`、`Save`、`Submit` 等业务接口。
