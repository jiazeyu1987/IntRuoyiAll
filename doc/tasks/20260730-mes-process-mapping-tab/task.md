# MES 工序映射页签

## Task Goal

在现有 MES 生产菜单中，在“工序设置”和“工艺流程”之间新增同级“MES 工序”入口；同时保留工艺路线编辑页内部的只读“MES 工序”页签，用列表展示 MES 一线报工工序、设备与工序设置主数据的对应关系，尽量复用现有工序设置、设备、工艺流程和报工系统，不另起独立系统。

## Thread Notes

- 一线入口仍是“报工”，同时作为记录本入口；员工点击提交后，既生成报工信息，也写入记录本/批记录相关原始数据。
- 一线员工只填当前工序所需的简单数据：上一个工序输入数量、设备参数、输出数量、损耗数量；PQC 简化为检测成功/失败。
- 员工填写时间默认取提交时间，不手填；实际生产滚动并行，工艺路线可配置但一线填写不按路线限制。
- 原始记录不限制填写，审核时生成最接近限制的副本；原始值和修正值都保留，原始提交后修改需要日志。
- FIFO 订单按生产工单计划开始时间排序；本次不考虑排产系统，只考虑生产工单。
- 员工 UI 固定几类模板；账号可限制可切换工序，员工只能切换绑定对应工序的人员，切换员工时 UI 同步切换。
- `压力泵工序.xlsx` 的“二代压力泵”中，“工序名称”是展示给一线员工看的 MES 工序名称，“批记录工序名称”是对外批记录名称，“设备编码”可能包含多台设备。

## Milestones

1. 识别现有工艺路线编辑页、工序设置列表、设备关联接口和前端数据结构。
2. 新增工艺路线编辑页内部 MES 工序页签，展示 MES 工序与工序设置/设备对应关系。
3. 根据用户反馈补同级“MES 工序”菜单页面，位于“工序设置”和“工艺流程”之间。
4. 增加最小静态验证，锁定页签/菜单顺序、列表列名和数据来源。
5. 运行定向验证，记录剩余阻塞。

## Expected Verification

- 前端静态合同：新增编辑页页签位于“基础信息”和“流转关系图”之间。
- 前端静态合同：新增同级菜单页面 `MES工序` 使用组件 `mes/pro/mes-process/index`，菜单排序为“工序设置 20 / MES工序 25 / 工艺流程 30”。
- 前后端权限合同：新增同级菜单包含独立查询权限 `mes:pro-mes-process:query`，资源读模型接口允许该权限，避免菜单可见但接口 403。

- 定向类型检查或可替代静态检查可证明新增 API 类型和页面引用无语法级断裂。
