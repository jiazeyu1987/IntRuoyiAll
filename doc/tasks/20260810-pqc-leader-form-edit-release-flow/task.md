# PQC 组长表单修改与放行流转

## Task Goal

按用户确认的 7 条规则调整 PQC 组长工作台：

- PQC 组长可修改 PQC 组员提交的数据。
- PQC 当前表单列表中“修改”和“复核”按钮常驻。
- PQC 历史中保留记录。
- 复核通过更新活跃订单审核进度。
- 活跃订单放行前，PQC 表单数据都可修改。
- 活跃订单放行后，从 PQC 当前表单列表移除。
- 放行后仍保留在 PQC 历史里。
