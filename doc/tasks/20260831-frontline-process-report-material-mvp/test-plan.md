# Test Plan

## Database RED/GREEN

- 新增迁移静态测试，锁定 `mes_pro_feedback_material`、租户字段、唯一键和索引，并禁止复制 ERP 批号字段。
- 运行 migration policy gate，确认迁移可进入本地/测试/生产标准流程。
- 数据安全：仅新增表，不修改或回填既有正式报工；应用回滚后保留表中事实。

## Backend RED/GREEN

- 冻结物料解析：成功、缺配置、重复物料、错误产品、错误工序、旧版本冻结。
- 运行态与会话快照：返回相同物料集合，提交篡改或缺少任一物料时拒绝。
- 正式提交：全部物料一次成功；一个明细失败整事务回滚；幂等重试不重复插入。
- 进度数量：覆盖不同完成数量直接取最小值以及最小值为 `0`。
- 同步批号读取：单批号、多批号去重、空数据、其它订单/物料隔离，禁止库存表或 ERP 网络路径。

## Frontend RED/GREEN

- 运行态类型包含物料集合。
- 红框区域按冻结物料渲染页签。
- 初始灰色、明确填写绿色、`0` 绿色、清空灰色。
- 损耗和参数改变不影响颜色。
- 切换页签保持两套独立草稿。
- 正式提交只发一次且 `materialDetails` 覆盖全部配置物料。
- 缺完成数量提示具体物料且不发请求。

## Real E2E

- 启动服务前读取本机运行规则并预留 worktree slot。
- 使用真实测试租户、活跃订单、冻结路线产品 BOM、两种物料和一线生产账号。
- 通过页面切换两个物料、填写不同数量、核对灰绿状态和网络请求。
- 正式写入必须使用任务自有数据；批号只验证系统内同步表读取，不执行 ERP 外部联调。
