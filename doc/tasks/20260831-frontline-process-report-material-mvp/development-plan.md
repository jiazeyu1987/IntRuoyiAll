# Development Plan

## M1 冻结工序物料运行态

- 为冻结路线产品 BOM 解析写后端 RED。
- 实现精确物料解析并加入运行态和会话快照。
- 验证旧订单使用旧版本，新订单使用新版本，缺配置明确失败。

## M2 多物料正式提交与持久化

- 为迁移和子表写 schema RED。
- 为完整集合、缺明细、重复物料和事务回滚写后端 RED。
- 实现迁移、DO/Mapper、请求/响应和同事务持久化。
- 按用户确认规则计算单一工序进度。

## M3 一线生产物料页签

- 为页签来源、灰绿状态、`0`、清空、草稿隔离和一次请求写前端 RED。
- 实现物料草稿和页签交互，不改动其它页面视觉结构。
- 运行类型检查和相邻一线提交合同。

## M4 系统同步批号读取

- 为生产订单号 + 物料编码读取同步领料单批号写 RED。
- 实现全部非空批号去重只读查询；无数据返回空集合。
- 不直连 ERP、不写回同步表、不读取缺订单身份的库存表。

## M5 验证、提交和融合

- 运行迁移、后端、前端和真实页面验证。
- 运行 evidence validators、branch runtime guard 和差异检查。
- 收尾后提交任务代码；融合前计算分支实际增量与 `int_main` 脏文件交集。
- 无交集时在主工作区执行 `git merge --ff-only`；有交集时创建从最新 `int_main` 出发的干净集成 worktree，选择性移植任务提交并验证后再快进融合。
