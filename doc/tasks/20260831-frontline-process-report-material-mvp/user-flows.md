# 工序多物料一线报工用户流程

## Purpose and Scope

本文描述工艺路线维护人员配置工序物料、一线生产人员按物料填写并统一提交、以及系统同步批号只读展示的用户流程。

## Evidence Reviewed

- 用户提供的粗洗记录表和一线生产页面截图。
- 用户确认的灰绿页签、完成数量触发和统一正式提交规则。
- 现有工艺路线产品 BOM 按工序配置页面。
- 现有一线生产完成数量、损耗、不良明细、设备参数和正式提交页面。
- 现有订单冻结路线与一线正式提交规则。

## Primary User Flows

### Flow 1：配置粗洗工序的报工物料

1. 工艺路线维护人员进入目标工艺路线。
2. 创建或打开可编辑的候选版本。
3. 进入“产品配置”，编辑目标产品。
4. 在“产品 BOM 配置”中选择“粗洗工序”页签。
5. 添加弹簧和杠杆两种 BOM 物料。
6. 保存候选版本并完成既有路线发布流程。
7. 新进入执行的生产订单冻结该版本中的粗洗物料配置。

结果：弹簧和杠杆成为该产品粗洗工序的一线报工物料，不另建第二份物料清单。

### Flow 2：一线人员填写多个物料

1. 一线生产人员进入目标订单的粗洗工序。
2. 页面从订单冻结路线版本读取粗洗报工物料。
3. 红框物料区域显示“弹簧”和“杠杆”两个页签，初始均为灰色。
4. 页面默认选中第一个物料。
5. 人员填写弹簧的完成数量；弹簧页签立即变绿。
6. 人员继续填写弹簧的损耗、不良明细和对应参数。
7. 人员点击杠杆页签，页面切换到杠杆的独立填写内容。
8. 人员填写杠杆的完成数量；杠杆页签立即变绿。
9. 人员继续填写杠杆的损耗、不良明细和对应参数。
10. 人员可以往返切换两个页签，已填内容保持不变。

结果：两个物料形成同一工序填写会话中的两套独立数据。

### Flow 3：一次正式提交全部物料

1. 一线人员点击页面唯一的“正式提交”。
2. 系统确认所有配置物料都已明确填写完成数量。
3. 系统进入现有确认与电子签名流程。
4. 用户确认后，页面只发送一次正式提交请求。
5. 请求包含本次粗洗公共信息，以及弹簧、杠杆两条物料明细。
6. 系统整体保存本次工序报工及两条物料明细。
7. 系统取两条物料完成数量最小值作为工序进度。
8. 明确成功后，页面显示正式提交成功并结束本次填写会话。

结果：弹簧和杠杆属于同一次粗洗正式提交，不能形成互不关联的两笔页面提交。

### Flow 4：读取系统同步批号

1. 系统每日既有任务把 ERP 生产领料单及明细同步到本地表。
2. 用户查看报工物料详情时，系统取得生产工单编号和物料编码。
3. 系统只读匹配同步领料单明细的非空批号。
4. 页面展示全部去重批号；没有匹配数据时保持空白。

结果：本功能不直连 ERP、不写回同步表，也不要求一线人员填写批号。

## Alternate Flows

### 只有一个报工物料

页面显示一个页签。完成数量填写后由灰变绿，点击“正式提交”仍按一次工序提交处理。

### 完成数量为零

用户明确输入 `0` 后，页签变绿。页面初始空值不自动显示为已填写。

### 清空完成数量

用户清空完成数量后，页签从绿色恢复灰色；该物料其它草稿暂时保留，方便继续修改。

### 系统只同步了部分物料批号

有同步批号的物料显示批号，未同步到批号的物料保持空白。

### 路线发布了新版本

既有执行订单继续使用冻结版本中的物料；新订单使用新版本。页面不把当前最新配置套到旧订单。

## Error Flows

### 当前工序没有配置报工物料

页面显示“当前工序未配置报工物料”，不生成默认页签，不允许正式提交。

### 某个物料未填写完成数量

该物料页签保持灰色。用户点击“正式提交”时，页面指出具体物料需要填写完成数量，不发送请求。

### 正式提交失败

页面显示正式错误并保留全部物料数据和原提交会话，不显示成功，不清空输入。

### 正式提交响应不确定

沿用现有正式提交回执与幂等处理规则；不能让用户重复生成另一笔相同的多物料报工。

### 同步表读取失败

系统显示真实错误，不切换到库存表或 ERP 网络调用。

### 同一订单物料有多个批号

系统展示全部非空批号并去重排序，不任取一条。

### 冻结版本中物料与工序无法唯一对应

页面或服务明确阻塞，并指出配置身份问题；不得改读当前路线或其它工序的物料。

## Out-of-Scope Flows

- 一线人员临时增加、删除或替换工序物料。
- 按物料分别点击正式提交。
- 手工填写、预生成或临时生成批号。
- 使用黄色、红色等额外颜色表达填写进度或错误。
- 根据损耗、参数、设备或批号改变页签颜色。
- 页面刷新后恢复未提交草稿。
- 直连 ERP 或新增批号回调接口。
- 用批记录表单或表单槽位决定当前工序物料。

## Open Questions

- 产品 BOM 中是否存在只消耗但不需要一线填写完成数量的物料；首版按全部需要报工处理。
