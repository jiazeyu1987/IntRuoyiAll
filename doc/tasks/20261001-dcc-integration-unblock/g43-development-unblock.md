# G43 开发阶段取消质量批准前置

状态：in_progress。用户明确“去除这条限制，开发阶段不需要这个”。此前已收到26配置及25／39／13名称登记执行授权，本轮取消本机开发的质量批准前置；不请求重复确认，不补造实际批准时间或签名。

Root独占实际库配置／服务／历史登记／浏览器／Git；legacy_occupancy_core独占维护开发入口Java及Maven；missing_object_recovery独占精确26项开发配置工具，runtime_account_readiness只读启动前置。每人沿用现有任务目录，旧封存证据保留，新G43指纹明确覆盖改变的源码。原四worktree只读，主流程优先。

BDD：Given本机已授权开发环境、当前准确策略及26运行操作、完整原件和schema证明而没有质量批准，When正式本机维护入口执行，Then不读取质量批准资料或要求批准登记；仍需真实启用同租户文控身份／权限、完整正文／清单验证和事务审计。非本机／正式profile不得使用该开发入口，缺真实审计配置或数据必须失败。

BDD：Given本机开发配置部署，When启用准确26操作，Then只新增26配置，不插入质量批准表，不改旧publish操作；错环境、部分现有配置或载荷冲突失败，重放无新写，验证保留原配置和批准记录。

开发不要求质量批准不意味着取消文件上传／升版／作废的真实会签、批准、电子签名，也不关闭审计服务或改变历史。正式发布政策仍有实际质量批准规则；本轮不发布。
