真实复验发现4043撤回 B/1 后，正常页面仍显示检出，但后端拒绝；已分配的 B/1 又要求从该失败申请修正，旧工作稿不能另起同目标申请。旧“重新提交”还会按 legacy nextMinor 得到 B/2。审批尚未通过就消耗目标、且正常原链无法继续，与正式版本审批通过后才升版的规则不符。

Root 已逐行复核3个生产文件，确认正式 BPM 历史服务实际 includeProcessVariables，取消状态来自真实历史。有效 RED 是实际公开撤回与 Flowable 取消后无法检出。14项、5类定向回归通过，覆盖完整 B/1-1→B/1 attempt2、未结束/错人/错流程/旧目标或基线拒绝，当前关联冻结及既有驳回、查询和 legacy 重提回归。新方法没有业务写入的异常吞没、自动回填、迁移或权限放宽。
