# 验收标准

## AC-01 通用规程类型

Given QA 管理员创建通用规程主档
When 保存规程类型
Then 系统将该规程/DCC 组合登记为 `scopeCode=COMMON_PACKAGING`，并与产品专属 QA 规程区分。

## AC-02 版本生命周期

Given 一个已发布版本 A
When 用户尝试直接编辑版本 A
Then 系统拒绝修改，并要求复制生成新草稿版本。

## AC-03 版本内容完整性

Given 用户提交通用规程版本
When 工序或检验项目缺少必要标准、方法、工具或抽样方案
Then 草稿可以保存；提交发布时失败并指出缺失字段。

## AC-04 多产品复用

Given 版本 A 已发布
When 产品 1 和产品 2 分别绑定版本 A
Then 两个产品绑定均成功，版本 A 只维护一份。

## AC-05 单产品唯一有效绑定

Given 产品 6 已绑定版本 B 且状态启用
When 用户新增版本 C 绑定而未走变更流程
Then 后端拒绝重复有效绑定。

## AC-06 绑定候选约束

Given 页面选择产品绑定版本
When 候选版本包含草稿、退休版本或产品专属规程
Then 这些版本不可选，候选只属于当前选择的 `regulationId`，后端也必须再次拒绝。

## AC-07 绑定变更事务

Given 产品 6 当前绑定 B
When 用户将其变更为 C
Then 同一事务内 B 失效、C 启用并立即生效；首期不接受未来生效时间；任一写入失败时两者均不改变。

## AC-08 租户边界

Given 用户属于租户 T1
When 请求绑定租户 T2 的产品或规程版本 ID
Then 后端拒绝并不写入任何关系。

## AC-09 历史追溯

Given 版本 A 已被产品绑定过
When 管理员退休 A
Then 当前新绑定不可再引用 A，但历史绑定和审计记录仍可查询。

## AC-10 版本摘要

Given 产品绑定版本 A
When 用户查看绑定列表或详情
Then 页面显示产品、DCC、scope、规程、版本、发布状态、来源文件数量、包装阶段、工序数量、项目数量和最近变更时间。

## AC-11 退休联动与幂等

Given 版本 A 仍被产品 1 启用绑定
When 管理员退休 A
Then 系统在同一事务内停用绑定并退休版本，任一步失败全部回滚；重复幂等请求不得重复写入。

## AC-12 服务端派生

Given 客户端提交错误 scope、状态或 DCC 项目代码
When 创建产品绑定
Then 后端固定 scope 为 `COMMON_PACKAGING`、状态为 `ENABLED`，并从规程主档解析 DCC。

## AC-13 多来源版本

Given QA 管理员将初包装 Word 规程和大中包装 Word 规程共同导入 A 版本
When A 版本发布并绑定到产品
Then 产品引用的是同一个 A 版本，版本摘要显示两份来源文件、两个包装阶段及其完整工序/项目，不拆分成两个绑定。

## AC-14 来源表头兼容与失败

Given Word 来源文件的工具/抽样列可能写作 `检具`/`检验规则` 或 `检验器具及设备`/`抽样方案`
When 导入来源文件
Then 白名单同义表头可解析；未知表头或缺少必填列时整个导入失败且不写入半个版本。

## AC-15 版本间不自动补齐

Given A 版本有初包装和大中包装两份来源，B 版本只有美联初包装一份来源
When 产品绑定 B
Then 系统只展示和冻结 B 的来源内容，不自动继承 A 的大中包装来源。

## AC-16 条件标准显式适用性

Given A-01 来源中存在“百瑞吉产品要求”的密封强度条件标准
When QA 管理员发布 A 版本
Then 系统要求为该条件标准选择正式产品 ID 或删除该条件标准；未确认时发布失败，确认后只有适用产品使用该条件标准。

## AC-17 版本适用范围

Given B-01 来源包含“美联”线索且 QA 管理员将 B 设置为 `PRODUCT_SET`
When 用户将非适用产品绑定到 B
Then 后端拒绝绑定；系统不能根据产品名称或来源文件名自动判断适用性。

## AC-18 来源逐项追溯

Given A 版本由两份来源 Word 组成
When 用户查看已发布版本证据
Then 每个检验项目都显示来源文件、包装阶段、Word 表号、行号、原始标准摘录、工具和抽样方案。

## AC-19 Warning 分级

Given 来源 Word 存在非内容类 OpenXML schema warning
When 检验规则表和必填字段可解析
Then 系统允许发布但记录 warning；若 warning 指向检验规则表不可读、必填列缺失、必填单元格为空或条件标准未确认，则发布失败。
