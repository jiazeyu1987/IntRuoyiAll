# 前端设计

## 页面

- `QA 管理 -> 通用检验规程`
- `QA 管理 -> 产品通用检验规程`

## 通用规程页面

- 列表：DCC 项目代码/名称、规程名称、类型、当前发布版本、版本状态、来源文件数量、工序数、项目数、更新时间。
- 新建主档抽屉：必须选择 DCC 项目代码；scope 固定显示“通用包装检验”，不可由前端改写。
- 版本抽屉：版本号、状态、发布信息、DCC 项目代码/名称、来源文件清单、sha256、解析 warning、工序和项目树。
- 版本编辑器：工序列表、项目明细、标准/方法/工具/抽样方案/上下限/单位/精度/设备要求。
- Word 导入区允许选择多份来源规程文件，并要求每份文件选择包装阶段；导入后按来源文件分组预览解析结果。
- 条件标准确认区显示产品/客户特定标准线索，要求 QA 管理员选择适用产品或删除该条件标准；未确认时发布按钮禁用。
- 已发布版本只读，编辑按钮改为“复制新版本”。

## 产品绑定页面

- 列表：产品编码、产品名称、规格、DCC 项目代码/名称、规程名称、版本号、状态、来源文件数量、工序数、项目数、更新时间。
- 新增/变更抽屉：产品选择、通用规程选择、已发布版本选择、版本摘要预览。
- 版本卡片展示 DCC、scope、来源文件数量、包装阶段、sha256、工序数和项目数；摘要预览展示将绑定的完整版本，不允许前端自行裁剪部分来源文件。
- 当版本适用性为 `PRODUCT_SET` 时，页面展示版本适用产品范围；条件标准另行展示条件标准适用产品范围，后端仍以正式 `productId` 再次校验。
- 同产品已有启用绑定时，新增按钮提示使用“变更版本”。
- 产品选择必须以正式 `productId` 提交；名称只用于显示。

## 状态与错误

- 加载失败显示后端错误，不显示空成功状态。
- 候选为空显示业务空态和阻断原因。
- 保存按钮在提交期间禁用，防止重复绑定。
- 冲突错误定位到产品和当前绑定版本。
- 任一 Word 来源文件解析失败时，页面保留已选文件和阶段选择，展示失败文件名、失败原因和后端错误码，不显示保存成功。
- 条件标准未确认或产品不在版本适用范围内时，展示后端错误，不允许前端改为默认通过。

## 可访问性

- 状态不能只用颜色，必须有文字。
- 版本状态、绑定状态、阻断原因使用可读文本。
- 版本树和表格支持键盘操作；长标准文本使用详情抽屉，不强行横向撑开表格。
