# 用户流程：通用检验规程与产品绑定

## Flow A：维护通用规程版本

1. QA 管理员进入 `QA 管理 -> 通用检验规程`。
2. 创建或打开“通用包装检验规程”主档，并选择/查看 DCC 项目代码。
3. 创建版本草稿，填写版本号和版本说明。
4. 上传一份或多份来源 Word 规程，并逐份选择包装阶段。
5. 系统解析来源文件，展示来源文件清单、包装阶段、工序和项目摘要。
6. 若存在“百瑞吉产品要求”“美联”等产品/客户特定线索，QA 管理员显式确认版本适用产品或条件标准适用产品。
7. 维护或补齐检验项目：标准、方法、工具、抽样方案、上下限、单位、精度、设备要求。
8. 保存草稿并查看版本摘要。
9. 按现有 QA 发布接口发布，状态变为 `PUBLISHED`；若现有接口无法识别通用作用域、多来源版本或条件适用性，操作被阻断。
10. 发布成功后版本变为只读；继续修改必须复制新版本。

## Flow B：建立产品绑定

1. QA 管理员进入 `QA 管理 -> 产品通用检验规程`。
2. 点击新增绑定。
3. 选择正式产品；产品选择器按 `productId` 传值并展示编码、名称和规格，同时由后端解析正式 QA/DCC 上下文。
4. 选择通用规程主档。
5. 选择已发布版本；候选只显示当前 `regulationId` 下、通用作用域且 `PUBLISHED` 的版本。
6. 查看 DCC、scope、来源文件、适用产品范围、版本摘要和检验项目数量。
7. 确认来源文件清单符合当前产品，例如 A 显示初包装和大中包装两份来源，B 显示美联初包装一份来源。
8. 提交绑定。
9. 后端校验产品唯一即时有效绑定并保存审计信息；首期不支持未来生效。

## Flow C：变更绑定

1. 在产品绑定列表打开当前产品。
2. 点击变更版本。
3. 选择另一个已发布版本。
4. 页面展示旧版本/新版本摘要，不在前端自行比较项目内容。
5. 确认后端事务完成旧绑定失效、新绑定启用。
6. 页面刷新显示新的当前版本和变更时间。

## Flow D：阻断

- 产品未选择：表单阻止提交。
- 版本未发布：候选不可选。
- 产品已有有效绑定：新增接口返回冲突，页面引导变更版本。
- 版本被绑定或被历史引用：删除按钮不可用或后端拒绝。
- 多来源版本任一文件解析失败：整个导入失败，页面展示失败文件和错误码。
- 条件标准未确认适用产品：发布失败并定位到具体来源文件/行号。
- 产品不在版本适用范围内：绑定失败并展示后端返回的适用性错误。
