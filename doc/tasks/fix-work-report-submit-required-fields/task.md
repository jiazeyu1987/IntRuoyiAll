# 修复报工提交缺少关键字段

## Task Goal

修复报工提交时缺少报工单编号、报工类型、订单上下文、生产任务、产品物料、班组长审批人、记录本、签名、签名员工导致无法提交的问题，确保正式提交链路按真实上下文携带必填字段并失败可见。

## Expected Verification

- 定向回归测试先 RED 后 GREEN，覆盖提交载荷包含报工单编号、报工类型、订单上下文、生产任务、产品物料、班组长审批人、记录本、签名、签名员工。
- 相关前端或后端静态合同/单元测试通过。
- 若真实 E2E 前置缺失，记录缺失前置与影响，不用 API-only 或 mock 冒充真实用户路径。
