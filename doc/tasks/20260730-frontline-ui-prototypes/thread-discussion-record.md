# 本线程：一线报工与 PQC 需求讨论记录

## 记录范围

- 只记录当前 Codex 线程，不包含其它线程或其它历史对话。
- 本文按讨论顺序整理需求、澄清和已确定的界面方向，不作为逐字聊天转录。

## 业务模型讨论

1. 业务同事认可当前批记录系统，但希望一线员工只填写自己当前工序最必要的数据，包括上一个工序的输入数量、设备及设备参数、输出数量和损耗数量。
2. 不同员工的填写 UI 可以相同，也可以不同；后续明确为固定的几类模板。
3. 员工提交时间默认取系统当前时间，不要求手工填写时间。
4. 实际生产为滚动并行生产。工艺路线可以配置路线，但一线填写时不能因为路线前后关系限制报工。
5. 所有员工填写的原始内容汇入资源池；生产工单按计划开始时间执行 FIFO，先计划开始的生产工单先获得数量。
6. 一线填写不做业务范围限制，保留原始记录。审核时可以生成最接近限制的审核副本，例如限制 20～40，原始值 50 调整为 40，原始值 10 调整为 20；原始值和调整值都必须保留。
7. 原始记录提交后仍允许修改，但必须保留修改日志。
8. 一个账号可以限制可用工序，只能切换绑定工序；员工只能在当前工序绑定的员工中切换；切换员工时同步切换对应 UI 模板。
9. PQC 输入同样简化，但后续明确 PQC 需要逐件填写检验项目，不再只是整批成功/失败。
10. 不考虑排产系统，本次订单范围只考虑生产工单。

## 与现有系统结合

1. 尽量复用当前报工系统、记录本和批记录系统，不单独建设一套新的生产一线系统。
2. 一线统一入口名称为“报工”，同时也是记录本入口。
3. 员工点击确定提交时，一次操作同时提取报工信息和批记录相关信息。
4. 同一次提交既完成报工，也写入记录本；后续批记录审核从这些原始记录生成审核副本。
5. 生产工单包含完成数量，以数量判断当前工序是否完成。
6. 同一个工序的必要内容可能由一个人全部填写，也可能拆给多个人填写，最终按同一生产工单和工序汇总。

## 生产一线页面决定

1. 页面目标分辨率为 1920×1080。
2. 页面必须极简，只显示必须填写的内容，不显示美化、统计、说明或管理信息。
3. 生产一线员工不需要了解生产工单，因此生产员工页面去掉工单展示。
4. 不单独显示“切换工序”“切换员工”按钮，直接点击顶部工序卡片和员工卡片切换。
5. 页面面向生产员工，不显示 PQC 的成功/失败控件。
6. 设备需要覆盖无设备、一个设备和多个设备；最终按最多 3 个设备设计。
7. 多设备不使用 Tab 形式。
8. 页面增加“主页”按钮。
9. 生产员工不再填写“收到数量”，生产页只保留“完成数量”和“损耗数量”。
10. 一个工序可能配置 6～7 种不良；员工需要选择具体不良类型并填写每一种不良的数量。
11. 为避免重复填写和数量不一致，原型中损耗数量由各不良类型数量自动汇总。
12. 不良数量不使用弹框；一个工序配置的 6～7 种不良必须在主页面同时显示，员工直接在同一个页面填写每种不良数量。

## PQC 页面决定

1. PQC 负责一条工艺路线的所有工序，需要看到生产订单、工序和员工。
2. PQC 可以选择首检、巡检、末检；一个工序可以有多次巡检。
3. PQC 页面必须与生产一线页面保持统一，生产订单、工序、员工和主页的位置固定一致，工序选择入口位置也一致。
4. 左侧显示检验内容，例如长度、外观、密封、压力；右侧显示首检/巡检/末检、巡检次数、检验数量和损耗数量。
5. 检验内容必须可填写，例如长度输入厘米数，外观选择合格或不合格。
6. 用户截图标出的巡检摘要、检验方法行和底部整批结果行不显示。
7. 2026-07-31 新增：如果 PQC 要检验 30 个产品，点击长度、外观等检验项目时，必须弹出 30 条逐件检验列表，由检验员逐件填写。
8. 数值项目逐件输入数值和单位；判断项目逐件选择合格/不合格，默认不自动判定合格。
9. 主页面只回显每个检验项目的必要完成状态 `已填 x/总数`，不显示统计分析。
10. 逐件结果按工序、首检/巡检/末检、检验次数和检验项目分别保存，不能互相覆盖。
11. 2026-07-31 补充：外观、密封等判断项目在主页面分成三个操作区，依次为全部合格、全部不良、逐件选择。点击全部合格或全部不良后，当前检验数量内的每一件都自动选择对应结果；进入逐件选择时完整回显，并允许再单独修改。
12. 2026-07-31 补充：外观、密封等判断项目名称单独列在上方，下面才显示全部合格、全部不良、逐件选择，避免把项目标题误认为批量操作的一部分。
13. 2026-07-31 补充：需要填写的数值由模板提供默认值，默认值旁可用加减号调整，也可以直接手工输入。逐件检验弹框使用 M×N 网格充分利用空间；当前1920×1080原型中，30件按5列×6行展示。长度默认32.5厘米、步长0.1，压力默认50MPa、步长1。
