# 新建生产人员负责范围误校验修复

## Task Goal

修复生产组长“新增人员”阶段误报“班组长不在该员工或工序的负责范围内”的问题：新增人员档案时不应要求班组长已负责尚未加入的员工；只有绑定到工序、复核或报工确认等操作才校验员工/工序负责范围。

## Milestones

- [x] M0：建立任务记录，读取后端、任务收尾和适用门禁。
- [x] M1：定位新增人员调用链和触发范围校验的具体环节。
- [x] M2：补充 BDD/RED 回归测试，证明新增人员不应触发员工负责范围校验。
- [x] M3：实施最小修复并运行定向回归。
- [x] M4：更新证据、经验检查和 closeout 状态。

## Expected Verification

- RED：新增生产人员时，当前实现错误触发 `PRO_PROCESS_POOL_TEAM_SCOPE_DENIED`。
- GREEN：新建正式工/临时工生产人员档案不再要求该员工已在班组长负责范围内。
- REGRESSION：工序人员绑定、报工列表/详情、复核/确认仍保留负责范围校验。
- CONTRACT：无 fallback、无前端吞错、无默认成功。
