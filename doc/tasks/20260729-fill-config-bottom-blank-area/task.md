修复填写配置弹窗中底部固定空白区域占用高度的问题：去掉截图红框中的空白留白，让原表单、辅助表单预览和右侧映射控制栏的主内容区域填充到可用底部空间。

3. `pending`：实施最小前端布局修复，不引入 fallback 或静默降级。
4. `pending`：运行目标静态合同、相邻回归和类型检查。
5. `pending`：更新证据、cleanup 状态和最终验证结果。
