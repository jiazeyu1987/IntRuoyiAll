# 活跃订单按工艺路线与 DCC 项目解析 QA

- 同名但 MES 产品 ID 不同的工单，只要其正式物料绑定能够唯一解析到 ACTIVE 路线版本及 DCC 项目，即可读取该路线版本的已发布 QA。

- 定向 JUnit RED/GREEN、相邻活跃订单候选回归和本机运行态只读验证通过。
