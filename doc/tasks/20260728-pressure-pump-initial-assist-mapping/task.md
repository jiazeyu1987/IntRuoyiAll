# 球囊扩张压力泵批记录辅助映射初始化

## Task Goal

为“球囊扩张压力泵”最新版本批记录表单初始化一个可测试的辅助模式版本：根据每个表单签字单元格数量自动创建填写人数量（至少 1 个），并自动生成原表单元格到对应填写人的初始映射。后续仍由用户在现有辅助映射界面手动调整。

## Milestones

- [ ] 核对现有报表版本、签字单元格识别字段、辅助映射保存结构和目标租户范围。
- [ ] 设计并记录初始化规则：填写人数量、单元格归属、冲突处理、最小 1 人规则。
- [ ] 先补充可失败的验证或初始化契约，再执行最小正式初始化。
- [ ] 使用现有系统路径/API/数据库只读核验初始化结果，并记录可回滚范围。

## Expected Verification

- 能定位“球囊扩张压力泵”最新版本及其各批记录表单。
- 每个目标表单初始化后的填写人数量等于签字单元格数量，且最少为 1。
- 原表单元格只分配给一个填写人，不存在跨填写人重复分配。
- 现有辅助模式手动映射入口仍可继续调整。
