# 实习用户生命周期时间与审计扩展

## 目标

在既有 `实习用户 / intern_user` 模块内扩展文件时间维护能力：

- 查看上传时间修改审计。
- 修改 DCC 升版时间。
- 查看升版时间修改审计。
- 修改 DCC 作废时间。
- 查看作废时间修改审计。

模块仍保持可切割：加载模块时提供后端接口、权限和前端入口；不加载模块时不暴露这些能力。

## 设计约束

- 角色中文名统一为 `实习用户`，角色编码统一为 `intern_user`。
- 权限点统一归属 `intern-user:time-maintenance:*`。
- 所有时间修改必须写入追加型审计记录，不提供无日志修改路径。
- 审计查看权限只挂给 `实习用户` 角色。
- 前端验收动作必须从真实页面入口进入；2026-09-22 用户已追加授权重启并进行 E2E 验证。

## Given / When / Then

### 上传时间修改审计

Given 用户拥有 `实习用户` 角色并通过模块接口修改上传时间\
When 用户在文件列表点击上传时间修改审计入口\
Then 页面展示该文件上传时间变更的旧值、新值、操作人和操作时间。

### 升版时间修改

Given 用户拥有 `实习用户` 角色并选中 DCC 受控文件记录\
When 用户提交新的升版时间\
Then 系统更新真实 DCC 升版时间字段，并追加一条升版时间修改审计。

### 升版时间修改审计

Given DCC 文件存在升版时间修改记录\
When 用户点击升版时间修改审计入口\
Then 页面只读展示该文件的升版时间修改审计。

### 作废时间修改

Given 用户拥有 `实习用户` 角色并选中 DCC 受控文件记录\
When 用户提交新的作废时间\
Then 系统更新真实 DCC 作废时间字段，并追加一条作废时间修改审计。

### 作废时间修改审计

Given DCC 文件存在作废时间修改记录\
When 用户点击作废时间修改审计入口\
Then 页面只读展示该文件的作废时间修改审计。
