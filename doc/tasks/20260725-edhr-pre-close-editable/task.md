# Task: eDHR Submitted Form Editable Before Close

## Task Goal

将 eDHR 已填写提交的普通工序表单调整为“批次关闭前仍可修改并重新提交”，解决当前提交后进入填写完成状态后不能继续填写的问题。

## Milestones

- [x] 建立任务记录、读取后端/前端/eDHR/PowerShell 相关门禁。
- [x] 用 BDD 和 RED 静态/后端测试固化“关闭前可修改、关闭后仍阻断”的行为。
- [x] 修改后端已提交普通表单可编辑门槛与批次打开动作锁。
- [x] 修改前端批次详情已完成表单打开条件与提示文案。
- [x] 运行目标验证并记录 GREEN/REGRESSION 结果。

## Expected Verification

- 后端目标 JUnit：已提交普通表单在批次关闭前、即使存在放行待处理事务，原填写人仍可打开并重新提交。
- 后端目标 JUnit：批次已关闭/归档/驳回/作废后仍禁止打开填写。
- 前端静态合同：批次详情页不再仅因任务状态为 `APPROVED/填写完成` 禁用“打开填写”，而是以后端 `OPEN_FORM` 动作为准。
