# Test Data

## Purpose and Scope

本文件定义生产报工提交参数改造所需的任务自有测试数据。数据必须可追踪、可清理，并严格区分生产组长配置、员工提交和只读核验。不得使用生产租户、管理员基线数据或不可恢复的真实业务记录。

## Evidence Reviewed

- `docs\e2e-rules.md`：写入型 E2E 必须使用确认的测试租户和账号，并创建带任务标识、可追踪、可清理的数据。
- `TeamLeaderWorkbenchPage.vue`：生产组长可维护损耗原因、设备档案、工序设备关系和设备参数。
- `FrontlineFixedTemplatePanel.vue`：员工提交界面按运行态配置渲染损耗原因、设备和参数。
- `MesFrontlineLossReasonValidatorImpl`：后端当前按 `routeProcessId` 校验损耗原因。
- `MesProcessDeviceParameterRuleServiceTest`：设备参数规则包含 `deviceId`、`parameterCode`、`lowerLimit`、`upperLimit`。

## Required Test Data

- 测试租户：仅使用项目确认的本地测试租户，不使用生产租户。
- 生产组长账号：具备生产组长工作台、损耗管理、班组配置和报工管理权限。
- 员工设备账号：可进入一线生产报工界面，并能选择任务自有工序。
- 签名凭证：员工提交报工所需的合法签名凭证，不写入日志明文。
- 生产工单：任务自有或可安全复位的工单，编码建议包含 `BDD-TDD-REPORT-20260806`。
- 工序 A：名称建议 `BDD工序A-报工参数`，用于配置两个损耗原因和设备 `PT-A-03`。
- 工序 B：名称建议 `BDD工序B-报工参数`，用于验证同名原因、同设备或不同上下限不会串用。
- 损耗原因 A1：`密封件划伤`，工序 A 数量示例 `3`。
- 损耗原因 A2：`装配不到位`，工序 A 数量示例 `2`。
- 损耗原因 B1：可与 A2 同名或不同名，用于验证按工序配置 ID 保存。
- 设备 A：`PT-A-03`，绑定工序 A。
- 设备 B：`PT-A-03` 或 `PT-B-01`，绑定工序 B，用于验证同设备跨工序上下限差异。
- 参数 A1：`压力`，单位 `MPa`，工序 A 下限 `20`、上限 `40`，提交值 `50` 应标红但允许提交。
- 参数 A2：`时间`，单位 `秒`，工序 A 下限 `30`、上限 `60`，提交值 `45` 应正常显示。
- 参数 B1：`压力`，工序 B 上限可设为 `60`，提交值 `50` 应不标红。

## Reset Procedure

- 使用任务标识 `BDD-TDD-REPORT-20260806` 查询并清理本任务创建的损耗原因、设备绑定、参数规则和生产报工测试记录。
- 清理必须走正式页面或已批准的测试清理接口；不得直接修改生产租户数据。
- 每次真实 E2E 前确认工序、设备和损耗原因未被上一轮运行残留占用。
- 若关系具有唯一键，重复运行前创建新的任务自有编码或先走正式删除/禁用流程。
- 清理后只读核验列表中不存在本任务标识的待处理记录。

## Data Ownership

- 本任务数据归 `doc/tasks/20260806-production-reporting-submit-bdd-tdd-design/` 后续实现任务所有。
- 所有新增数据编码、备注或显示名必须包含 `BDD-TDD-REPORT-20260806` 或后续实现任务 ID。
- 不得复用其它并行任务的数据作为写入目标。
- 不得记录密码、token、私钥、数据库连接密钥或签名明文。

## Test Blockers

- 缺少测试租户、生产组长账号、员工设备账号、签名凭证或活跃生产工单时，真实 E2E 阻塞。
- 工序 A/B 无法绑定设备或无法保存设备参数上下限时，先修配置链路，不能跳过设备参数异常验证。
- 若正式页面没有清理入口且未批准测试清理接口，写入型真实 E2E 阻塞，避免留下不可控业务数据。
- 若同名原因或同设备跨工序无法通过正式配置建出，跨工序边界场景阻塞，不能用前端 mock 数据替代。
