## 经验门禁

- EDHR 术语门禁：批记录表单、表单槽位、工序开始必须作为三条独立链路表达，禁止互相 fallback。
- 后端 EDHR 门禁：批次任务配置来源、批记录版本治理、单元格链接落库、字段审计链和作废终态必须 fail-fast。
