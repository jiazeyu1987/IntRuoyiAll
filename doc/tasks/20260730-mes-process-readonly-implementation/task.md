# 20260730 MES process read-only implementation

## Task Goal

在“工序设置”和“工艺流程”之间新增只读“MES工序”菜单，展示 `压力泵工序.xlsx` 的 `二代压力泵` 工作表数据。只有设备关联现有设备主数据，执行工序关联现有工序设置；其它字段均为展示快照。完成数据库、后端、前端和本机真实 Playwright E2E。

## Expected Verification

- 菜单顺序为“工序设置、MES工序、工艺流程”。
- MES 工序页面只有查询、筛选、分页和显示字段，不存在新增、编辑、删除、启停或导入入口。
- 列表只展示 `二代压力泵` 工作表有效工序行，不包含末尾无工序名称的孤立产能值。
- 设备编码关联现有设备主数据，多设备以多个设备对象返回。
- 执行工序关联现有 `mes_pro_process`；无法唯一匹配时迁移或种子明确失败。
- 产品、MES 工序编码/名称、设备数量、产能、人力、单价、报工标记、批记录标记和批记录工序名称均为展示快照。
- 后端分页接口受独立查询权限保护，不提供写接口。
- 前端静态合同、TypeScript、后端定向测试、迁移策略门禁和真实 Playwright E2E 通过。
- E2E 使用本机 `int_main` 前端/后端成对地址，并记录租户、用户、页面断言、接口响应和控制台错误。

## Experience Gate

- 动态菜单必须同时提供正式菜单迁移、组件、权限、角色/套餐可见性和真实页面验证。
- 一对多设备关系不得直接 JOIN 挤压主列表分页；分页以 MES 工序目录行为主，设备批量加载后组装。
- 中文菜单迁移使用 ASCII 安全写入并验证 UTF-8。
- 静态合同与真实 Playwright E2E 分开记录，API-only 不得代替页面验收。
- 当前工作区存在其它任务未跟踪文件；本任务只编辑、暂存和提交明确列出的自有路径。

## Non-Goals

- 不提供 MES 工序新增、编辑、删除、启停或页面导入。
- 不修改报工提交、记录本、批记录、工序池、FIFO 或排产逻辑。
- 除设备和执行工序外，不建立产品、路线、批记录、人力、价格或产能业务关联。
