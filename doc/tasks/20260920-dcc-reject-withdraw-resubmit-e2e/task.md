# DCC 驳回撤回重新提交 E2E

## Current Status
blocked

## 任务目标

使用真实 Playwright 前端页面和本机 E2E 账号，完整验证 DCC 受控文件审批的驳回、申请人查看驳回结果、重新上传新文件、重新进入审批，并确认历史意见和签名保留。

## BDD

BDD: 审批人驳回并填写原因 -> Given 申请人通过真实上传页提交任务自有受控文件进入审批；When 审批人在审批中心打开待办并选择驳回、填写原因和电子签名；Then 页面显示审批驳回成功，业务单据进入待申请人处理状态，驳回原因可见。

BDD: 申请人查看驳回并撤回/重新提交 -> Given 受控文件已被审批驳回；When 申请人从真实详情页查看处理摘要和历史意见，上传新文件并重新提交；Then 新流程进入审批中心待办，旧流程状态关闭或撤回，历史意见仍可见。

BDD: 历史意见和签名保留 -> Given 原流程已有驳回签名证据；When 申请人重新提交并进入新审批流程；Then 详情页或审批追溯中同时保留旧驳回意见、签名记录和新流程入口，不以新上传覆盖历史证据。

## 里程碑

1. 核对规则、运行态、端口、账号和任务数据边界。
