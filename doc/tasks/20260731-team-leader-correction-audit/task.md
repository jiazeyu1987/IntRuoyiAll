# 20260731 班组长复核修改与 PQC 提交日志

## Task Goal

让生产组长和 PQC 组长可以对负责员工提交逐条判定“正确/不正确”，对不正确内容发起带原因的修改，并保证组长修改、复核判定和 PQC 检验员提交均有可追溯日志记录。

## Milestones

- [ ] 核对现有班组长复核、审核副本、原始修改历史、PQC 提交事件和日志表/服务边界。
- [ ] 补充 BDD/TDD：复核判定、组长修改写日志、PQC 提交日志可见。
- [ ] 实现最小正式链路，优先复用现有事件修订/审核副本/时间轴日志能力，不新增 fallback 或默认成功。
- [ ] 更新组长工作台前端入口与静态契约。
- [ ] 运行前后端定向验证，更新验证报告并进入收尾。
