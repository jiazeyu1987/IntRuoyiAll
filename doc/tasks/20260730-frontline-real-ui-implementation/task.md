# 20260730 一线报工与 PQC 真实前端界面实现

## Task Goal

基于现有系统，分别实现生产一线员工和 PQC 一线员工的真实前端界面设计，并由主 agent 审查两组子 agent 的实现，确保界面足够精简、符合本次线程已确认的业务口径，且不修改后端 API、数据契约或真实数据来源。

## Milestones

1. 识别真实前端入口、组件边界、现有数据/API 契约。
2. 子 agent A 实现 PQC 一线员工界面。
3. 子 agent B 实现生产一线员工界面。
4. 主 agent 审查两组改动，修正冲突、越界或视觉不一致问题。
5. 运行聚焦静态合同和可行的 1920×1080 页面验证，记录证据。

## Expected Verification

- BDD 场景覆盖生产一线和 PQC 一线的必要 UI。
- RED/GREEN 记录当前界面静态合同从失败到通过。
- 聚焦静态合同验证：生产页不显示工单，PQC 页显示生产订单，二者共用一致顶部选择区和简化输入区。
- 可行时使用真实前端页面或静态页面截图进行 1920×1080 检查，确认无横向溢出、提交区不遮挡输入区。
- 明确记录未修改后端、API wrapper、DTO、schema、mock 或数据源。
