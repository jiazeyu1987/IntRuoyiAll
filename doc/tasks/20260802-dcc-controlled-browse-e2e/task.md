# 20260802 DCC 受控浏览真实 E2E 验证

## Task Goal

验证 DCC 文控“受控浏览”真实前端页面中，不同非 admin 角色只能看到有权限的当前有效文件，能打开正确发布/盖章版本，并且不能误看草稿、历史失效版或无权限分类文件。

## Milestones

- [x] M1: 读取项目规则并建立 BDD 验收口径
- [ ] M2: 确认本机场景前置条件，包括运行态、登录账号、页面入口和已知 ACTIVE 测试文件。BLOCKED：当前进程、用户级和机器级均未注入非 admin DCC 密码环境变量，无法合法登录有权限/无权限非 admin 账号。
- [ ] M3: 使用有权限非 admin 账号通过 Playwright 操作真实受控浏览页面，验证当前有效版本与预览
- [ ] M4: 使用无权限或低权限非 admin 账号通过 Playwright 操作真实受控浏览页面，验证不可见或明确无权限
- [ ] M5: 通过只读 API/DB 核验文件状态、版本、权限范围和预览文件 ID
- [ ] M6: 输出 verification-report.md，记录证据、错误数和 blocker

## Expected Verification

- Playwright 操作真实本机前端页面，不使用 API-only 替代页面权限验证。
- 至少两个非 admin 账号：一个具备目标分类/项目浏览权限，一个无权限或权限较低。
- 已知 ACTIVE 测试文件来自任务自有原版或升版链路，且核验当前有效版本。
- 记录受控浏览目录路径、文件编号、版本、标题、publishedFileId/stampedFileId 或等价发布文件信息、预览结果。
- 只读 API/DB 仅用于最终核验，不用于绕过页面路径。

## Current Status

blocked

## Applicable Gates

- 登录访问门禁：非 admin 真实页面登录必须使用已注入的测试账号密码；不得使用 `admin`、默认 `.env` 身份或明文凭据替代。
- E2E 门禁：受控浏览权限验证必须由 Playwright 操作真实前端页面完成；API/DB 只能在页面路径完成后做最终只读核验。
- 目标链路错误归因门禁：只有真实页面目标路径执行后，才能统计本机前端、后端和 DCC 目标接口错误数；本轮在登录前置处阻塞，因此不制造目标链路错误数。

## Blocked Precondition

- 缺少 `DCC_E2E_PASSWORD` 或等价本场景非 admin 密码环境变量。影响：无法执行有权限账号和无权限/低权限账号的真实 Playwright 登录、受控浏览路径定位、预览打开、无权限不可见性验证，也不能进入最终 API/DB 核验阶段。
- 本轮不使用 API-only、SQL 改状态、admin 账号或默认 `.env` 登录密码绕过阻塞。
