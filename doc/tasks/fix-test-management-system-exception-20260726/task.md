## Task Goal

- [ ] 运行定向回归验证并记录结果
- [ ] 收尾清理、经验沉淀、提交与推送

- 访问「系统管理 / 测试管理」不再出现系统异常。
- 定向回归测试覆盖本次根因。
- 相关前端或后端检查通过。
- 不引入 fallback、吞异常、mock 成功或默认成功。
