## 任务目标

## BDD

BDD: 受控文件检出与撤销检出 -> Given：目标文件存在当前受控版本且账号具备页面权限；When：从真实文件详情进入检出并确认，再从同一页面执行撤销检出；Then：页面显示检出人/时间和检出状态，撤销后恢复可检出，且未生成新业务版本。

BDD: 小版本检入 -> Given：目标文件已由当前账号重新检出；When：通过真实检入页面上传新的不可编辑浏览版 PDF，填写一般修改声明并确认小版本检入；Then：页面显示新小版本已受控、旧版本失效、检出锁释放，且默认阅读入口指向新版本。

BDD: 大版本检入 -> Given：小版本已受控且目标账号具备升大版本权限；When：通过真实页面检出并选择大版本，填写修订原因、主要变更和涉及范围，上传新的不可编辑浏览版 PDF 并提交；Then：页面显示新大版本进入正式审批/待文控状态，旧受控版本在审批完成前仍有效。

BDD: 同名源文件上传路径隔离 -> Given：同一天内多次通过真实页面上传同名源文件；When：后端文件服务生成对象存储路径；Then：每次上传默认带日期和唯一后缀目录，不复用同一个对象 key，后续 DCC 签名证据可以按受控文件 `sourceFileId` 读取到正确源文件。

BDD: 版本链遗留待审迭代收口 -> Given：同一受控文件主链已有正式当前版本、一个遗留待审的小版本迭代和一个更高版本的审批完成候选；When：候选完成最终发布并成为当前有效版本；Then：遗留待审迭代必须标记为 `SUPERSEDED`，不得继续使当前有效版本显示“修改中”或阻止下一次真实页面检出。
