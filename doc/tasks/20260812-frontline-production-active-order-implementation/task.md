## Applicable Experience Gates

- 一线生产正式提交必须单事务落链并按唯一生产组长归属可见。
- 禁止恢复旧的自动单订单选择或 `productionSubmitContext.activeOrder` 口径；订单必须来自用户明确选择。
- 活跃订单候选、订单工序映射和组长分配必须使用正式来源，缺失即失败，不做前端猜测或默认切换。
- 选择弹框必须有 loading、empty、error、ready 状态，且不静默覆盖用户已确认的工序和员工。
