# 批记录重复行组对应关系实现

## Task Goal

在现有“批记录单元格链接”页面实现“重复行组”配置能力：只保存当前路线版本、当前工序、当前正式批记录表单版本下，一线生产字段到重复记录行组的对应关系；不在配置页或一线提交时生成批记录数据。

## Milestones

- M1：冻结 PRD 范围、现有代码边界和 BDD 场景。
- M2：用 RED 证明当前系统没有重复行组保存/读取/页面入口。
- M3：补后端重复行组配置 schema、读写接口和校验。
- M4：补前端重复行组模式、候选记录确认和模板字段映射保存入口。
- M5：运行聚焦后端、前端静态/类型验证；真实 E2E 若缺运行数据则记录 blocker。

## Expected Verification

- 后端：重复行组配置保存/读取测试通过。
- 前端：批记录单元格链接重复行组静态合同通过。
- 前端：类型检查通过或记录无关阻塞。
- 真实页面：能进入现有链接页并看到重复行组入口；若本机运行态或正式测试数据缺失，fail fast 记录 blocker。

## 设计约束检查

- 是否引入 fallback/降级/吞异常：否。
- 是否从根因和长期维护角度解决：是；按路线版本、工序、正式批记录表单版本保存重复行组，不按工序名或固定 4 行硬编码。
- 是否存在临时补丁或绕过：否。
