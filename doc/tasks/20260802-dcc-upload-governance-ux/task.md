## Applicable Gates

- DCC 文控审批处理入口门禁：审批和签名必须保持真实 DCC 处理态，不得用 BPM 原生行、直接 API 或 SQL 改状态替代。
- DCC 上传类别权限投影门禁：上传页分类选择必须基于正式 `canUpload` 投影和后端 fail-fast 校验。
- DCC 文件类别规则种子门禁：分类规则与类别来源必须来自正式分类树/规则，不得直接 SQL 修文件分类字段。
- DCC 基础条目关联文档分类树门禁：文件分类树和受控浏览目录不得由当前文件列表、空值或前端硬编码反推。
- 本地 OnlyOffice/受控浏览门禁：受控浏览和预览入口只展示正式可达入口，不用 API-only 或未登录响应冒充可浏览。
