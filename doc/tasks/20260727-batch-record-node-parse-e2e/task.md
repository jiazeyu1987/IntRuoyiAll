# 批记录节点：解析真实浏览器 E2E

## Task Goal

使用 Playwright 在本机前端 `http://127.0.0.1:8081`、租户 `122` 中，按页面真实路径执行“批记录节点：解析”固定样本导入、内容可见性核对和清理闭环。

## Milestones

- [ ] 创建任务记录并完成 E2E、登录、本地运行态、工作区端口和命中经验门禁预检。
- [ ] 进入批记录表单列表，搜索并通过页面删除固定表单“批记录节点-解析样本”。
- [ ] 在导入弹窗中选择固定文件“批记录节点-解析样本.docx”；文件缺失时立即阻塞并停止。
- [ ] 若导入成功，人工核对表格、文字和签名日期区域可见。
- [ ] 若导入成功，删除固定表单并再次搜索确认无结果。
- [ ] 记录截图、实际页面文本、阻塞原因和最终验证状态。

## Expected Verification

- 真实 Playwright 浏览器操作，不使用 API-only、直接 SQL、mock 或替代文件。
- 租户上下文为 `122`，入口为 `http://127.0.0.1:8081`。
- 固定表单命中时必须先通过页面删除，删除入口不可见即停止。
- 固定文件不可选择时必须记录固定样本不存在并停止，不继续导入。
- 导入成功后页面可见固定表单，且表格、文字、签名日期区域均可人工查看。
- 测试结束后固定表单被页面删除，再次搜索无结果。

## 经验门禁

### Element Plus 上传控件门禁

- Trigger: 通过批记录表单列表的 Word 导入弹窗上传固定 `.docx` 文件。
- Preflight check: `setInputFiles` 后必须看到上传列表中的固定文件名，并确认真实上传/识别请求触发。
- Blocker: 固定文件不存在、文件名未进入上传列表、请求未触发或弹窗停留在空上传控件时立即停止。
- Verification: 记录固定文件路径、页面入口、上传列表可见文本、请求和截图。
- Forbidden action: 禁止使用其他文件、API-only 上传或仅以 `input.files` 非空代替组件状态断言。
- Evidence: `docs/e2e-rules.md#element-plus-上传控件门禁`。

### 测试管理测试节点闭环门禁

- Trigger: 执行“批记录节点：解析”固定样本测试项。
- Preflight check: 固定表单先页面清理；导入后页面可见核对；结束后页面删除并搜索无结果。
- Blocker: 删除入口不可见、固定文件不存在、导入结果无法页面核对或清理后仍有结果时停止。
- Verification: 记录四个检查点的页面文本和截图。
- Forbidden action: 禁止只创建不清理、使用其他文件、API-only 清理或残留固定样本。
- Evidence: `docs/e2e-rules.md#测试管理测试节点闭环门禁`。

### eDHR 批记录 Word 表格解析门禁

- Trigger: 批记录 Word 导入和解析内容可见性验证。
- Preflight check: 使用真实固定 Word 文件并通过真实前端上传入口。
- Blocker: 缺少真实源文件或页面入口时不得继续，不得用 mock、截图或其他文件替代。
- Verification: 导入后人工核对表格、文字和签名日期区域。
- Forbidden action: 禁止按表单名或文件名实现特例，禁止用 API-only 或截图替代页面核对。
- Evidence: `docs/backend-development.md#edhr-批记录-word-表格解析门禁`。
