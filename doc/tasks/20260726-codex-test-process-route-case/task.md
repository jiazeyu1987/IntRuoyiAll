## 预期验证

- 本机前端 `http://127.0.0.1:8081` 返回 HTTP 200。
- 本机后端 `http://127.0.0.1:48081/actuator/health` 返回 `UP`。
- 使用 `芋道源码/admin` 登录本机测试管理页面。
- 页面分类中可见唯一分类 `工艺路线`。
- 页面列表中可见本任务新增测试项，详情中的测试方法和检查点与工艺路线真实操作路径一致。

## 经验门禁

- 测试管理页面出现 `系统异常` 时，先核对 `system_codex_test_case` 当前 schema 和分页接口，不得隐藏错误或切换数据源。
- E2E 必须使用 Playwright 走真实前端路径；API 仅允许最终只读核验，不得替代页面新增。
- 写入前必须确认本机入口、`芋道源码/admin` 身份标签和目标数据范围；不得写入远端或未授权租户。
- Element Plus 下拉选择必须按页面可见业务文本定位并确认真实选中，不得用数组下标、隐藏值或坐标猜测。
- 测试管理数据必须使用可追踪名称；本任务创建的数据为用户要求的正式本机测试管理内容，不作为临时 E2E 数据清理。
