# 球囊扩张导管 23 工序正式来源映射审查

## 结论

压力泵既有报表可以作为正式报表容器和布局来源，但不能把压力泵的产品、物料、设备、工艺参数、检验限值原样绑定到导管工序。结合 DCC 中导管专用受控文件后，当前可以形成以下结果：

- 生产批记录内容来源：`20/23` 有导管受控工艺内容，其中 `14` 道可直接对应，`6` 道需从同一受控作业指导书拆分；`3` 道仍无正式内容来源。
- 过程检验候选覆盖：`9/23` 有不与其它工序重叠的直接证据，`7/23` 可从三组共享检验行拆分但尚待 QA 冻结唯一归属，`1/23`（穿显影环）只有压制后结果的条件候选；另外 `6/23` 没有适用的 C/1 条目。
- 仍阻塞生产来源的工序：`外管切缝`、`裁剪圆角`、`球囊盘管（机器）`。
- 仍缺独立过程检验条目的工序：`球囊裁剪`、`外管切缝`、`裁剪管材`、`穿显影环`、`裁剪圆角`、`球囊盘管（机器）`、`纸塑袋封口（包装）`；其中穿显影环存在相关但不充分的条件候选。
- 因此当前不能宣称 23/23 已具备可发布的 MAIN + PROCESS_INSPECTION 正式绑定；20 道生产映射可以作为拟冻结清单，过程检验只能先冻结 9 道直接映射，另外 7 道必须由 QA 先批准唯一拆分规则。

## DCC 版本治理风险

- DCC 数据库把 `B/6`、`C/0`、`C/1` 三份 `PQC-PTCABC-003` 分别建成三个 `ACTIVE_CHAIN`，每条 master 都指向自身，数据库层没有形成同一文件的修订链。
- `B/6` 与 `C/0` 当前对象内容不是有效 DOCX ZIP；`C/1` 和 `A/0` 记录表可以通过 OfficeCLI 正常解析。
- 本审查按文件内受控版本号和可读内容选用 `C/1` 作为“内容最新候选”，但正式发布前仍必须把 controlledFileId `2054545668044064068` 作为冻结输入，不能运行时按 `ACTIVE` 任取第一条。

## 配置边界

1. 压力泵报表只复用报表定义/布局，不复用压力泵业务值。
2. 导管派生报表必须写入上表对应的 DCC controlledFileId、页码/检验行和 SHA-256，保证来源可追溯。
3. 一份受控规程拆成多个路线工序时，必须由工艺/QA 明确每个字段和检验项目的唯一归属；不得让同一 PQC aggregate detail 同时生成两份资料。当前待冻结组为 `11/13 -> C/1 20-21`、`14/15 -> C/1 22-24`、`19/21/22 -> C/1 29-31`。
4. 未补齐 `6/12/20` 的生产来源、`2/6/7/8/12/20/23` 的独立 PQC 规则，并批准三组共享行唯一归属前，不创建或发布 23/23 fixture。
