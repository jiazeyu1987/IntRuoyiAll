# 球囊扩张压力泵表单到球囊扩张导管工序映射审查

## 结论

现有压力泵正式表单不能直接形成导管路线 23 个工序的正式一一对应。

- 源路线：`922119 / RT000028 / 球囊扩张压力泵 / V27 ACTIVE`，14 个工序、14 张 MAIN 生产记录。
- 目标路线：`900025 / ROUTE-XLSX-00001 / 球囊扩张导管 / V9 ACTIVE`，23 个工序。
- 对目标 23 个工序名称执行源 MAIN 布局全文精确检索：`0/23` 命中。
- 对目标 23 个工序名称执行 `过程检验记录 V3.0` 识别结构全文精确检索：`0/23` 命中。
- MAIN 报表本身是 definition `47`、current APPROVED version `130` 的正式报表，但标题、生产依据、物料、设备和参数均属于压力泵。
- 当前 APPROVED PROCESS_INSPECTION report 为 `b48d2a150afc40deb456fb5fe9da551b / definition 51 / version 99 / V6.0`；它可作为正式报表身份候选，但源表 49 条检验方法仍全部属于压力泵工艺，且当前没有 `PQC_AGGREGATE_DETAIL` cell mapping。

因此，下面仅是“语义候选矩阵”，不是可直接落库的正式映射。`无直接对应` 和 `弱候选` 均不得自动绑定。

## 过程检验记录覆盖

`过程检验记录 V3.0` 含 49 条压力泵检验方法：清洗 1、精洗 1、清洁 1、组装 I 2、硅化 I 2、组装 II 4、光固 14、硅化 II/III 2、组装 III 10、检测 12。

- 文档检验依据明确为 `PQC-IDPR-001 按压式球囊扩张压力泵组装过程检验规程`。
- 检验对象包含旋转接头、压力表、延长管、活塞、活塞环等压力泵部件。
- 检测项包含压力泵的无跳压、回零、8/30 atm 气密性等标准。
- 导管 23 个工序名称在该表识别结构中精确命中 `0/23`。
- 目标工序 16、21、23 只能分别与“光固”“检测”“包装/热合”形成条件性结构借用；其余工序缺导管正式检验项目、限值、设备和抽检规则。

该表可以作为“表格布局/字段结构来源”，但不能单独生成 23 个工序的 PUBLISHED QA items/equipment，也不能替代 `PQC_AGGREGATE_DETAIL` cell mapping。
