## Experience Gate Summary

- 浏览器本地目录写入门禁：现有 `showDirectoryPicker`/`LOCAL_WRITTEN` 链路只能证明浏览器下载，不得冒充“文件已进入 DCC 系统”；本任务必须由后端产生正式同步事实。
- E2E 脚本入口存在性门禁：静态合同、API wrapper 和源码检查不能冒充真实页面 E2E；缺少运行态、账号、租户、NAS 样本或可清理数据时要记录 E2E BLOCKED。
- DCC 受控浏览当前有效版与权限隔离门禁：若宣称可在 DCC 正式受控浏览中看到文件，必须额外证明目录、状态、权限和当前有效版本；本任务先实现“NAS 原路径同步记录”查询，不用默认分类或权限扩大冒充正式受控浏览。
- 全量类型检查与静态合同边界门禁：前端静态合同应锁定用户可观察行为和目标代码块，不用宽泛整页关键词扫描制造误判；TypeScript 检查使用单实例 8GB Node 堆。
- NAS 原路径同步静态合同经验：同一页面同时保留浏览器本地归类下载和后端原路径同步时，负向断言必须限定到目标 handler，不能整页禁止 `showDirectoryPicker`。
- DCC 文件类别规则种子门禁：本任务不新增类别规则，不直接 SQL 修改 `dcc_controlled_file` 分类，不把未识别文件强行归类。
- MyBatis Plus 空值更新门禁：删除/解绑路径需要把外键清空时，不能依赖会跳过 `NULL` 字段的默认 `updateById`，必须使用显式清空语句并测试数据库结果。
- 逻辑删除表真实 E2E 断言门禁：逻辑删除表验证“有效记录不存在 + 历史行 deleted=1”，不得用物理行不存在作为默认断言。
