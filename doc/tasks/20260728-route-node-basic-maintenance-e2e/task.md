## Task Goal

使用真实浏览器访问 `http://127.0.0.1:8081`，在租户 `1` 下按固定数据闭环验证工艺路线节点基础维护：前置复位、创建、详情查看和最终删除无残留。

## Milestones

- [ ] 读取并记录本机 E2E、登录、端口、PowerShell 编码和任务收尾规则。
- [ ] 通过真实页面搜索固定路线，若命中则先删除到无结果；删除入口不可见时阻塞。
- [ ] 通过真实页面新增固定路线并保存。

## Expected Verification

- Playwright 使用真实浏览器访问本机前端 `http://127.0.0.1:8081`。
- 本机后端 `http://127.0.0.1:48081/actuator/health` 为 `UP`。
- 登录身份标签记录为 `芋道源码/admin`，不记录密码、令牌、Cookie 或 Authorization。
- 写入数据仅限固定路线编码 `TN-ROUTE-BASIC-001`、固定路线名称 `测试节点-工艺路线-基础维护`、固定说明 `测试节点闭环基础维护`。
- 最终搜索固定名称无结果，证明任务自有测试数据已清理。

## Applicable Experience Gates

- 真实 E2E 必须使用 Playwright 操作真实前端页面；API 只能用于最终只读核验或辅助检查，不得代替页面路径。
- 本机 `int_main` 入口必须成对使用 `8081/48081`，端口归属需确认属于 `E:\IntRuoyi`。
- 登录默认来源为本机前端配置，身份标签仅记录 `芋道源码/admin`，不得输出密码、token、Authorization、Cookie。
- 表格行操作必须按页面可见业务唯一文本定位目标行，不得使用接口数组下标或表头全选。
- 写入型测试节点必须有固定样本、前置复位、页面操作、页面可见验证和清理闭环。
