# Frontend Feature Evidence

## User Flow

- 备份计划页可分别保存每周 FULL 和周一至周六 INCREMENTAL 时间。
- 管理员可显式触发“立即全量备份”或“立即增量备份”。
- 历史列表显示真实备份类型、基线、直接父点和可恢复状态。
- “导出审查证据”按钮只下载后端 ZIP，并使用独立权限控制。

## States

- 保存、开关、立即备份和证据导出均有 loading、成功和失败提示。
- 后端返回 blocker 时页面显示配置异常，不在前端推断为 PASS。
- 无更新权限时保留只读历史与状态视图。

## Verification

- 两个备份计划静态合同测试通过。
- 目标 API 与页面 ESLint 通过。
- 全仓类型检查的 4 个错误均来自未修改 DCC 上传页，并在主工作区复现。
- 未获当轮 E2E 授权，因此未启动服务或执行 Playwright。
