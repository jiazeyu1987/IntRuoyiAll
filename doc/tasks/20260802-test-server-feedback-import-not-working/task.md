# 测试服第三方报工导入不生效原因排查

## Task Goal

分析用户反馈的“测试服务器导入李萍.xlsx 后报工列表不更新、排产工单进度增量为 0%”的原因，区分发布版本、正式报工链路、Excel 数据、测试服工单/任务/人员/工作站配置导致的跳过。

## Milestones

1. 核对测试服发布包与运行态版本。`completed`
2. 核对导入文件解析后的真实行数、工单号、工序号、人员与审批人。`completed`
3. 核对测试服业务库的工单、有效排产单、排产工序、未完成任务、用户与工作站配置。`completed`
4. 按后端导入器执行顺序分类失败原因并输出修复路径。`completed`
5. 补齐测试服用户与工序工作站基础数据。`completed`
6. 复验导入前置条件、执行真实导入验证并确认报工列表/排产进度更新。`completed`

## Expected Verification

- 测试服当前 releaseTag / manifest sourceRepos / 容器镜像是否已是第三方报工修复版本。
- `李萍.xlsx` 按 `parseLiPingDirectWorkReport` 规则解析后的行数和关键字段。
- 测试服 `mes_pro_feedback`、`mes_pro_feedback_import_record` 是否有本次导入新增正式报工或审计记录。
- 逐行确认失败分类：工单不存在、排产工序不存在、未完成任务不唯一、报工人不存在、工作站不存在。

## Applicable Experience Gates

- `docs/backend-development.md#第三方报工直报正式链路门禁`：导入成功必须落到正式报工，不得用导入记录直接进度或前端假新增替代。
- `docs/database-rules.md`：测试服真实数据只读核对；未授权不得直接修测试服业务数据。
- `docs/server-access.md`：测试服远端只读状态和日志核对。
