# 粗洗工序参数配置前端调整

## Task Goal

让“工序配置”里的粗洗工序支持配置并保存 5 个前端可配置参数：清洗次数、清洗介质、清洗功率、室温、清洗时间。

## Requirements

- 清洗次数：整数，默认值 2，不配置上下限。
- 清洗介质：下拉框，可选“自来水”“纯净水”，默认值“自来水”。
- 清洗功率：整数，下限 20，上限 30。
- 室温：一位小数，下限 20，上限 30，默认值 26。
- 清洗时间：整数，默认值 30，不配置上下限。
- 用户明确修正：不是“清洗温度”，字段和界面应表达为“室温”。

## 适用经验门禁

### 一线设备参数默认值门禁

- Trigger: 设备参数默认值、上下限、`lowerLimit`、`upperLimit`、`defaultValue`、清洗功率默认值。
- Preflight check: 数值参数必须优先使用显式默认值；显式默认值为空且上下限同时存在时，运行态默认值由后端统一按中点解析。前端执行 `Number(...)` 前必须显式排除 `null`、`undefined` 和空字符串。
- Blocker: 前端把空默认值转换成 `0`，或用固定常量覆盖正式默认值。
- Verification: 当前任务静态契约必须覆盖清洗次数、清洗功率、室温、清洗时间的默认值/边界定义，并负向证明不再出现“清洗温度”配置。
- Forbidden action: 禁止由前端重复计算范围中点，禁止用 `Number(null)`、单边边界或固定常量补齐空默认值。
