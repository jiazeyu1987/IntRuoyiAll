# 个人中心修复方案编制与主 Agent 评审

## Task Goal
子 Agent 基于当前代码编写个人中心四项已确认问题的修复方案、验收标准和验证计划，主 Agent 独立复核，只有方案无阻塞项才放行。本轮交付文档，不修改生产代码，不执行业务测试或 E2E。

2026-10-06续办：用户要求“补齐文档”。沿用本任务目录，补齐四项问题的根因/修复/验收覆盖、开发前提、实施顺序及性能失败后的停止条件；子Agent补文档，主Agent重新评审，不开始代码开发。

## Scope
- F01 / P1：个人待办及角标遗漏仍可办理的 OVERDUE eDHR 工作任务。
- F02 / P1：工作台多来源仅取首批数据，再做本地分页与筛选，造成任务遗漏及隐藏任务恢复范围不完整。
- F03 / P2：手机号、邮箱前后端必填契约不一致，阻碍只修改昵称。
- F04 / P2：修改密码缺少提交中防重复操作和成功后的表单清空。

## Non-goals
不迁移 ERP/基础配置，不新增交接聚合，不改变共享排产归属，不改变隐藏任务业务含义及角标口径，不恢复个人信息卡片或原始时间行，不扩展权限、密码策略或会话策略。
