# 移除一线 PQC 额外限制

## Task Goal

按用户确认的业务口径，移除一线 PQC 填写链路中未要求的额外限制：不再预生成并强绑 `FIRST/PATROL_AM/PATROL_PM/FINAL` 轮次，不再因终检适用性配置阻断当前首检/巡检流程，不再强制无业务要求的设备/选项约束，不再要求不合格必须填写说明，不再要求绑定正式生产提交事件才能提交。

2026-08-08 追加口径：用户进一步确认“一线 PQC 提交只要电子签名签名了、检验数量大于 0 就可以提交”。本轮修正将前后端提交前置收敛到电子签名密码非空与检验数量正数；其它工单、活跃订单、生产提交事件、任务身份、任务状态、QA 项目逐件明细、设备、损耗说明等只作为可追溯数据或已有页面上下文，不再作为阻断提交的条件。
