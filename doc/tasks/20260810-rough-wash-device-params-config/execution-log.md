# Execution Log

## User Intent

用户要求粗洗工序的 5 个设备参数在前端工序配置里可配置：

- 清洗次数：整数，默认 2，不要上下限。
- 清洗介质：下拉框，可选自来水、纯净水，默认自来水。
- 清洗功率：整数，下限 20，上限 30。
- 室温：1 位小数，下限 20，上限 30，默认 26。
- 清洗时间：整数，无上下限，默认 30。

## BDD Scenarios

BDD: 粗洗设备参数可配置 -> Given 用户进入工序配置的粗洗参数配置区域, When 查看或编辑粗洗设备参数, Then 清洗次数、清洗介质、清洗功率、室温、清洗时间均由前端配置定义类型、默认值、范围或选项。

BDD: 粗洗参数默认值符合要求 -> Given 粗洗工序没有用户覆盖值, When 前端初始化参数配置, Then 清洗次数为 2、清洗介质为自来水、室温为 26.0、清洗时间为 30。

BDD: 粗洗参数校验规则符合要求 -> Given 用户编辑粗洗设备参数, When 输入清洗功率或室温, Then 清洗功率限制为 20 到 30 的整数，室温限制为 20 到 30 且保留 1 位小数；清洗次数和清洗时间不配置上下限。
