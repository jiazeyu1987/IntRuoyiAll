# 测试文件与报告存储位置

1、本目录按权限管理目录的四类文件组织，仅保留：审批中心模块测试清单.xlsx、审批中心模块测试方案.md、审批中心模块测试报告模板.xlsx和README.md。这里存放可复用计划，不存实际执行报告。

2、执行人员或测试执行工具读取方案和清单后，依据当前环境及仓库规则自行准备工具、账号、权限和输入数据；凭据单独交接。39项功能、77条唯一用例包含73条交叉用例，不重复计数。用户排除的A33-02、A36-01、A36-02不再验证。

3、每轮结果保存到仓库根目录ruoyi_test/report/审批中心/{时间戳}/，时间戳使用北京时间yyyy-MM-dd-HH-mm-ss。从本目录出发的相对位置为../../report/审批中心/{时间戳}/。

4、将报告模板复制到本轮目录，命名为审批中心模块测试报告.xlsx，填写实际环境、版本、用例对象、结果、证据及缺陷。截图、日志和下载文件保存在同轮目录，报告填写相对路径。模板初始全部未执行，不能直接当作通过结果；保留历史轮次，不覆盖计划模板。

5、清单的测试结果默认留空；模板的执行明细预列77条，交叉标识与清单一致。轮次信息按执行状态统计。每个用例全部子场景完成才可记成功；当前可执行范围和缺少的前提应由执行端据实核对。

6、计划目录不写本机端口、机器路径、登录态、密码、token、工具缓存、临时脚本或历史执行结果。换版本需重新记录轮次，不能把此前测试结论套用到新代码。报告及证据脱敏后再按仓库约定管理。
