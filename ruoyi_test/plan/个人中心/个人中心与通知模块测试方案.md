# 个人中心与通知模块测试方案

1、范围：49条唯一用例，覆盖入口与路由、个人资料、密码、社交页签角色可见性、工作台自身交互、本人通知和会话隔离。不包含模块交叉sheet，不测试其他业务模块的审批、签收、完成或撤权闭环。

2、执行端依当前仓库规则组织本轮测试，记录实际前后端地址、版本及证明、租户、账号逻辑名、数据标识和执行时间及其时区。环境地址、租户名称、端口、工具和账号由实际环境提供，不依赖固定公司、电脑、盘符、缓存或旧脚本。凭据单独安全交接，不写入计划、报告或截图。

3、所有准备数据和验收动作均通过Playwright操作真实前端，不用API、数据库写入或mock代替；结果须由本轮真实页面和证据支撑。缺少前提只阻塞依赖项，其余可独立执行。页面本身的加载失败须如实记录，不当作空数据或成功。

4、P表示执行端生成的本轮唯一数据前缀。A、B为同一测试租户的两个专属普通账号，联系方式互不重复；E为无消息的空账号；M为具备账号准备及专属通知模板测试发送权限的管理员。管理员和普通账号使用独立会话，A另开第二会话用于并发与失效测试。名称为逻辑约定，实际账号和数据ID写入本轮报告。

5、先记录A/B资料基线，再准备唯一昵称、合法手机号、不同长度邮箱、错误格式、前后空格和重复联系方式。昵称30/31字、邮箱50/51字符分别覆盖边界。改密使用符合当前密码策略的新密码并安全保管，记录历史关系而不记录明文；成功改密后及时更新本轮私有凭据。

6、通过真实页面准备或确认本任务专属待办集合N，N大于10，记录完整标识、类型、来源和详情用于展示、筛选、排序及分页。仅验证工作台本身，不处理来源业务；同一来源数据可用于组件行为验证，不据此宣称多来源聚合通过。另保持B工作台为空。隐藏/恢复仅操作本轮专属任务T，结束后恢复基线；双会话测试核对最终唯一状态。

7、管理员通过实际通知模板测试发送入口向A/B发送带P和连续序号的专属消息。记录发送前集合、实际发送顺序与正文，本轮A消息数M大于10；B独立保留未读，E保持无消息。正文覆盖中文长文、换行、引号及HTML样式文本。发送仅为测试准备，不将模板管理业务计入验收范围。无前端准备入口时准确记录缺失前提。

8、执行顺序按依赖安排：确认环境与账号→资料校验与持久化→工作台筛选、分页、隐藏恢复、配置、断网和并发→专属通知发送及铃铛→阅读、筛选、跨页、断网与账号隔离→双会话轮询→真实改密与历史密码→退出和切账号。密码修改安排在依赖原会话的用例之后。

9、用户明确取消头像入口、上传裁剪、列顺序调整、第三方OAuth社交绑定、跨租户隔离；这些项目不列为待测、阻塞或后续补测，也不计为通过。配置迁移和其他模块联动同样不在范围。N11只测列显隐与宽度，N13只测同租户账号隔离，P21只测页签可见性。

10、所有子场景和断言都有本轮证据才记通过；业务不符记失败、缺前提记阻塞、只做部分记部分执行、未开始保持未执行。取消和失败需核对原集合及字段未变，刷新和重新登录核对持久化；并发要核对两会话最终状态。填写报告模板并关联脱敏证据和缺陷复验；结果位置见README.md。

|P01|入口|默认个人中心|管理员和A已可登录|分别从首页及用户菜单进入个人中心|默认个人工作台，身份一致，无空白页|
|P02|入口|站内信入口与直达|A已登录|从铃铛查看全部、个人中心页签、独立站内信路由进入|三入口均显示A的同一消息集合|

|P04|资料|资料初始值|A昵称、手机、邮箱、性别已知|打开基本资料，逐字段对照本轮准备数据时记录的账号A基线|四字段与A一致，不显示B资料|
|P05|资料|修改保存持久化|A手机号邮箱唯一|将昵称改为本轮唯一前缀加资料修改标记，保存专属手机、邮箱及性别；刷新和重新登录|各字段保留新值，顶栏昵称同步，B保持原值|
|P06|资料|重置放弃编辑|记录A已保存值|修改四字段但不保存；点重置|恢复已保存值，刷新后仍不变|
|P07|资料|昵称必填与长度|A已登录|分别提交空昵称、30字、31字昵称|空值与31字拒绝；30字可保存，失败不改原资料|
|P08|资料|手机格式边界|记录原手机号|分别输入10位、12位、字母及合法11位手机号保存|非法拒绝且原值不变，合法值保存|
|P09|资料|邮箱格式与长度|记录原邮箱|分别输入错误邮箱、50字符合法邮箱、51字符邮箱|错误和超长拒绝，50字符合法值可保存|
|P10|资料|重复手机邮箱|B已设置独立联系方式|A分别保存B的手机号和邮箱|明确重复错误，A其他字段不被部分更新|
|P11|资料|联系方式空值与空格|A有已保存联系方式|分别清空手机邮箱；再填前后空格的合法值|清空明确拒绝；前后空格被去除后正确保存|
|P12|资料|本人保存与重复点击|A已知原资料|不修改直接保存；再双击保存新的昵称|本人联系方式不误判重复，最终资料一致|
|P13|资料|未保存切换与账号隔离|A、B双会话|A改字段不保存，切页重载；B打开资料|A仍为原保存值，B只见自己的资料|
|P16|密码|空值弱密码及不一致|A原密码有效|空提交；输入弱密码；两次新密码不同|逐项明确校验，不退出且原密码有效|
|P17|密码|错误旧密码|A原密码已知且未锁定|填错误旧密码和有效新密码提交|明确失败，原密码仍可登录，现有会话不被撤销|
|P18|密码|重置密码表单|A已输入三项内容|点重置|三项及校验提示清空，不修改密码|
|P19|密码|成功修改及多会话失效|A有两个真实登录会话|改为新密码；在另一会话刷新受保护页面；旧新密码各登录一次|当前退出，旧会话失效，旧密码失败，新密码成功|
|P20|密码|历史密码禁止复用|P19完成且记录旧密码历史|使用当前密码尝试改回旧密码|明确拒绝复用，当前密码及会话保留|
|P21|社交绑定|按角色显示|超级管理员与普通A|分别查看社交绑定页签，普通账号访问带type参数的个人中心|仅super_admin可见社交绑定，A仍落工作台|
|W01|工作台|空待办与刷新|无待办的专属测试账号B|打开工作台并刷新、切已隐藏|成功加载时显示0及空态，不把加载失败显示成0|
|W02|工作台|汇总与唯一性|A有本轮专属待办，数量N大于10，已记录完整标识集合；仅核对工作台展示|核对列表数量、详情、任务标识及各处待办角标|列表无重复遗漏，各处待办数量一致|
|W03|工作台|过滤与排序|已有不同标题的专属待办|使用当前任务类型、来源、详情筛选；检查逐列排序并清除条件|筛选命中当前数据，排序正确，清除恢复完整集合|
|W04|工作台|分页完整性|专用账号超过10条待办|逐页记录任务；换每页条数再核对|无重复遗漏，总数不随页数改变|
|W05|工作台|隐藏取消|A有一个专用待办T|点T隐藏，核对标题，取消后刷新|取消隐藏后目标仍在待办，隐藏数量不变|
|W06|工作台|隐藏确认与持久化|W05数据保留|确认隐藏T，刷新并重登，进入已隐藏|目标刷新、重登后仅在已隐藏出现，隐藏数正确|
|W07|工作台|恢复隐藏任务|W06完成|恢复T并刷新|目标恢复待办且只出现一次，隐藏数减1|
|W10|工作台|个人列配置|A、B均有工作台入口|A隐藏可选列、调列宽并刷新重登；B核对|A配置持久化，操作列保留，B不受影响|
|W11|工作台|加载失败与恢复|工作台已正常加载|浏览器断网后刷新，再恢复网络并刷新|显示加载失败，操作不可用；恢复后真实列表重载|
|W12|工作台|快速切换与并发操作|A两个真实会话及专属待办可用|快速切换筛选、分页及隐藏页；双会话隐藏和恢复同一任务|最终状态对应当前查询，无重复任务或旧响应覆盖|
|N01|通知|发送与接收|专属通知模板、A/B账号均可操作|管理员通过模板测试发送分别给A、B，内容含唯一序号|A/B各收到自己的消息，发送人、正文、时间正确|
|N02|通知|空消息列表|新建且未收消息的A|打开铃铛和我的站内信|空列表，无红点，无历史他人消息|
|N03|通知|铃铛最近10条|记录A已有消息集合；前端发送带本轮唯一前缀和连续序号的新消息，数量M大于10|打开铃铛，按实际发送时间核对最新10条；再到完整列表逐页核对本轮发送记录|铃铛展示最新10条且顺序正确；完整列表总数等于原有数加M，本轮消息无重复遗漏|
|N04|通知|未读红点一致性|A有多条未读专属消息|重载核对铃铛、站内信页签；读取1条后重开铃铛|有剩余未读时红点保留，实际未读数减1|
|N05|通知|阅读单条及详情|A至少2条未读且一条无业务跳转|点第一条阅读，核对详情、状态、发送和阅读时间，刷新|该条已读且有阅读时间，其他条保持未读|
|N06|通知|重复查看已读|N05已完成并记录阅读时间|多次开该条详情并刷新|不重复修改首次阅读时间，无重复数据|
|N07|通知|全部阅读含跨页|A超过10条未读，B有未读|A点全部阅读，逐页、刷新、重登并登录B核对|A全部已读红点清除；B仍未读，消息总数不变|
|N08|通知|全部已读时再阅读|N07已完成|再次点全部阅读并刷新|保持已读，无新增消息，无阅读时间重写|
|N09|通知|已读未读过滤|A已读未读混合|按是否已读切换筛选，再清除|两集合互斥且并集等于全部，筛选后从第一页开始|
|N10|通知|消息分页完整性|A至少12条带唯一序号消息|逐页、切每页条数核对序号集合|无重复遗漏，合计与发送记录一致|
|N11|通知|通知列配置|A、B均有消息|A调整列显隐及宽度，刷新重登；B核对|A配置持久化，操作列保留，B配置不受影响|
|N12|通知|详情关闭与页面切换|A有消息|开关详情、切工作台再返回、前进后退|关闭状态正确，无残留弹窗及布局错位|
|N13|通知|账号隔离|同租户A/B及空消息测试账号|分别登录查看、阅读本人消息，对照其他账号状态|账号间不串消息，A阅读不改B；空账号无其他人消息|
|N14|通知|普通文本与特殊字符|专用模板含中文长文、换行、引号和HTML样式文本|发送后查看铃铛、列表及详情|内容可辨认且无脚本执行、原始路由泄露或页面破坏|
|N15|通知|发送取消与缺参|有参数的专用模板|分别取消发送、缺接收人、缺必填参数提交|取消及失败均不新增消息，明确校验|
|N16|通知|读取失败不能伪成功|A有未读专用消息|浏览器断网后阅读/全部阅读，再联网刷新|失败明确且状态未误报已读；联网后仍可重试|
|N17|通知|多会话阅读与红点同步|A两个会话及两条未读|会话1读取，再在会话2刷新和等待轮询|同条只保留首次阅读时间，刷新和轮询最终显示真实状态|
|S01|会话|退出后受保护页面|A已登录|退出后用后退、个人中心直达及站内信直达|要求重新登录，不泄露缓存资料或消息|
|S02|会话|无权限账号最小访问|无业务菜单权限的A|访问个人中心和我的消息，尝试工作台来源及管理通知页面|本人资料消息可用，无权限管理入口及来源不可越权|
|S03|会话|切账号清缓存|A有资料列配置消息待办；B不同|同一浏览器退出A并登录B，快速切各页签|资料、消息、工作台及角标均为B，无A残留|

49条为唯一用例，不重复统计。本方案及报告模板不包含既往或本轮执行通过结论。
