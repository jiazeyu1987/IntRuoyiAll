# DCC产品目录与项目代码联合测试资料

1、本目录只保留README.md、测试方案.md、测试清单.xlsx、测试报告模板.xlsx。两个模块为一个测试单元，共44条唯一用例，其中5条模块关联用例已包含在总数内，不重复计数。

2、执行端先读取当前仓库规则和方案，再按自己的环境预约独立服务槽位、准备工具与逻辑账号。计划不含环境地址、账号凭据或既往执行结论。清单结果留空，报告模板全部未执行。

3、先用虚拟测试数据联合新增，完成当前角色审核、驳回重提，再验证普通管理与删除；包含该流程必要的审批中心和签名。注册证全部操作、无关审批及文件发布仍排除。目录整包导入导出混合注册证而不执行。普通项目导入导出、待审撤回、完整优先级/状态筛选及底层关系核验因页面缺失已从用例清单移除；不能调用接口替代。

4、每轮复制报告模板至../../report/DCC产品目录与项目代码/{轮次标识}/，命名测试报告.xlsx。轮次标识使用北京时间yyyy-MM-dd-HH-mm-ss。截图、日志、下载文件、缺陷和代码依据均置于该轮目录，通过相对路径关联，保留历史轮次。

5、真实业务动作全部用Playwright操作前端，禁止API/DB写入、mock及伪造审核数据。只有实际证据齐全才能标通过；前提不足标阻塞。报告及证据不保存密码、令牌、Cookie或登录态，不覆盖计划模板。

6、按用户要求，另移除C12、X07、P12三个缺少测试数据前提的用例；累计移除11项，均不计通过，保留用例不重新编号。
