# 测试文件与报告存储位置

1、本目录由 Git 管理，只保留四个文件：电子签名模块测试清单.xlsx、电子签名模块测试方案.md、电子签名模块测试报告模板.xlsx 和本说明。

2、执行端读取方案和清单，遵守当前仓库规则，自行准备工具、服务、测试账号及输入数据。共 58 个唯一用例，本模块 23 项、模块交叉 35 项，两表互斥、不重复计数；保留原 ES 编号，ES13 不在当前范围。实际租户、账号与环境由执行端确认，凭据单独交接。

3、每轮结果保存到仓库根目录的 ruoyi_test/report/电子签名/{时间戳}/，时间戳采用北京时间 yyyy-MM-dd-HH-mm-ss。从本目录出发的相对位置为 ../../report/电子签名/{时间戳}/。执行端创建本轮目录，不依赖固定盘符、用户名或旧机器目录。

4、复制报告模板到本轮目录，命名为电子签名模块测试报告.xlsx，填写实际环境、前后端版本、租户和账号逻辑身份、数据编号、逐项结果与证据。截图、日志及下载文件存放在同一轮次目录，用相对路径关联；缺陷与回归记录写入报告。模板初始全部未执行，不能作为已通过结果。

5、plan 目录只存可复用测试资料，本轮实际结果、机器配置、凭据、临时脚本和工具依赖另行存放。保留历史报告，不覆盖计划模板；报告与证据按仓库约定脱敏，不写入密码、令牌、私钥或登录态。新环境须重新执行，不能继承其他轮次的通过结论。
