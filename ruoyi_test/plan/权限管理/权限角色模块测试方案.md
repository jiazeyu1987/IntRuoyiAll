# 权限角色模块测试方案（本机适配）

1、范围：26项功能、57个唯一用例，含32条交叉用例；交叉sheet是重复展示，不另计数。审计、审查及已有历史任务不测试。

2、所有路径以当前Git仓库根目录为基准：计划在ruoyi_test/plan/权限管理/，报告在ruoyi_test/report/user_manager/{北京时间戳}/，不绑定盘符或电脑用户名。执行前按docs/branch-runtime-ports.md和实际监听服务核对前后端地址、运行包及源码版本，不能把已拉取代码或已构建包当作正在运行的新版本；实际值填报告，不复用旧机器的端口、缓存、脚本或配置。账号凭据单独交接，不写入本目录或报告。

3、本机主测试租户统一为芋道源码。所有业务准备和被验收动作走Playwright真实前端，不用API、数据库写入或mock替代。普通功能在此租户内用本轮专用分类、角色、账号和独立会话隔离，不强制创建额外租户。R22-02、R26-02及R27-01至R27-04保留额外环境前提：跨租户/套餐边界须有另行提供且允许操作的独立租户与套餐；eDHR产品目前仅允许芋道源码导出、瑛泰集团预览和确认导入。仅有芋道源码时，相关缺失子场景记阻塞，已做部分记部分执行，不把同租户测试当作跨租户或成功迁移通过；不为补前提自动创建、改名其他租户或修改共享套餐。

4、P是本轮唯一且由数字、字母组成的数据前缀。芋道源码内只准备一组分类A/B（P_a、P_b）和角色A/B（P_read、P_create），记录实际ID，后续用例复用并按前提恢复状态。U为本轮普通用户，testAdmin为已交接的测试管理员，两者使用独立会话；boundaryUser、targetUser仅用于第3条条件用例，缺少前提不创建。真实用户名须为4至30位数字、字母，报告记录逻辑别名与实际账号的映射；例如将P与u、child16、child17、childrev等后缀拼接成不同账号，不把带下划线的角色编码当用户名。

5、芋道源码内的角色A只授用户页面和查询，B在此基础上增加用户新增，不授删除；普通用户无管理员、临时角色或动态扩大授权。管理员和普通用户使用独立会话，按用例恢复U无角色、仅A、A+B或仅B的状态。撤权用例保留U原会话。R12临时授U角色页面查询以调整列；R22-03单独准备仅角色页面查询角色，验证后恢复授权。新增成功、权限叠加及撤权尝试使用不同的专用账号，防止重名错误被误判为撤权生效。

6、R08-01将同一组角色中的A移入分类B并保存备注，R08-02接着验证这条角色编辑取消；此时分类A为空、分类B含两角色，供空分类删除、非空拒绝、关联保留和JSON导出使用。分页另用本轮专用分类及N>10条角色，记录完整ID集合。芋道源码内的scopeUser与Peer同部门、Other异部门，三个专用账号无扩大范围的其他角色；所需部门通过页面准备或确认，只处理本轮数据。批删另准备两条待删角色和未选中对照。

7、测试输入由执行端自行准备：有效JSON以芋道源码本轮页面导出的v3包为基础，改为尚不存在的分类/角色编码；更新包保持同编码。异常分别构造空文件、坏JSON、非v3、缺角色编码、第二角色引用不存在菜单。R22-02仅在额外前提已具备时准备越界包、第一角色合法第二角色越界包和合法包；边界套餐允许角色查询、导入等所需功能但不含system:role-category:create。菜单键以本轮实际环境为准；异常前后核对集合，不能将合法菜单缺失误判为业务通过。

8、eDHR导出使用芋道源码中新建的P_migrate角色、两个专用账号及真实页面导出文件。迁移角色使用产品支持的全部数据或仅本人范围，不与R24部门范围角色混用；迁移副本仅保留任务账号/角色，目标编码沿用本轮真实导出关系，不借用旧编码。空/非xlsx/超5MB样本可在本机校验；不存在或停用目标、重复映射、有效预览及确认导入须在产品允许且已交接的目标租户执行。目标用户只保留本轮原角色，迁移角色尚不存在，先建立并验证新密码和新测试签名基线，密码不入报告。不得为适配本机把工作簿中的目标租户改成芋道源码。

9、执行次序依据依赖安排：先核对运行版本和账号前提，再分类/角色创建编辑、授权和用户联动、导入导出，最后清空菜单和删除。R04-01需等B有角色后补改名与关联保留；R15人数补齐0→1→0；R27目标租户相关操作仅在前提具备后按预览、异常、首次确认、重复确认执行。缺前提只阻塞依赖它的子场景。每项完成所有子场景才可判通过；运行版本或方案验收标准变更另建轮次，不覆盖之前报告。

10、通过需全部断言及本轮证据；业务不符记失败，缺前提记阻塞，只做部分记部分执行，未开始保持未执行。取消核对前后集合；新增/删除核对ID及人数/数量；权限生效由普通用户真实操作验证；文件导出读回数量、内容与范围。填写报告模板并关联证据，失败保留缺陷及复验记录，不采用历史通过结果。报告位置见README.md。
