# 测试文件与报告存储位置

1、本目录由Git管理，只保留四个文件：权限角色模块测试清单.xlsx、权限角色模块测试方案.md、权限角色模块测试报告模板.xlsx和本说明。计划目录为ruoyi_test/plan/权限管理/；user_manager仅为报告目录名，测试对象是权限角色模块。

2、本机主测试租户为芋道源码，普通功能使用本轮专用分类、角色、普通账号及管理员独立会话；不要求为普通功能另建租户。真实用户名须为4至30位数字、字母，示例中的逻辑别名和角色编码不能直接当作用户名。凭据单独交接，不写入测试资料。57条唯一用例含32条交叉用例，不重复计数；审计、审查及已有历史任务不测试。

3、所有路径相对当前Git仓库根目录，不绑定盘符或电脑用户名。每轮结果保存到ruoyi_test/report/user_manager/{时间戳}/，时间戳使用北京时间yyyy-MM-dd-HH-mm-ss；从本目录出发为../../report/user_manager/{时间戳}/。前后端地址按docs/branch-runtime-ports.md及实际运行服务核对，只填本轮报告；代码已拉取或包已构建不能代替运行版本核验。

4、将报告模板复制到本轮目录，命名为权限角色模块测试报告.xlsx，填写实际环境与版本、各用例结果、证据路径及缺陷；截图、日志和下载文件保存在同一轮次目录内并由报告关联。模板初始为未执行，不能直接当作通过结果。保留之前轮次，勿覆盖计划模板和历史报告。

5、plan目录只存可复用测试资料；本机配置、密码、工具依赖、临时脚本和实际执行结果不放入其中。报告及证据应脱敏后再按仓库约定管理，不写入密码、token或登录态。

6、R22-02、R26-02及R27-01至R27-04为条件用例：跨租户/套餐边界需另行提供允许操作的独立环境；eDHR产品目前仅允许芋道源码导出、瑛泰集团预览及确认导入。本机单租户范围缺前提时记阻塞，已完成部分子场景记部分执行，保留全部断言及57条总数。不为补前提自动创建、改名其他租户、修改共享套餐或改写工作簿目标；R27-05仍在芋道源码验证错误租户拒绝。

7、调整方案时同步清单的详细用例、交叉用例与报告模板的名称、前提和通过标准；模板不预填业务通过或失败。实际执行产生的对象ID、账号映射、状态恢复及遗留数据记录在本轮报告中，不写死在计划里。
