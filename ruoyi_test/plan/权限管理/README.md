# 测试文件与报告存储位置

1、本目录由Git管理，只保留四个文件：权限角色模块测试清单.xlsx、权限角色模块测试方案.md、权限角色模块测试报告模板.xlsx和本说明。目录名user_manager按约定保留，实际测试权限角色模块。

2、执行端Codex读取方案和清单后，依据自己的环境及当前仓库规则组织测试，自行准备工具、测试账号和输入数据；凭据单独交接。57条唯一用例含32条交叉用例，不重复计数，审计、审查及已有历史任务不测试。

3、每轮结果保存到仓库根目录下的ruoyi_test/report/user_manager/{时间戳}/，时间戳使用北京时间yyyy-MM-dd-HH-mm-ss，例如2026-11-03-15-30-00。从本目录出发的相对位置为../../report/user_manager/{时间戳}/。

4、将报告模板复制到本轮目录，命名为权限角色模块测试报告.xlsx，填写实际环境与版本、各用例结果、证据路径及缺陷；截图、日志和下载文件保存在同一轮次目录内并由报告关联。模板初始为未执行，不能直接当作通过结果。保留之前轮次，勿覆盖计划模板和历史报告。

5、plan目录只存可复用测试资料；本机配置、密码、工具依赖、临时脚本和实际执行结果不放入其中。报告及证据应脱敏后再按仓库约定管理，不写入密码、token或登录态。
