# 共同业务契约与接口边界

版本SC-1.0，2026-09-30。以下是跨线程必须遵守的业务合同；具体Java/TS字段名、SQL及接口URL由模块提出后主管理Review，不能各自实现不同命名。未给出的参数不得硬编码或猜测。

## 1. 两种版本定位

- **最新受控版本：**最近完成文控审核和受控的正式版，允许生效日期在未来；关联入口必须解析此版本并显示待生效。
- **当前执行受控版本：**已生效、尚未作废、当前可执行的版本。新版提前受控时仍保留旧版为当前执行版；新版生效时切换并自动作废旧版。
- 两个定位在生效前可以不同，不能继续仅用现有Master.currentActiveControlledFileId同时表示两者。现有字段是否保留语义或新增指针，须在G1决定并审查所有调用点。
- 名称查看、正文预览、正式下载打印、引用、关联、版本详情分别使用约定权限和版本定位；不能把“最新受控但待生效”当作已生效执行文件。
- 生效切换应同事务更新新旧状态与执行定位，并具有并发锁、幂等和可审计结果；不能新旧同时执行或先作废旧版后新版切换失败。

## 2. 流程

上传/升版：会签（部门负责人指派＋实际会签）→批准→可选培训→文控审核→受控→下发。

作废：会签→批准；批准通过作废并结束，不创建培训、文控审核、受控或下发节点。纸件后续处置是独立记录，不能使作废流程继续。

会签和文控审核应有真实签名证据。负责人指派签名不代替被指派人的会签签名，同一用户多个部门义务不能按userId去重。

2026-10-01用户补充已确认：培训节点由文控上传当前文件本次申请的线下培训文件即可完成，随后文控审核；不得另加逐人线上确认、全员培训核验或第二培训批准。票据仍必须对应真实文件/版本/申请轮次，实际失败不能报告完成。

下发没有失败/驳回业务分支；实际网络、存储、权限或事务失败必须真实报错，不能默认成功。文控下发不能覆盖生效日期或修改已受控正文。

## 3. 日期与提醒

编制时预设生效日期；受控日期由系统记录；二者分开。到新版生效日期，旧版自动作废，不在受控时提前作废。A负责文控日期合理性检查及按生效日期升序提醒。

日期已过时的重新审批处理等未定细节保留待讨论；明确配置字段及真实失败，不静默设为今天或另猜提醒天数。

## 4. 项目默认属性与申请快照

三组属性：目标市场（含其他说明）、注册/生产身份（两个独立选择）、文件转移及目标。B定义共用值对象及页面组件；主管理落地公共申请字段。

- 上传、升版、作废新申请均从所属项目当前默认值初始化，用户可改。
- 保存草稿后读取草稿值，不能刷新覆盖为项目默认；新一轮申请的初始化与原申请返工回显要区分。
- 提交后保存默认值来源和实际值快照；改项目不改在途或历史。
- 作废申请快照单独保存，不覆盖原受控版本属性。
- N/A互斥、市场多选及“转移至”文本语义属于现有建议，G1须明确是否正式采用；MADSAP原拼写不自行更改。

## 5. 版本与名称

C提供统一版本规则服务：小版本A/1-1、A/1-2；局部A/1→A/2、A/9→B/1；换版A/3→B/1。正式变更类型必须保存实际操作，不能从字母增加推断；详情和历史显示每版自己的类型。

完整文件名含后缀，只有大小写全部一致才同名。SOP.pdf与sop.pdf、SOP.PDF、SOP.docx均不同。判重须跨全部项目且按源文件完整名称；模板显示名、生成的受控PDF名称不是替代键。C方案需审查trim、大小写、字符排序及唯一约束的语义。

保留期内作废文件占原名称与编号；同一逻辑文件链自身升版仍可沿用。A产生作废事实、调用C的保留期占用服务；C不能另外修改A的作废事务。2026-10-01用户确认作废文件保存20年，本轮实施自实际作废日期起算；期限不再列未知。期满处置/释放权限未确认，不自动删除历史证据或释放在用身份。

引用和取消引用仅当前目标项目的项目负责人；其他项目负责人、普通成员以及未担任该项目负责人的管理员不能仅凭菜单权限办理。不能直接把“任何OWNER候选用户”当唯一负责人；必须明确身份合同。

## 7. 关联、引用及事件

- D关联记录稳定文件身份；当前关联取最新受控版本，历史审批快照取当时版本。两条查询不可混用。
- 引用是项目/文件夹到文件身份的关系，关联是文件到文件。不能共用一张业务关系来冒充两种语义。
- D保存会签阶段的关联整改负责人和期限；A在会签指派操作中正式提交这份安排。
- **受控事件：**A在实际受控成功后触发，D只通知本申请明确选择的关联整改人；原用户要求此时通知，不能改为生效日通知。
- **生效事件：**A完成新旧切换后触发，D不得以此替代受控事件。事件均带租户、逻辑文件、版本、申请轮次及幂等身份，失败/撤回不产生成功事件。
- 同一项目多个文件夹引用同一文件按项目计数1；取消最后一个引用才减项目数。D执行计数与权限，B提供目录身份。
- 引用是否自动跟随最新受控版尚未确认；交关系存储及可配置策略方案，不擅自把关联规则套给引用。
