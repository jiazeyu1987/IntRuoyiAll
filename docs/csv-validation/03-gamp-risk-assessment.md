# 03 GAMP 分类与风险评估

## 1. 目的

按 GAMP 分类和质量风险管理方法，确定 IntRuoyi 各功能的验证深度、优先级和测试策略。

## 2. 评分方法

| 维度 | 1 | 3 | 5 |
| --- | --- | --- | --- |
| 严重度 S | 不影响 GxP 记录或质量结论 | 影响流程效率或辅助判断 | 可能影响产品质量、患者安全、放行、签名或数据完整性 |
| 发生概率 O | 少见，受强控制 | 可能发生 | 频繁或复杂链路容易发生 |
| 可检测性 D | 自动检测并阻断 | 事后可发现 | 难以及时发现或发现后影响已发生 |

RPN = S x O x D。

| RPN | 风险等级 | 验证策略 |
| --- | --- | --- |
| 1-20 | 低 | 设计评审 + 目标确认 |
| 21-50 | 中 | OQ + 必要 PQ + 数据/权限验证 |
| 51-125 | 高 | 完整验证：URS/FS/风险/IQ/OQ/PQ/DI/SEC/RTM/偏差关闭 |

## 4. 验证深度结论

| 范围 | 最高风险 | 验证深度 |
| --- | --- | --- |
| eDHR/MES 批记录和放行 | 高 | 完整 URS/FS/IQ/OQ/PQ/DI/SEC/RTM |
| DCC 文控和注册证 | 高 | 完整 URS/FS/IQ/OQ/PQ/DI/SEC/RTM |
| 电子签名和 GxP 审计追踪 | 高 | 专项安全、数据完整性、留存、恢复和周期审查验证 |
| ERP/BPM/对象存储/备份接口 | 高 | 接口验证、对账、失败关闭、恢复演练 |
| 表单中心/Word 解析 | 中/高 | 真实样本、边界、失败关闭和无写入 parse-only 测试 |
| 基础设施 | 中 | IQ、配置确认、版本和供应商评估 |
