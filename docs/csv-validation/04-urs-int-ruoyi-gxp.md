## 2. 预定用途

IntRuoyi 预定用于支持生产、质量、文控和受控记录管理，包括生产订单进入活跃池、一线报工、PQC 检验、批记录形成、受控文件管理、注册证管理、电子签名、审计追踪、备份恢复和质量放行。系统应保证相关电子记录准确、完整、一致、原始、可归属、可读、可追溯、可检索并按批准期限留存。
