# IntRuoyi CSV 正式送审分册包

## 使用定位

本目录用于药监现场核查或外部审核沟通的 CSV 分册式交付。分册采用“目录导读 + 总计划 + 系统影响 + 风险评估 + URS + FS + IQ/OQ/PQ + RTM + 偏差/CAPA + 供应商 + VSR + 持续验证 + QMS/培训/审批”的结构，避免把全部内容塞进一个文件。

重要边界：本目录提供正式送审结构和待签文件，不伪造企业签章、已执行测试结果、培训记录、供应商资料或生产运行证据。对外提交前，企业 QA、业务、IT、系统所有者、验证负责人、培训、供应商管理和文件管理员必须补齐真实记录并签署。

## 提交前必须补齐

- 企业正式文件编号、版本、生效日期、受控状态和归档位置。
- QA、业务、IT、系统所有者、验证负责人和文件管理员签字。
- 已执行 IQ、OQ、PQ 原始记录、证据截图、执行人、复核人和日期。
- 真实或经 QA 批准的代表性生产数据、性能标准和 PQ 结果。
- 偏差/CAPA 根因、影响评估、纠正预防措施、复测和 QA 关闭。
- 培训签到、考试、实操、补训、岗位授权和权限开通前置记录。
- 供应商评估、质量协议、SLA、外部系统变更通知和接口对账记录。
- 备份恢复演练、审计追踪抽样、电子签名复核、权限复核和周期回顾。

## 送审建议

对外提交时建议先提交 `00-送审目录与审查导读.docx` 和 `12-验证总结报告VSR.docx`，再按老师要求展开对应分册和原始附件。若任何高风险执行证据未完成，应在 VSR 中如实列为限制项、风险接受或整改计划，不得写成已完成验证。
