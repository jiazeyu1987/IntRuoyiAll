# 09 供应商与外部依赖评估

## 1. 目的

识别 IntRuoyi 依赖的外部系统、平台、开源组件、基础设施和服务商，定义供应商评估与接口责任界面，避免只依赖供应商声明而无独立验证。

## 3. 供应商评估内容

| 评估项 | 要求 |
| --- | --- |
| 供应商资质 | 营业/资质、质量体系、服务能力、安全能力。 |
| 产品版本 | 当前使用版本、生命周期、补丁策略、已知漏洞。 |
| GxP 适用性 | 是否参与 GxP 数据生成、修改、存储、传输、审批或展示。 |
| 安全和数据完整性 | 身份、权限、审计、加密、备份、恢复、日志和访问控制。 |
| 变更通知 | 外部系统升级、补丁、配置变更的通知和影响评估机制。 |
| 服务级别 | 可用性、恢复时间、支持响应、备份责任界面。 |
| 文件证据 | 供应商问卷、审计报告、质量协议、SLA、验证包或版本声明。 |
| 独立验证 | 不能仅依赖供应商声明；需执行接口、配置、权限和数据完整性测试。 |

## 4. 接口责任界面

| 接口 | IntRuoyi 责任 | 外部方责任 | 联合验证 |
| --- | --- | --- | --- |
| ERP 同步 | 接收、校验、对账、缺失阻断、审计 | 提供准确订单、调拨、批次和接口变更通知 | 数据完整性、边界、失败重试、重复数据 |
| BPM 审批 | 发起业务审批、绑定对象和签名证据 | 保持流程任务、节点顺序和回调一致 | 审批顺序、回调幂等、驳回/重试 |
| 对象存储/NAS | 上传、hash、引用、权限、证据包 | 存储可用性、留存、对象版本、访问控制 | 文件读写、缺失检测、恢复演练 |
| 时间源 | 使用服务器/DB 受控时间并导出证据 | 提供批准 NTP/chrony 源和时间管理 | 偏差、漂移、不可手工覆盖 |
| 报表/文档查看 | 生成、展示、导出受控内容 | 组件渲染和兼容性 | 输出一致性、签名/水印/预览权限 |
