## 5. 偏差处理

测试执行中出现以下任一情况，必须开偏差：

- 实际结果与预期结果不一致。
- 测试步骤无法执行、数据缺失、权限缺失或环境配置不一致。
- 使用了未经批准的替代路径、人工干预或非真实数据。
- 发现未记录的 GxP 写入口、未授权访问、审计缺失或接口数据不一致。

偏差不得直接关闭；必须记录根因、影响评估、CAPA、复测证据和 QA 批准。
