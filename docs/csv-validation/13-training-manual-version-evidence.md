# 13 培训、操作手册与文档版本现场证据

## 1. 目的

本文件补充 7.1-7.4 现场检查项的可交付证据框架，覆盖 IntRuoyi eDHR / 批记录系统的 CSV 专项培训、系统操作手册、文档版本管理和岗位培训匹配。

配套 Excel 台账：`docs/csv-validation/IntRuoyi-eDHR-CSV现场证据包.xlsx`。

## 2. 适用检查项

| 检查项 | 现场关注点 | 配套台账页签 |
| --- | --- | --- |
| 7.1 未开展针对性 CSV 培训 | 是否有 CSV、GMP、数据完整性、电子记录/签名、权限和审计专项培训，是否有签到、考试、实操和补训记录 | `7.1培训矩阵`、`7.1培训记录` |
| 7.2 系统操作手册不完整 | 手册是否覆盖当前系统版本、岗位操作、详细步骤、异常处理和版本更新 | `7.2手册清单` |
| 7.3 文档版本管理混乱 | CSV 文档、SOP、操作手册、培训材料是否有编号、版本、状态、修订和作废控制 | `7.3文档主清单` |
| 7.4 培训内容与岗位需求不匹配 | 培训是否按生产、PQC、QA、IT、放行、审计等岗位差异化，并与权限授权前置关联 | `7.4岗位匹配`、`权限培训关联` |

## 5. 岗位培训原则

培训不得只做一套通用课，应按岗位拆分：

- 生产一线员工：一线报工 / 记录本提交、设备参数、完成数量、损耗、电子签名和异常上报。
- 生产班组长：活跃订单、报工复核、数量分配、异常上报、订单完成、批次执行资料。
- PQC 检验员：首检、巡检、末检、逐件检验、检验结果和电子签名提交。
- PQC 组长：PQC 提交复核、退回、确认和过程检验单回填来源。
- QA / 验证负责人：验证包、RTM、OQ/PQ、偏差/CAPA、放行审核和审计追踪。
- IT / 系统管理员：账号生命周期、角色权限、权限评价、备份恢复和审计导出。
- 放行负责人：批记录资料审核、附件齐套、放行通过 / 退回、电子签名和归档。

## 6. 权限前置规则

关键权限应与培训合格绑定：

| 权限能力 | 前置培训 | 控制要求 |
| --- | --- | --- |
| FILL | 岗位操作课 + 电子签名 | 未通过实操不得填写 GxP 记录 |
| SIGN | 电子签名责任培训 | 必须使用个人账号和签名凭证 |
| APPROVE | 复核 / 放行岗位课程 | 必须具备岗位任命和职责分离确认 |
| ARCHIVE | 放行 / 文档归档课程 | 必须理解记录不可篡改和归档要求 |
| AUDIT_VIEW | 审计追踪培训 | 只读授权，不附带修改权限 |
| ROUTE_EDIT | 工艺路线和版本控制培训 | 不得影响历史订单快照 |
| PERMISSION_ADMIN | 权限管理和审计培训 | 建议双人复核并定期复查 |

## 7. 正式提交前必须补齐

本包当前为现场准备版，不声称真实培训和审批已经完成。正式提交前必须补齐：

- 真实人员名单、岗位、部门、账号和权限清单。
- 真实培训日期、讲师、签到、考试成绩、实操考核和补训记录。
- 已批准 SOP / 手册编号、版本、生效日期、批准签名和作废记录。
- 系统正式发布版本、部署环境、验证包编号和验证报告结论。
- QA、IT、业务负责人签核记录。

## 8. 判定建议

在真实记录补齐前，7.1-7.4 建议判定为“发现问题 / 已建立整改证据框架”；补齐培训记录、受控手册、文档主清单、权限培训关联和有效性检查后，可按企业质量体系转为“未发现”。
