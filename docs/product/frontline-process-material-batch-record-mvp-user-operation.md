# 一线生产工序物料批记录 MVP 用户操作文档

## Purpose and Scope

本文说明“一线生产工序物料批记录 MVP”的实际操作方式。使用对象包括工艺管理员、审批人、一线生产员工和批记录查看人员。

本操作文档只覆盖最小实现：在工艺路线的工序里绑定批记录物料；一线生产按物料页签填写；完成数量填写后页签由灰色变绿色；正式提交时一起提交；批号从系统每日 ERP 同步表单读取，系统没有就没有；数量不一致取最小值。

本功能不要求用户维护用料比例，也不要求用户到产品 BOM 中设置一线生产物料页签。

## Evidence Reviewed

- 粗洗生产记录样式：同一工序下存在弹簧、杠杆等多个物料，批记录需要分别体现物料批号和数量。
- 一线生产页面样式：页面左侧已有完成数量、损耗数量、不良明细区域，右侧已有工序参数区域，中间空白区域可放物料页签。
- MVP 约束：灰色/绿色两种状态；完成数量填写即绿色；不做其它页签校验。
- 数据源约束：只读系统内 ERP 同步表单，不直连 ERP；系统没有同步数据就显示没有；数量不一致取最小值。
- 版本约束：物料绑定放在工艺路线的工序维护中，版本统一由工艺路线管理，历史订单使用快照。

## Roles

- 工艺管理员：维护工艺路线和工序下的批记录物料。
- 审批人：审批工艺路线版本变更。
- 一线生产员工：在生产提交页按物料填写数据并正式提交。
- 批记录查看人员：查看提交后的物料明细和系统同步批号。

## Primary User Flows

### Flow 1：工艺管理员配置某工序需要的物料

1. 进入“工艺路线”。
2. 打开需要维护的工艺路线草稿；如果当前路线已经发布，先创建或进入新的草稿版本。
3. 在路线中选择目标工序，例如“粗洗工序”。
4. 打开该工序的“批记录物料”区域。
5. 添加物料：
   - 物料编码：例如弹簧的编码。
   - 物料名称：例如“弹簧”。
   - 显示顺序：例如 1。
   - 启用状态：启用。
6. 继续添加第二个物料，例如“杠杆”。
7. 保存当前工序物料配置。
8. 按现有流程提交工艺路线审批。
9. 审批通过并发布后，新订单使用该路线版本时，一线生产页面会按该工序显示这些物料页签。

操作重点：

- 物料是在“工艺路线 > 某个工序”里设置，不是在产品 BOM 里设置。
- 一个工序可以有多个物料，不需要填用料比例。
- 如果另一个工序也需要物料，需要进入那一道工序单独绑定。

### Flow 2：审批人审核工序物料绑定变更

1. 进入工艺路线审批任务。
2. 查看本次路线版本变更内容。
3. 重点确认哪些工序新增、删除或调整了“批记录物料”。
4. 确认无误后审批通过。
5. 路线发布后，变更只影响后续新订单，不影响历史订单。

操作重点：

- 审批的是工艺路线版本，不是单独审批某个物料。
- 如果发现物料绑定错了，应驳回路线版本，由工艺管理员在草稿中修改后重新提交。

### Flow 3：一线生产员工填写物料页签

1. 进入一线生产页面。
2. 选择或进入当前订单、当前工序和当前员工。
3. 页面加载当前订单锁定路线版本中的工序物料。
4. 在页面空白区域看到物料页签，例如“弹簧”“杠杆”。
5. 初始状态下，所有物料页签为灰色。
6. 点击“弹簧”页签，填写弹簧的完成数量、损耗数量、不良明细和当前工序参数。
7. 只要“弹簧”的完成数量填写了，弹簧页签变为绿色。
8. 切换到“杠杆”页签，填写杠杆的数据。
9. 杠杆完成数量填写后，杠杆页签变为绿色。
10. 点击“正式提交”，系统把当前工序数据和物料明细一起提交。

操作重点：

- 页签绿色只表示“完成数量已填写”，不表示批号已经同步，也不表示其它字段都正确。
- 完成数量填 0 也会变绿色，因为 0 也是已填写。
- 批号不是一线员工手工填的，系统后续从每日 ERP 同步表单里读。
- 如果某个物料没有填写完成数量，MVP 不因为页签灰色而增加额外拦截；是否能提交仍以当前页面原有正式提交规则为准。

### Flow 4：查看批号和批记录

1. ERP 表单每日同步到系统后，系统内会保存生产订单和物料相关数据。
2. 批记录查看页按生产订单号和物料编码读取系统内同步表单。
3. 如果系统内找到批号，显示在对应物料下。
4. 如果系统内没有找到批号，显示为空或“暂无同步数据”。
5. 系统不会因为缺少批号去实时访问 ERP，也不会用库存批号替代。

操作重点：

- 批号晚于一线提交出现是正常情况。
- 一线提交事实和系统同步批号是两个来源：提交事实记录人填了什么，同步批号记录 ERP 同步到了什么。

## Alternate Flows

### 修改已发布路线中的物料

1. 工艺管理员不能直接改已发布路线对历史订单生效的内容。
2. 需要创建或进入路线草稿版本。
3. 在草稿版本中修改某工序的批记录物料。
4. 走工艺路线审批。
5. 发布后只影响新订单。

### 某工序不需要物料

1. 工艺管理员不配置该工序的批记录物料。
2. 一线生产页面不显示物料页签。
3. 员工按原流程填写工序数据并提交。

### ERP 同步数据还没到

1. 一线员工照常提交生产数据。
2. 批号区域显示为空或“暂无同步数据”。
3. 系统等待下一次 ERP 表单同步。
4. 同步数据进入系统后，查看页按系统内同步事实展示批号。

### 数量不一致

1. 如果弹簧完成数量为 5，杠杆完成数量为 3，工序进度按 3。
2. 如果一线填写某物料完成数量为 5，系统同步数量为 3，该物料可用完成量按 3。
3. 系统不按用料比例折算，不把多个物料数量相加。

## Error Flows

### 路线未发布

- 现象：管理员已配置物料，但一线页面看不到。
- 处理：确认工艺路线草稿是否已审批并发布。
- 原则：未发布的路线物料不能影响一线生产。

### 历史订单看不到新物料

- 现象：管理员修改路线后，旧订单仍显示旧物料。
- 处理：这是正确行为。旧订单读取订单锁定时的路线版本快照。
- 原则：不能用新路线覆盖历史订单。

### 系统没有同步批号

- 现象：批记录中某物料批号为空。
- 处理：检查系统内每日 ERP 同步表单是否已有该生产订单号和物料编码的数据。
- 原则：系统没有就没有，不直连 ERP，不从库存补。

### 物料页签没有变绿

- 现象：页签仍是灰色。
- 处理：检查该物料的完成数量是否为空。
- 原则：只有完成数量是否填写决定颜色，其它字段不影响颜色。

## Out-of-Scope Flows

- 不在产品 BOM 页面设置一线物料页签。
- 不维护用料比例。
- 不从 ERP 实时读取。
- 不手工选择或录入批号。
- 不做全部物料必须绿色才能提交的新增校验。
- 不做扫码、称重、自动带出批号或异常差异审批。
- 不把历史订单自动迁移到新路线版本。

## Frontend Operation Notes

### 页面放置

- 物料页签放在一线生产页面中当前空白区域。
- 页签只使用两种颜色：
  - 灰色：完成数量为空。
  - 绿色：完成数量已填写。
- 不增加黄色、红色、异常色。

### 页面交互

- 点击物料页签后，当前页面字段切换为该物料的草稿。
- 切换页签时保留每个物料自己的填写内容。
- 员工填写完成数量后，当前物料页签立即变绿色。
- 员工点击“正式提交”时，页面把当前工序和物料明细一起提交。

### 批号展示

- 批号区域只读展示。
- 有同步数据时展示批号。
- 没有同步数据时展示为空或“暂无同步数据”。
- 不提供“从 ERP 读取”按钮。
- 不提供“从库存选择批号”按钮。

## Admin Configuration Notes

### 正确入口

正确入口是：

工艺路线 → 编辑路线草稿 → 选择工序 → 批记录物料

### 不再使用的入口

以下入口不用于本 MVP：

- 产品 BOM。
- 产品下的用料比例。
- 独立工序设置里的物料版本。
- ERP 实时查询入口。

### 配置例子

粗洗工序需要两个物料：

| 显示顺序 | 物料编码 | 物料名称 | 启用状态 |
| --- | --- | --- | --- |
| 1 | A001.02.03.4.202 | 弹簧 | 启用 |
| 2 | A001.02.04.8.102 | 杠杆 | 启用 |

配置发布后，一线粗洗页面显示两个页签：弹簧、杠杆。

## Acceptance Checklist

- 工艺管理员能在工艺路线的某道工序下配置多个批记录物料。
- 配置不要求填写用料比例。
- 工艺路线审批通过并发布后，新订单可以看到新配置。
- 历史订单不受新配置影响。
- 一线页面显示物料页签。
- 页签初始为灰色。
- 完成数量填写后页签变绿色。
- 页签颜色不受损耗、参数、批号影响。
- 正式提交时物料明细随工序数据一起提交。
- 批号只从系统内 ERP 同步表单读取。
- 系统内没有同步数据时不直连 ERP。
- 数量不一致时取最小值。

## Open Questions

- 如果后续希望“所有物料都填写完成数量后才能提交”，需要作为二期增强单独确认。
- 如果后续希望一线手工选择批号或扫码批号，需要作为二期增强单独确认。
- 如果后续希望用料比例参与计算，需要先重新定义比例和实际完成数量、同步数量、损耗数量之间的关系。
