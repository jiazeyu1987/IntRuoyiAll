# 生产班组长每日系统操作文档

## Purpose and Scope

本文定义生产班组长未来每天在本系统中的完整操作路径。重点说明班组长如何根据纸质订单从金蝶 ERP 同步并加入生产订单、如何同步并关联调拨单、如何组织生产报工、复核员工提交、分配工序数量、处理异常、查看 PQC 状态、确认批记录进度，以及如何进行非每日必做的班组基础维护。

本文只描述生产班组长在本系统中的操作，不替代计划排产员、仓库、物料员在纸质单据或金蝶 ERP 中的职责。

## Evidence Reviewed

- 用户确认：计划排产员通过纸质订单与生产班组长同步订单。
- 用户确认：生产订单由金蝶 ERP 每晚同步到本地生产订单列表，班组长根据纸质订单编号在本地列表中过滤搜索并加入活跃订单池。
- 用户确认：调拨单由金蝶 ERP 每晚同步到本地调拨单列表，班组长根据纸质调拨单号过滤查询并关联到本系统生产订单。
- 用户确认：班组长负责复核员工报工，并将工序报工数量分配给对应生产订单。
- 用户确认：班组基础维护包括添加/禁用员工、维护不良/损耗原因、从设备台账选择设备并绑定到工序、维护设备参数上下限、配置本班组负责范围。
- 用户确认：班组基础维护要留审计记录，只影响后续生产，不改写历史报工和历史批记录。
- 用户确认：一线生产、一线 PQC 签名提交和生产组长、PQC 组长复核只是提交复核来源；活跃订单生产进度 100%、检验进度 100% 后由班组长点击完成，才在同一业务节点统一回填批记录、过程检验单和有损耗时的损耗单；回填完成后创建批次执行，再上传来料检、灭菌、成品检文件，全部成功后才允许放行。
- 既有项目约束：批记录表单、表单槽位 `formBindings`、工序开始配置不得混用。

## Product Summary

生产班组长的一天应围绕 `生产班组长工作台` 展开。系统每天晚上从金蝶 ERP 同步生产订单和调拨单到本地列表；系统不应把本地列表中的所有生产订单和调拨单自动纳入生产执行，而应由班组长按纸质订单号和纸质调拨单号过滤搜索后，主动把对应生产订单加入活跃订单池，并把对应调拨单关联到生产订单。

班组长每日核心工作分为两类：

- 每日生产执行：加入订单、关联调拨单、判断能否开工、监控报工、复核报工、分配订单、处理异常、查看 PQC 状态、完成活跃订单并触发统一回填、日结。
- 低频班组维护：维护员工、原因、设备、设备参数上下限和负责范围。

批记录相关资料不在一线提交、生产组长复核或 PQC 组长复核时提前写入。班组长只在活跃订单双进度达到 100% 后点击 `完成`，由系统统一回填批记录、过程检验单和有损耗时的损耗单；无损耗时不生成损耗单。回填成功后系统创建批次执行，后续在批次执行内上传来料检、灭菌、成品检文件，文件齐全后才进入最终放行。

## Target User

| 角色 | 生产班组长 |
| --- | --- |
| 操作系统 | 本系统 |
| 外部依据 | 计划排产员同步的纸质订单、纸质调拨单号、ERP 夜间同步后的本地生产订单列表和本地调拨单列表 |
| 核心职责 | 把已确认订单和调拨单纳入本系统，组织生产，复核报工，分配工序数量，处理异常，完成日结 |
| 非职责 | 不替计划排产员排产，不替仓库生成调拨单，不替物料员解包，不替 PQC 填检验单，不替放行负责人放行 |

## First Version Scope

- 生产班组长从 ERP 夜间同步后的本地生产订单列表中过滤查询并加入生产订单。
- 生产班组长从 ERP 夜间同步后的本地调拨单列表中过滤查询并关联调拨单。
- 生产班组长判断订单和物料是否可开工。
- 生产班组长查看员工报工提交并复核。
- 生产班组长将工序完成数量分配给生产订单。
- 生产班组长查看工序进度、PQC 状态和批记录汇总状态。
- 生产班组长上报订单或工序异常。
- 生产班组长执行每日生产收尾和待办清理。
- 生产班组长维护班组基础配置，并保留审计记录。

## Non-Goals

- 不要求计划排产员登录本系统录入排产。
- 不要求仓库登录本系统生成调拨单或发货。
- 不要求物料员登录本系统做解包确认。
- 不把 ERP 中所有订单自动加入生产执行池。
- 不把 ERP 中所有调拨单自动关联到订单。
- 不允许用默认订单、默认调拨单、默认物料批次、默认设备或默认人员掩盖缺失数据。
- 不允许班组长复核覆盖员工原始提交记录。
- 不允许班组基础维护改写历史报工、历史批记录或历史电子签名。

## Daily User Flow

### 1. 上班后进入生产班组长工作台

班组长登录系统后，首先进入 `生产班组长工作台`。首页应展示：

- 今日已加入系统的生产订单。
- 近期仍未完成的生产订单。
- 紧急订单提醒。
- 待关联调拨单的订单。
- 待开工检查的订单。
- 员工待复核报工。
- 待分配到订单的报工数量。
- 异常订单和异常工序。
- PQC 首检、巡检、末检状态。
- 批记录和过程检验记录完整性状态。

班组长在这个界面判断当天工作重点，但不在这里直接替员工填报生产数据。

### 2. 根据纸质订单加入生产订单

计划排产员把纸质订单同步给班组长后，班组长进入 `本地生产订单列表 / 加入活跃订单`。

班组长操作：

1. 根据纸质订单上的订单编号、产品名称、规格、数量、客户或日期，在本地生产订单列表中过滤搜索。
2. 核对本地生产订单列表中的 ERP 同步数据与纸质订单是否一致。
3. 勾选确认本班组要执行的生产订单。
4. 点击 `加入本系统生产订单池`。
5. 系统记录加入人、加入时间、ERP 生产订单号、纸质确认来源说明。

系统要求：

- 只有班组长主动加入活跃订单池后的生产订单，才进入本系统后续报工、PQC、批记录和放行流程。
- 本地生产订单列表中存在但班组长未加入的生产订单，不应出现在员工报工订单分配范围内。
- 如果纸质订单在本地生产订单列表中查不到对应生产订单，系统应提示 ERP 夜间同步数据缺失或纸质订单编号不匹配，不能创建默认订单。

### 3. 同步并关联调拨单

生产订单加入后，班组长进入 `本地调拨单列表 / 物料调拨关联`。

班组长操作：

1. 按纸质调拨单号、生产订单号、调拨申请单号、物料编码或日期，在本地调拨单列表中过滤查询。
2. 核对本地调拨单列表中的 ERP 同步数据是否对应当前生产订单。
3. 查看物料种类、数量、批次和发货状态。
4. 勾选正确调拨单。
5. 点击 `关联到生产订单` 或 `加入物料追溯`。

系统要求：

- 班组长不替仓库生成调拨单，也不替仓库发货。
- 班组长只把 ERP 夜间同步到本地调拨单列表中的调拨单关联到本系统生产订单。
- 调拨单关联后，系统才能把物料种类、数量和批次作为该生产订单的正式追溯依据。
- 如果调拨单缺失、物料批次缺失、物料数量不足或物料与订单不匹配，系统应阻塞开工检查或提示异常上报。

### 4. 执行订单开工检查

订单和调拨单加入后，班组长进入 `订单开工检查`。

班组长检查：

- 生产订单是否已加入本系统。
- 对应调拨单是否已关联。
- 物料种类是否匹配。
- 物料数量是否满足生产。
- 物料批次是否完整。
- 工艺路线是否存在。
- 每个工序是否有生产系数。
- 每个工序是否有 SOP。
- 需要批记录的工序是否绑定正式批记录表单。
- 需要 PQC 的工序是否有 QA 检验规程。

系统结果：

- 全部满足时，订单进入 `可生产` 或 `生产中`。
- 缺少物料、调拨单、批次、工艺路线、生产系数、SOP、批记录绑定或检验规程时，订单进入 `开工阻塞`。
- 异常上报第一版暂时只在活跃订单内发起；未加入活跃订单的本地订单或调拨单问题先作为同步/开工检查阻塞处理。

### 5. 组织生产并监控员工报工

生产开始后，一线员工在 `一线报工/记录本提交` 或设备端入口提交工序数据。

班组长在 `生产班组长工作台` 查看：

- 哪些员工已提交报工。
- 哪些工序已提交报工。
- 完成数量、损耗数量、损耗原因。
- 使用设备和设备参数。
- 电子签名状态。
- 是否有参数超限或缺失。
- 是否待班组长复核。

班组长不替员工录入原始生产事实。员工原始提交、电子签名和提交时间必须保留。

### 6. 复核员工报工

员工提交后，班组长进入 `报工复核与订单分配`。

班组长复核内容：

- 员工是否属于本班组或当前负责范围。
- 工序是否正确。
- 报工数量是否合理。
- 损耗数量是否合理。
- 损耗原因是否正确。
- 使用设备是否为该工序可用设备。
- 设备参数是否完整。
- 设备参数是否超出上下限。
- 电子签名和提交时间是否存在。

班组长可执行：

- `复核通过`：进入订单数量分配。
- `退回修改`：要求员工补充或修正，并记录退回原因。
- `标记异常`：对明显异常报工、设备参数异常、损耗异常或现场异常发起异常处理。

复核规则：

- 班组长复核不能覆盖员工原始提交。
- 如果需要修改，应形成修订记录、修改原因和新的签名或复核日志。
- 复核通过后，报工才能进入订单进度计算。

### 7. 将工序数量分配到生产订单

班组长复核通过后，需要把本次工序完成数量分配给对应生产订单。

班组长操作：

1. 查看本次可分配完成数量。
2. 查看可分配订单列表。
3. 系统按活跃订单加入时间和订单剩余数量给出 FIFO 默认分配建议。
4. 班组长确认分配结果，必要时手动调整。
5. 点击 `确认分配`。

系统计算：

```text
工序应完成数量 = 生产订单数量 × 工序生产系数
```

例如订单要求生产 300 个产品：

- 工序生产系数为 `1.0`，该工序应完成 `300` 个。
- 工序生产系数为 `3.0`，该工序应完成 `900` 个。

系统要求：

- 报工数量只能分配给已加入本系统且未异常终止的生产订单。
- 分配数量不能超过该订单该工序剩余应完成数量，除非后续业务明确允许超产。
- 损耗数量不能替代合格完成数量。
- 分配完成后系统更新订单工序进度。

### 8. 处理中途异常

生产过程中出现异常时，班组长进入 `异常订单上报` 或从订单、工序、报工记录发起异常。

常见异常：

- 原材料异常。
- 客户取消订单。
- 活跃订单对应调拨单缺失。
- 调拨物料与订单不匹配。
- 调拨数量不足。
- 物料批次异常。
- 设备异常。
- 工序参数异常。
- 损耗异常。
- PQC 检验失败影响继续生产。

班组长填写：

- 异常对象：订单、工序、物料、设备或报工记录。
- 异常类型。
- 异常原因。
- 现场说明。
- 影响范围。
- 是否需要停止后续生产。

系统要求：

- 异常不改写已经提交的员工原始报工。
- 异常不改写历史批记录。
- 异常订单不再继续生成新的报工、PQC、批记录和放行流程，除非后续有正式恢复规则。

### 9. 查看 PQC 状态

班组长可以在 `PQC 状态看板` 查看质量进度，但不替 PQC 填写检验单。

班组长查看：

- 首检是否完成。
- 上午巡检是否完成。
- 下午巡检是否完成。
- 晚上末检是否需要做。
- PQC 检验是否通过。
- PQC 组长是否已确认。
- 是否有检验失败或待处理质量异常。

系统要求：

- PQC 检验事实由 PQC 检验员提交。
- PQC 检验单由 PQC 组长确认。
- PQC 组长未确认的检验单，不能作为活跃订单完成时的过程检验单回填来源。

### 10. 查看工序完成和批记录进度

当订单某工序累计完成数量达到应完成数量时，系统更新工序完成状态和生产进度；此时不提前回填最终批记录。

班组长在 `批记录进度看板` 查看：

- 订单每个工序的目标数量。
- 每个工序已完成数量。
- 每个工序剩余数量。
- 工序对应批记录表单是否已具备回填来源。
- 设备参数、完成数量、损耗数量、损耗原因是否已具备回填来源。
- 过程检验单来源是否已由 PQC 组长确认。
- 是否存在阻塞活跃订单完成或统一回填的缺项。

系统要求：

- 批记录表单必须来自工序设置中的正式逐工序绑定。
- 不得用表单槽位 `formBindings` 替代批记录表单。
- 不得用工序开始配置替代批记录表单。
- 缺少正式批记录绑定时，系统必须阻塞活跃订单完成节点的统一回填并提示原因。

### 11. 完成活跃订单并进入批次执行

当活跃订单生产进度 100%、检验进度 100% 后，班组长进入活跃订单点击 `完成`。

班组长确认：

- 生产进度是否为 100%。
- 检验进度是否为 100%。
- 生产报工是否已由生产组长复核并分配。
- 一线 PQC 是否已由 PQC 组长复核。
- 领料单是否已与生产工单建立正式对应。
- 有损耗时损耗数量和损耗原因是否已复核；无损耗时确认不生成损耗单。

系统要求：

- 点击 `完成` 是批记录回填、过程检验单回填和损耗单回填的同一个业务节点。
- 一线生产、一线 PQC、生产组长复核和 PQC 组长复核都只是提交复核，不得提前触发表单回填。
- 批记录回填读取一线生产、生产工单和领料单正式来源。
- 过程检验单回填读取一线 PQC 和 PQC 组长确认后的正式来源。
- 损耗单只在一线生产存在损耗时回填；没有损耗时不写损耗单。
- 三类回填完成后，系统创建批次执行并建立可追溯关系。
- 批次执行中必须上传来料检文件、灭菌文件和成品检文件；三类文件上传成功后，才允许最终放行。

### 12. 下班前执行班组日结

每天结束前，班组长进入 `班组日结 / 今日生产收尾`。

班组长确认：

- 纸质确认订单是否都已从 ERP 加入系统。
- 今日紧急订单是否已加入系统。
- 每个生产订单是否已关联正确调拨单。
- 是否存在调拨单缺失、物料缺失或批次异常。
- 今日员工报工是否全部复核。
- 今日复核通过的报工是否全部分配到订单。
- 是否存在退回未修改的报工。
- 是否存在异常订单或异常工序未处理。
- PQC 首检、巡检、末检状态是否有阻塞。
- 工序完成状态是否正确。
- 活跃订单完成、统一回填和批次执行文件上传是否存在缺项。
- 明天需要继续生产的订单和工序。

系统输出：

- 班组日结记录。
- 未完成事项清单。
- 次日延续订单列表。
- 异常未关闭列表。
- 待复核 / 待分配 / 待 PQC 确认提醒。

## Low-Frequency Maintenance Flow

### 班组基础维护

班组长还需要有 `班组基础维护` 界面。这不是每天必须做的主流程，但属于班组长权限范围。

班组长可维护：

- 添加本班组员工。
- 禁用本班组员工。
- 维护不良原因和损耗原因。
- 给工序增加可用设备。
- 维护设备参数上下限。
- 配置本班组负责范围。

### 员工维护规则

- 添加员工后，该员工可在后续一线报工入口中被选择。
- 禁用员工后，该员工不再出现在后续报工可选人员中。
- 禁用员工不能隐藏历史报工、历史签名、历史批记录和历史审计记录。

### 原因维护规则

- 不良原因和损耗原因用于员工报工、班组复核和异常统计。
- 原因停用后，不再出现在后续可选列表中。
- 历史报工中已选择的原因必须保留当时编码和显示文本快照，不能被后续修改覆盖。

### 工序设备维护规则

- 班组长可从设备台账选择设备并绑定为工序可用设备。
- 员工报工时只能选择当前工序允许使用的设备。
- 设备停用或报修后，不再出现在后续报工可选设备中。
- 历史报工中已记录的设备不能因设备停用而消失。

### 设备参数上下限规则

- 班组长可维护某工序、某设备、某参数的上下限。
- 上下限用于报工提示、班组复核、异常判断和审核副本。
- 上下限不应直接覆盖员工原始提交值。
- 历史设备参数不因后续上下限调整而被改写。

### 负责范围维护规则

- 班组长可配置本班组负责的员工、工序、产线、设备或订单范围。
- 负责范围决定班组长能看到和复核哪些员工提交。
- 负责范围调整只影响后续可见范围和后续提交，不应直接改写历史数据归属。

### 审计规则

所有班组基础维护都必须记录：

- 操作人。
- 操作时间。
- 操作类型。
- 修改前内容。
- 修改后内容。
- 生效范围。
- 生效时间。

## Business Rules

- 生产订单来自 ERP 夜间同步后的本地生产订单列表，但必须由班组长按纸质订单编号过滤搜索并加入活跃订单池。
- 调拨单来自 ERP 夜间同步后的本地调拨单列表，但必须由班组长按纸质调拨单号过滤搜索并关联到本系统生产订单。
- 未加入本系统的 ERP 生产订单，不能参与员工报工分配。
- 未关联调拨单的生产订单，不能形成完整物料追溯。
- 班组长不替仓库生成调拨单，不替仓库发货。
- 班组长不替物料员解包。
- 班组长不替员工填写原始报工。
- 班组长不替 PQC 填写检验单。
- 班组长复核通过后，报工数量才能计入订单工序进度。
- FIFO 默认分配按活跃订单加入时间排序。
- 工序完成按生产订单数量乘以工序生产系数判断。
- 班组基础维护只影响后续生产。
- 班组基础维护不得改写历史报工、历史批记录、历史电子签名和历史审计记录。

## States and Transitions

| 对象 | 状态 | 触发 |
| --- | --- | --- |
| 本地生产订单 | 未加入活跃订单池 | ERP 夜间同步后存在于本地生产订单列表，但班组长尚未选择加入。 |
| 活跃订单 | 已加入 | 班组长根据纸质订单编号从本地生产订单列表过滤搜索并加入。 |
| 系统生产订单 | 待关联调拨单 | 订单已加入但尚未关联 ERP 调拨单。 |
| 系统生产订单 | 待开工检查 | 订单和调拨单已关联，等待检查物料和配置。 |
| 系统生产订单 | 可生产 | 物料、路线、工序、批记录和检验规程满足开工条件。 |
| 系统生产订单 | 开工阻塞 | 缺调拨单、物料批次、工艺路线、生产系数、SOP、批记录绑定或检验规程。 |
| 系统生产订单 | 异常终止 | 班组长上报并确认异常。 |
| 员工报工 | 待复核 | 员工签名提交后生成。 |
| 员工报工 | 已复核 | 班组长确认通过。 |
| 员工报工 | 已分配 | 班组长将数量分配到生产订单。 |
| 工序 | 已完成 | 累计合格完成数量达到订单数量乘以生产系数。 |
| 班组配置 | 已生效 | 班组长保存维护配置并记录审计。 |
| 班组配置 | 已停用 | 员工、原因、设备或规则被禁用，只影响后续选择。 |

## Edge Cases

- 纸质订单在本地生产订单列表查不到：不能手工创建默认订单，应提示 ERP 夜间同步数据缺失或纸质订单编号不匹配。
- 本地生产订单列表中的 ERP 同步数据与纸质订单数量不一致：不能加入或必须标记差异并走差异确认。
- 纸质调拨单号在本地调拨单列表查不到：订单不能形成完整物料追溯，应阻塞开工检查。
- 调拨单物料与订单不匹配：不能关联为正式追溯数据。
- 调拨单缺少物料批次：不能完成批记录物料追溯。
- 工序缺少生产系数：不能用 `1.0` 默认值代替，应阻塞工序完成判断。
- 员工报工未复核：不能计入订单工序进度。
- 报工数量未分配到订单：不能推动订单完成。
- PQC 未确认：不能作为过程检验单回填来源。
- 活跃订单双进度未到 100%：不能点击完成，也不能启动批记录、过程检验单、损耗单统一回填。
- 无损耗订单：不能为了凑齐资料生成空损耗单。
- 批次执行三类文件未上传成功：不能进入最终放行。
- 班组长禁用员工：历史报工和历史签名仍可查询。
- 班组长修改损耗原因：历史报工原因显示历史快照，不随新名称改写。
- 班组长调整参数上下限：历史设备参数不重新判定或覆盖。

## Acceptance Criteria

- 文档明确班组长每天先根据纸质订单编号从本地生产订单列表过滤搜索并加入活跃订单池。
- 文档明确调拨单由班组长根据纸质调拨单号从本地调拨单列表过滤搜索并关联到本系统生产订单。
- 文档明确系统不能自动把所有 ERP 订单和调拨单纳入生产执行。
- 文档按一天顺序覆盖上班查看、订单加入、调拨单关联、开工检查、生产监控、报工复核、订单分配、异常处理、PQC 状态查看、批记录进度查看、活跃订单完成、批次执行文件上传和日结。
- 文档覆盖 `班组基础维护`，包括添加/禁用员工、不良/损耗原因、从设备台账选择并绑定工序设备、设备参数上下限和负责范围。
- 文档明确班组基础维护必须留审计记录。
- 文档明确班组基础维护只影响后续生产，不改写历史报工和历史批记录。
- 文档明确班组长不替仓库、物料员、员工、PQC 或放行负责人执行其职责。
- 文档明确批记录表单、表单槽位和工序开始配置不得混用。
- 文档明确批记录、过程检验单、损耗单在活跃订单完成节点统一回填，且无损耗不生成损耗单。
- 文档明确批次执行在统一回填后创建，来料检、灭菌、成品检文件上传成功后才允许放行。

## Open Questions

- 纸质订单与本地生产订单列表中的 ERP 同步数据不一致时，是直接阻塞加入，还是允许班组长发起差异确认流程。
- 调拨单是否允许一个生产订单关联多张调拨单，或一张调拨单拆分关联多个生产订单。
- 班组长维护本班组负责范围是否需要上级审批。
- 班组基础维护的生效时间是立即生效，还是允许设置未来生效时间。
- 参数上下限超限时，第一版不覆盖员工原始提交；仍需确认不同超限等级对应提示、复核和异常判断的展示方式。

## Product Blockers

- ERP 夜间生产订单同步不可用时，班组长无法在本地生产订单列表中正式加入活跃订单。
- ERP 夜间调拨单同步不可用或缺少物料批次时，订单物料追溯不完整。
- 工艺路线缺少生产系数、SOP 或正式批记录表单绑定时，工序完成和活跃订单完成回填不能闭环。
- QA 未维护检验规程时，PQC 检验任务不能按规则生成。
- 批次执行中来料检、灭菌、成品检文件任一缺失时，最终放行不能闭环。
- 班组基础维护没有审计能力时，不能允许配置直接生效。
