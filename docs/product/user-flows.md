# 注册证业务时间模拟与九点任务测试用户流程

## Purpose and Scope

本文描述注册证“注册测试”页签的最小 MVP 用户路径，重点是创建单证件测试场景、设定场景业务日期、触发续证生效扫描、触发完整上午九点任务模拟和核对旧证归档结果。

## Primary User Flows

### Flow 1：进入注册测试

1. 用户登录本机或测试环境。
2. 用户打开注册证管理，选择“注册测试”页签。
3. 系统校验环境、芋道源码租户、用户权限和测试数据范围。
4. 页面显示测试模式、真实当前时间和可创建的测试场景。

成功结果：用户明确知道当前是测试模式，且不会修改电脑系统时间、芋道源码租户的全局业务日期或其他证件状态。

### Flow 2：配置测试场景

1. 用户创建测试场景。
2. 用户选择一张任务自有测试注册证。
3. 用户输入目标场景业务日期。
4. 用户点击“保存场景”。
5. 系统校验证件、日期、芋道源码租户和权限，保存场景编号、证件和日期。
6. 页面重新读取并显示场景编号、测试证件、场景日期、保存人和真实保存时间。

成功结果：场景已准备就绪，但系统尚未自动执行任何生效或提醒动作；正式注册证列表和其他证件不受影响。

### Flow 3：模拟续证生效并归档旧证

1. 用户打开一个包含待生效续证的测试场景。
2. 页面显示该场景测试证件的当前证、待生效证、生效日期和预计旧证。
3. 用户将场景日期设置到生效日期当天或之后。
4. 用户点击“执行续证生效扫描”。
5. 系统按正式生效规则校验并只处理该场景测试证件；该证件失败时按单证件事务回滚，不影响场景外证件。
6. 页面展示新证成为当前证、原证进入旧证库、旧证失效日期和生命周期记录。

成功结果：用户可以从场景结果、当前证列表和旧证库确认该测试证件的新旧版本状态；其他证件不受影响。

### Flow 4：手工触发完整上午九点任务模拟

1. 用户在场景日期已保存后点击“执行完整九点任务模拟”。
2. 系统只对场景测试证件依次执行续证生效、提醒计算和通知预览。
3. 页面分别展示三个阶段的运行状态、数量和失败原因。
4. 用户打开任务记录查看真实开始/结束时间、模拟业务日期和影响证件。

成功结果：用户能区分“生效归档成功”“提醒计算结果”和“通知预览结果”；系统不发送真实站内信，也不执行全租户九点任务。

### Flow 5：重复执行验证幂等

1. 用户在同一场景、同一测试证件和同一场景日期再次点击相同任务按钮。
2. 系统识别相同场景业务键并返回原执行结果或幂等重放结果。
3. 页面显示新增生效数、归档数和提醒事实均为 0，通知预览结果沿用原结果。

成功结果：数据库不会出现第二个当前证、重复旧证事件或重复通知。

### Flow 6：关闭测试场景

1. 用户点击“关闭场景”。
2. 系统要求确认，显示场景编号、测试证件和场景日期。
3. 用户确认后，系统将场景设为只读关闭状态。
4. 页面保留场景结果和审计记录，不再允许执行。

成功结果：正式注册证查询和任务始终使用真实日期；既有测试审计和生命周期记录保留。

## Alternate Flows

### Alternate A：没有待生效续证

用户仍可执行生效扫描。系统返回“无可生效候选”，不创建伪造生命周期记录，不修改证件状态。

### Alternate B：模拟日期尚未到达生效日

系统保留当前证和待生效证，返回待生效数量和下一条生效日期，不归档旧证。

### Alternate C：模拟日期回退

系统允许在场景内回退日期，但不会把已生效的新证恢复为旧证，也不会反向写入生命周期事件。页面明确提示“日期回退不执行反向业务”。

### Alternate D：仅验证归档，不验证通知

用户使用“执行续证生效扫描”，只验证新旧证切换，不触发提醒和站内信。

## Error Flows

### Error 1：环境或权限不允许

系统拒绝进入页签或提交请求，显示测试能力不可用，并记录拒绝原因。页面不能通过隐藏按钮或重试绕过后端拒绝。

### Error 2：日期输入非法

系统阻止保存，保留用户输入，显示日期格式或范围错误；不切换业务日期、不执行任务。

### Error 3：测试证件不在范围

系统不返回该证件的详细状态，显示测试证件范围不合法，并记录租户和对象校验失败。

### Error 4：生效数据不完整

版本、快照、文件或生命周期关系校验失败时，系统返回明确错误，当前证和旧证不发生部分切换。

### Error 5：提醒或通知阶段失败

完整九点任务模拟页面保留生效阶段结果，同时将提醒计算或通知预览阶段标记为失败，展示正式规则解析失败原因。

### Error 6：重复点击或并发执行

系统锁定同一场景、测试证件、场景日期和任务类型的并发执行；后续请求返回处理中或幂等重放结果，不重复写业务事实。

### Error 7：关闭场景失败

系统保留当前可执行场景并显示关闭失败原因，不显示已关闭成功；用户可在前置条件恢复后再次执行。

## Out-of-Scope Flows

- 修改 Windows 或 Docker 系统时间后观察全系统行为。
- 在正式环境选择真实注册证做时间推进。
- 通过测试页签直接批准、驳回或撤回审批。
- 通过测试页签直接下载旧证或绕过查看/下载授权。
- 直接修改数据库中的证件日期、版本状态或生命周期事件。
- 远程服务器、其他租户或批量测试证件管理。
- 调用全租户正式九点任务、发送真实站内信或修改正式任务记录。
