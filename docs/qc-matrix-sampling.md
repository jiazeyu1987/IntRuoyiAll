# 巡检矩阵抽样改造与验证

## 业务口径

- 巡检由“批量 × 百分比”改为：订单冻结批量 + 项目检验水平 → 字码 → 正常一次名义样本量。
- 支持 I、II、III、S-1、S-2、S-3、S-4，内部存储特殊水平为 S1～S4。
- 实际应检数取批量与名义样本量的较小值；1件批量全检，无字码。
- 首检继续使用项目固定数量；巡检由一线 PQC 手动创建连续轮次，每轮按各项目检验水平冻结矩阵抽样依据。
- AQL独立保存，不作为比例。本功能按已确认口径返回名义样本量，不计算AQL箭头调整或Ac/Re。
- 例如批量3000：I级为H/50件，S-3为E/13件。混合水平按各项目独立执行，任务总应检数量取项目最大值。
- 检验水平缺失、不完整或无效时拒绝发布/生成，不使用默认水平或百分比替代。

## 实现范围

- 检验规程Word解析、导入、编辑、发布及回显。
- QA规程配置、PQC和通用解析器、试填预览、导出回读。
- 活跃订单巡检任务生成，逐项目冻结标准、批量、水平、字码、名义样本量与实际应检数。
- 一线PQC返回各项目冻结数量和抽样依据；正式应检数不可手工调整。
- 任务提交与放行证据包含抽样依据，读取时校验冻结计划一致性。
- 质量检验模板页面增加抽样矩阵查询入口，复用现有查询权限。

数据库脚本：`IntRuoyiBackend/sql/mysql/20261105_mes_qc_matrix_sampling.sql`。新增检验水平、AQL、任务抽样依据字段。旧比例列停止读写；脚本不转换历史规程和任务。
