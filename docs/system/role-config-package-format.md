# 权限角色配置包格式

## 版本 4

权限角色包导出与导入统一使用 `packageVersion: "4"`。版本 4 使用当前精确菜单标识规则：唯一权限使用 `permission:`，共享权限使用包含权限及父级路由的 `route:`，无权限按钮保留名称以避免不同按钮合并。导入仍校验目标租户套餐边界、分类、角色及全部菜单引用，全部通过后才写入。

版本 3 曾同时用于权限聚合格式和精确路由格式，不能据版本号判定其含义。导入在获取审计账本锁、权限锁及任何业务写入之前明确拒绝版本 3，并提示从可信来源重新导出版本 4；不自动转换、不将共享权限映射到所有候选菜单，也不得只修改 JSON 中的版本号。

## 旧包迁移条件

必须有能够追溯至原导出时点的角色—菜单精确绑定，或由业务确认的逐角色菜单清单。将该绑定与原包的角色代码、分类、名称、状态、排序、角色类型、数据权限和菜单权限逐项对比，所有差异需明确确认；保留原包，生成独立的新包。当前配置或同名租户不能自动替代历史配置。

只存在旧权限字符串时，多菜单共用权限造成的信息损失无法由版本号或当前菜单列表还原。缺失可信绑定时继续拒绝，不生成猜测授权的迁移包。

## 验证与发布边界

服务测试覆盖版本 4 导出/导入回环、版本 3 写入前拒绝、仅改版本号不能绕过共享权限校验、精确菜单解析和租户套餐边界。测试通过不代表历史 59 角色已恢复，也不代表运行服务已部署或真实前端导入成功；需分别核实。
