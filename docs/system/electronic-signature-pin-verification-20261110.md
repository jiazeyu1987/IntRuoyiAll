# 电子签名 PIN / 密码：本机部署与验收

环境：本机 `int_main`，前端 http://127.0.0.1:8081 ，后端 48081。仅本机部署，未发布远程服务器。

## 已完成验证

所有创建测试数据、设置凭据、切换方式、登录与签署操作均由 Playwright 在真实前端完成；数据库仅用于最终只读核验。

系统账号：任务专用账号 `pine2e1110`，独立权限角色 `PIN验证1110`。没有修改管理员账号密码。

| 场景 | 实际结果 |
| --- | --- |
| 新账号默认 PIN 模式、默认 888888 | 实际业务审批策略开关签署成功 |
| PIN 连续错误 8 次，再输入正确值 | 8 次均拒绝，随后正确值可签署；不计次、不锁定 |
| PIN 长度、非数字、确认不一致 | 页面明确拒绝 |
| 修改为 000000、123456 | 重复、前导零、连续数字均可保存并实际签署；旧值失效 |
| 切换为登录密码 | 刷新后保留；PIN 被拒绝，登录密码签署成功 |
| 修改本人登录密码、重新登录 | 强制退出；旧密码签署失败，新密码成功 |
| 从个人中心切回 PIN | 刷新后保留；原 PIN 可签署，密码被拒绝 |

实际签署对象为任务专用 `PIN_E2E_1110 / SIGNATURE_TEST / VERIFY` 策略，不对应生产业务。产生 7 条有效统一签名，包含 `SESSION_PLUS_PIN` 与 `SESSION_PLUS_PASSWORD`，证据哈希均为 64 位。

员工档案：通过生产组长页面新增任务专用临时工 `PIN员工验证1110`，并在一线生产页面真实打开“签名设置”。补充部署后，17 项页面结果全部符合预期：8 次连续错误 PIN 均返回 `1002003033`，随后初始 PIN 正常认证；`000000`、`123456` 可保存，旧 PIN 失效；可修改独立签名密码并双向切换方式；旧密码和非所选方式凭据均被拒绝。全程仅修改任务自有员工，没有提交生产报工。
