# 发票凭证打印助手运行时地址

前端通过已有、受权限保护的助手状态/启动接口读取 `publicUrl`，不再读取构建变量 `VITE_INVOICE_VOUCHER_PRINT_ASSISTANT_URL`。同一个前端包可用于不同环境。

## 部署配置

后端必须按目标环境显式配置：

- `yudao.erp.invoice-voucher-print-assistant.public-url`：用户浏览器能访问的 HTTP(S) 助手基础地址，可包含路径，不允许凭据、查询参数或片段。
- `yudao.erp.invoice-voucher-print-assistant.assistant-host`：后端健康探测使用的主机，必须从后端运行环境可达；不能从公开地址推断。原固定端口 18733 不变。

可通过 JVM `-D` 参数设置上述完整键。配置随后端启动读取。缺少公开地址时状态/启动接口明确报错；非法显式地址使启动校验失败。没有环境地址回退，也不把后端环回地址提供给浏览器。原登录票据和财务权限检查继续生效。
