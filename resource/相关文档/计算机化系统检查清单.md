## 第一章 精准的权限控制

| 序号 | 具体问题 | 符合性 |
| --- | --- | --- |
| 1.1 | **共享用户账户或密码：**多个用户使用同一账户登录系统，无法追溯具体操作人员，导致数据变更责任不明。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.2 | **用户权限过度分配：**普通用户被赋予管理员权限，可随意修改系统设置或数据，违反权限分级原则。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.3 | **职责分离缺失：**同一用户可同时执行操作和审批，导致潜在冲突和数据操纵风险。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.4 | **权限未基于角色划分：**系统未按职责（如生产、质量）设置角色权限，导致无关人员访问敏感数据。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.5 | **离职员工账户未及时注销：**前员工账户仍活跃，可能导致未经授权访问。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.6 | **默认管理员账户未修改：**系统默认账户（如 admin）密码未更改或未禁用，易被滥用。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.7 | **权限变更无记录：**权限调整（如添加/删除用户）未记录，无法追溯变更历史。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.8 | **无定期权限审查：**未定期审核用户权限，导致过期或冗余权限长期存在。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.9 | **关键操作权限缺失：**系统缺少对提交、审核、变更等关键动作的细粒度控制，无法满足业务需求。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.10 | **临时权限管理失控：**为应对紧急情况授予临时权限后，未设定有效期、未及时回收，或无临时权限使用记录。 | □ 未发现　□ 发现问题　□ 不适用 |
| 1.11 | **权限申请审批流程缺失或不规范：**审批人无相应授权，或审批未基于岗位需求评估。（建议权限申请保留审批记录） | □ 未发现　□ 发现问题　□ 不适用 |
| 1.12 | **权限与岗位变动不同步：**员工岗位调整后，对应权限未及时调整，仍保留原岗位敏感权限。 | □ 未发现　□ 发现问题　□ 不适用 |

## 第二章 全面的审计追踪

| 2.3 | **审计追踪未定期审查：**企业未建立审计追踪审查程序，或虽有程序但未实际执行定期审查关键数据变更的审计追踪。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.4 | **审计追踪可被篡改或删除：**审计追踪记录未受保护，可被用户删除或修改，无独立存储或不可变机制。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.5 | **审计追踪未覆盖关键操作：**审计追踪仅记录部分操作（如修改），未覆盖新增、修改、删除、批准等关键 GxP 操作，尤其是基础数据配置、权限变更等。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.6 | **审计追踪未与电子签名关联：**涉及电子签名的操作未在审计追踪中记录签名细节，或签名记录与变更记录分离，无法追溯授权人员。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.7 | **审计追踪未备份或保存期不足：**审计追踪数据未进行备份，或保存期限短于记录保存要求，无法在保存期内查阅。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.8 | **系统升级/变更未记录审计追踪：**系统升级、接口变更或配置调整未生成审计追踪记录，无法追溯系统级变更对数据的影响。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.9 | **审计追踪时间戳不准确：**时间戳未与标准时间同步（如无 NTP 时间同步机制），或时间可手动修改，导致真实性无法确认。 | □ 未发现　□ 发现问题　□ 不适用 |
| 2.10 | **审计追踪记录格式不规范：**记录内容混乱、缺乏统一格式，关键信息被冗余数据掩盖隐藏，记录形式不可读，不利于审查与追溯。 | □ 未发现　□ 发现问题　□ 不适用 |

## 第三章 完整的数据备份策略

| 序号 | 具体问题 | 符合性 |
| --- | --- | --- |
| 3.1 | **备份频率不足或无定期备份机制：**企业未建立定期自动/手动备份程序，或备份间隔过长与产品风险不匹配（如仅年度备份，而非每日/每周），导致近期关键变更数据（如生产批记录、检验结果）在系统故障或误删后无法恢复。 | □ 未发现　□ 发现问题　□ 不适用 |
| 3.2 | **备份保存期限不足或未与记录保存期一致：**备份数据保存期短于 GMP 要求的记录保存期限（如 GMP 规定某些记录保存 10 年，但备份仅保留 3–5 年），或备份介质老化/损坏导致长期数据不可查阅。 | □ 未发现　□ 发现问题　□ 不适用 |
| 3.3 | **备份不便于查阅或恢复测试缺失：**备份虽发现问题，但存储在离线介质/云端无索引、加密不当或无恢复验证程序，导致检查时无法快速检索/恢复特定时间点数据，或定期恢复测试未开展证明备份有效性。 | □ 未发现　□ 发现问题　□ 不适用 |
| 3.4 | **备份介质管理不规范：**备份介质无唯一标识、存储环境不符合要求（如潮湿、高温、无防磁保护），或介质借阅、归还无记录，发现问题丢失、泄露风险。 | □ 未发现　□ 发现问题　□ 不适用 |
| 3.5 | **备份责任人不明确：**无专人负责备份工作，导致备份操作遗漏、备份数据维护不当，或故障后无人牵头恢复工作。 | □ 未发现　□ 发现问题　□ 不适用 |
| 3.6 | **增量备份与全量备份搭配不合理：**仅做增量备份无定期全量备份，或全量备份间隔过长，导致数据恢复时链路复杂、耗时久，且易出现数据缺失。 | □ 未发现　□ 发现问题　□ 不适用 |

## 第四章 可靠的电子签名

| 序号 | 具体问题 | 符合性 |
| --- | --- | --- |
| 4.1 | **账户唯一性缺失，允许多个用户共用同一账号：**系统允许创建相同用户名或多个用户共享登录凭证，无法确保电子签名制作数据专属于签名人一人。 | □ 未发现　□ 发现问题　□ 不适用 |

| 4.3 | **无强制首次登录/重置后修改密码机制：**新用户或密码重置后可直接使用默认/临时密码进行签名，未强制修改，增加密码泄露风险。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.4 | **密码有效期缺失或过长：**系统未设置密码过期机制（如 90 天/180 天强制更换），长期使用同一密码，签名制作数据控制权难以保证。 | □ 未发现　□ 发现问题　□ 不适用 |

| 4.6 | **账户锁定机制不完善：**密码错误次数无上限或锁定时间过短（如仅几分钟），易被穷举攻击后继续签名。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.7 | **电子签名与被签内容未强制绑定：**签名后可分离签名与数据电文，或签名仅记录用户名而非与具体记录内容哈希绑定，改动后无法发现。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.8 | **签名时间可由用户手动选择或修改：**系统允许用户回填或更改签名时间戳，非系统自动生成不可篡改时间，导致签名有效性和真实性无法保证。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.9 | **审计追踪对电子签名记录缺失或不完整：**签名操作未在审计追踪中完整记录（缺少签名人、时间、签名理由、变更前后对比、签名算法等），无法证明签名及数据改动可被发现。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.10 | **无定期电子签名合规性审查或验证：**企业未建立电子签名使用审查程序，或未对签名可靠性进行周期性验证（如账户符合性检查、密码策略有效性确认），无法持续确保签名符合法律法规。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.11 | **多人审批签名顺序混乱：**需多级审批的电子签名，系统无法或未强制按预设顺序签名，或签名顺序记录缺失，无法确认审批流程合规性。 | □ 未发现　□ 发现问题　□ 不适用 |
| 4.12 | **签名人身份验证不足：**系统未确保签名时至少采用“双因子认证”（账户+密码）。 | □ 未发现　□ 发现问题　□ 不适用 |
